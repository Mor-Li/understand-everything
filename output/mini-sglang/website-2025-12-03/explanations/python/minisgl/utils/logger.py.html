python/minisgl/utils/logger.py

这份代码看起来稍微有点复杂，因为它主要是在做一个“装修”和“管家”的工作。

简单来说，它的作用是：创建一个超级美观、带有颜色、且能适应多显卡（分布式）环境的日志打印工具。

原本 Python 自带的 print 或者 logging 太朴素了，这个脚本就是为了把日志变得像“仪表盘”一样清晰。

为了让你看懂，我把它拆解成一个 “打造完美日志系统的 To-Do List”，我们一步步来实现它：

✅ Task 1: 确定“音量”大小 (设置 Log Level)

目标：决定我们是想听所有的废话（Debug），还是只听重要的事（Info/Error）。

  • 代码对应位置： python global _LOG_LEVEL if _LOG_LEVEL is None: LEVEL_MAP = { ... } # 定义等级字典 level = level or os.getenv("LOG_LEVEL", "").upper() # 优先读环境变量 _LOG_LEVEL = LEVEL_MAP.get(level, logging.INFO) # 默认是 INFO
  • 解释：这里在检查环境变量。如果你的系统里设置了 LOG_LEVEL=DEBUG，它就会把所有细节都打印出来；否则默认只打印 INFO 级别的信息。

✅ Task 2: 制作“身份证” (处理 Suffix/PID)

目标：当一条日志打印出来时，我不仅要看内容，还要知道是哪个文件、哪个进程打印的。

  • 代码对应位置： python if strip_file: suffix = os.path.basename(suffix) # 只保留文件名，不要长路径 if use_pid: pid = os.getpid() suffix = f"|pid={pid}{suffix}" # 把进程ID贴在屁股后面
  • 解释：这部分是在拼凑日志的前缀字符串。比如加上 |logger.py 或者 |pid=1234，这样出问题了好定位是谁干的。

✅ Task 3: 设计“皮肤” (ColorFormatter 类)

目标：给不同级别的日志上色。报错要红的，警告要黄的，正常信息要绿的，并且格式要整齐。

  • 代码对应位置： ```python class ColorFormatter(logging.Formatter): COLORS = { ... } # 定义颜色代码（比如 \033[36m 是青色）

    # 1. 格式化时间戳，加上之前的后缀
    timestamp = self.formatTime(record, "[%Y-%m-%d|%H:%M:%S{suffix}]")
    # ... (处理多卡 Rank 信息) ...
    # 2. 给级别名称（INFO, ERROR）上色

✅ Task 4: 识别“工号” (分布式/TP Info)

目标：在 AI 训练中，通常有多个显卡（GPU）同时工作。我们需要知道是 “几号显卡” 在说话。

  • 代码对应位置： python # 在 format 函数里 tp_info = tp_info or try_get_tp_info() # 尝试获取并行信息 if tp_info is not None ...: real_suffix = f"{suffix}|core|rank={tp_info.rank}" # 加上 rank=0, rank=1 等标记
  • 解释：如果你有 8 张卡，日志里会显示 rank=0, rank=7 等。这对于调试并行计算的 Bug 非常重要。

✅ Task 5: 清理现场并上岗 (初始化 Logger)

目标：把上面做好的格式应用到 Python 的标准 logger 上，并防止重复打印。

  • 代码对应位置： python logger = logging.getLogger(name) logger.handlers.clear() # 先清空以前的设置，防止一条日志打印两次 handler = logging.StreamHandler(sys.stdout) # 设置输出到屏幕 handler.setFormatter(formatter) # 穿上刚才设计的“彩色皮肤” logger.addHandler(handler) logger.propagate = False # 别把日志传给父级，我自己处理就好

    给 logger 绑上新功能

总结：最终效果

经过这个脚本处理后，当你在代码里写：

logger = init_logger("Model")
logger.info("Loading weights...")

屏幕上看到的不再是枯燥的文本，而是类似这样的（带颜色的）：

[2023-10-27|10:00:01|pid=999|rank=0] INFO Loading weights...

一句话总结： 这个文件就是为了给 minisgl 库配置一个带颜色、带时间戳、带进程号、带显卡编号，且支持“仅主进程打印”功能的日志工具。
