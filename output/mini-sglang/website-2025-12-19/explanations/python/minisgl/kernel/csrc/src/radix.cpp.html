Task 1：搞懂背景

文件名叫 radix.cpp，属于 minisgl。 * 背景：在大模型推理（比如 vLLM, SGLang）中，我们需要管理 KV Cache（缓存）。为了省显存和加速，我们需要知道：“新的 Prompt（提示词）和之前缓存过的 Prompt，前面有多少个 token 是一模一样的？” * 目的：这个文件就是为了极速算出两个 token 序列的最长公共前缀长度。 * 角色：它是一个“外挂”。Python 调用它，它在底层 C++ 跑完，把结果扔回给 Python。

Task 2：看懂保安（辅助函数）

代码里有一个函数 _is_1d_cpu_int_tensor。你可以把它看作是一个保安。

auto _is_1d_cpu_int_tensor(const tvm::ffi::TensorView tensor) -> bool {
  return tensor.ndim() == 1 &&              // 必须是1维数组（像个列表，不能是矩阵）
         tensor.is_contiguous() &&          // 内存必须是连续的（中间不能断开）
         tensor.device().device_type == kDLCPU && // 数据必须在 CPU 内存里（不能在显卡上）
         (tensor.dtype().code == kDLInt) && // 必须是整数（Token ID 都是整数）
         (tensor.dtype().bits == 32 || tensor.dtype().bits == 64); // 必须是32位或64位整数
}

解释： 如果不满足这些条件，保安就会拦住，防止后面的代码出错。因为这个算法只针对 CPU 上的整数列表设计。

Task 3：看懂核心任务

主函数是 fast_compare_key(a, b)。 它的逻辑是：给我两个数组 a 和 b，我来比比看。

  1. 安检： cpp host::RuntimeCheck(_is_1d_cpu_int_tensor(a) && ...); // 两个都得过安检 host::RuntimeCheck(a.dtype() == b.dtype()); // 两个的数据类型得一样
  2. 拿数据指针： cpp const auto a_ptr = a.data_ptr(); // 拿到数组 a 的内存起始地址 const auto b_ptr = b.data_ptr(); // 拿到数组 b 的内存起始地址
  3. 定长度： cpp const auto common_len = std::min(a.size(0), b.size(0)); 比如 a 长 100，b 长 50。那我们最多只能比前 50 个。多出来的没法比。

Task 4：理解“找不同”的神器（重点！）

这是全篇最核心的一句代码：std::mismatch。

代码根据是 64位 还是 32位 分了两个分支，逻辑是一样的，我们看 64位 的：

// 在 a 和 b 的范围内，找出第一个“不匹配”的位置
const auto diff_pos = std::mismatch(a_ptr_64, a_ptr_64 + common_len, b_ptr_64);

形象解释： 想象你有两条拉链（数组 A 和 数组 B）。 * std::mismatch 就像是你拉拉链的动作。 * 它从头开始，一个齿一个齿地比对。 * 只要两个齿咬合（数字相同），就继续往后拉。 * 一旦遇到两个齿不一样（数字不同），或者拉到了尽头，立刻停下。 * 它返回停下的那个位置的指针。

Task 5：理解返回结果

return static_cast<size_t>(diff_pos.first - a_ptr_64);

解释： * diff_pos.first 是拉链卡住的位置（指针地址）。 * a_ptr_64 是拉链的起始位置（指针地址）。 * 两者相减（地址相减），得到的就是中间隔了多少个数字。

举例： * 数组 A: [1, 2, 3, 4, 9, 9] * 数组 B: [1, 2, 3, 4, 5, 6] * 程序对比：1对，2对，3对，4对，9和5不对！停！ * 停在第 5 个位置（索引为 4）。 * 相减得到结果：4。 * 含义：这两个数组，前 4 个元素是一模一样的。

Task 6：总结价值

你可能会问：“这在 Python 里写个 for 循环不也行吗？”

# Python 写法
i = 0
while i < len(a) and i < len(b) and a[i] == b[i]:
    i += 1
return i

为什么要用 C++？ 1. 速度：在大模型推理中，Token 序列可能很长（几千甚至几万）。Python 的 while 循环非常慢，因为每一步都要做类型检查和解释器开销。C++ 的 std::mismatch 编译后是直接的机器码指令，甚至会利用 CPU 的 SIMD（单指令多数据）指令集并行比对，速度快几十倍甚至几百倍。 2. Radix Attention：这个文件名叫 radix，是因为它被用于一种叫 RadixAttention 的技术。这种技术把 KV Cache 组织成一棵前缀树。为了在树上找到当前 Prompt 能复用哪个节点，必须极快地计算“最长公共前缀”。

💡 最终总结（一句话人话版）

这个文件就是定义了一个 C++ 函数，它接收两个整数列表，用最快的速度从头开始比对，告诉你它们前面有多少个数字是一模一样的。
