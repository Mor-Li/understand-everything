python/minisgl/utils/arch.py

这份代码看起来全是技术术语，但其实它的核心逻辑非常简单。你可以把它想象成一个 “显卡型号检查员”。

它的作用就是：看看你电脑上的显卡（GPU）够不够新，能不能跑某些高级功能。

为了让你彻底理解，我为你列了一个 5步走的 Task List，我们一步一步来拆解：

📝 学习任务清单

Task 1: 理解背景 —— 为什么要查“版本”？

概念： 就像手机 App 会要求 “iOS 16 或以上版本” 才能安装一样，英伟达（NVIDIA）的显卡也有硬件架构的版本号，叫做 Compute Capability (计算能力)。 * 版本越高，显卡越新，支持的加速指令越多。 * 这个文件就是用来判断：你的显卡版本是多少？是否达到了运行代码的最低要求？

Task 2: 拆解核心函数 —— _get_torch_cuda_version

代码段：

@lru_cache(maxsize=None)
def _get_torch_cuda_version() -> Tuple[int, int] | None:
    # ...省略导入...
    if not torch.cuda.is_available() or not torch.version.cuda:
        return None
    return torch.cuda.get_device_capability()

讲解： 这是“检查员”的第一步动作：查户口。 1. torch.cuda.is_available(): 先看你有显卡吗？显卡能用吗？如果没有，直接返回 None（没查到）。 2. torch.cuda.get_device_capability(): 这是 PyTorch 的内置功能，它会告诉我们显卡的硬件版本。 * 比如你是 A100 显卡，它返回 (8, 0)。 * 比如你是 H100 显卡，它返回 (9, 0)。 3. @lru_cache: 这是一个 Python 小技巧（缓存）。意思是“查过一次就记在本子上”，下次再问这个函数，不用重新去问显卡了，直接报上次的答案。因为显卡型号插在电脑上是不会变的。

Task 3: 理解判断逻辑 —— is_arch_supported

代码段：

def is_arch_supported(major: int, minor: int = 0) -> bool:
    arch = _get_torch_cuda_version() # 拿到刚才查到的版本，比如 (8, 0)
    if arch is None:
        return False
    return arch >= (major, minor)

讲解： 这是“检查员”的第二步动作：比大小。 * 你给它一个要求的版本（比如 major=9），它拿你实际的显卡版本跟这个要求比。 * 逻辑： 如果 你的显卡版本 >= 要求版本，就返回 True（通过）；否则返回 False（不通过）。

Task 4: 具体的 VIP 通道 —— is_sm90_supported

代码段：

def is_sm90_supported() -> bool:
    return is_arch_supported(9, 0)

讲解： 这是具体的业务需求。SM90 是英伟达 Hopper 架构 (H100) 的代号。 * H100 显卡有一些超快的特异功能（比如 TMA）。 * 这段代码就是问：“你是 H100 (版本 9.0) 或更新的显卡吗？” * 如果是，程序后面可能会开启一些“极速模式”。

Task 5: 面向未来的通道 —— is_sm100_supported

代码段：

def is_sm100_supported() -> bool:
    return is_arch_supported(10, 0)

讲解： SM100 是英伟达下一代 Blackwell 架构 的代号（版本 10.0）。 * 这段代码是为未来准备的，判断显卡是不是比 H100 还要新的下一代卡。

总结

把这个文件翻译成人话，它就在干这三件事：

  1. 问显卡：“你的硬件版本号是多少？”（比如拿到 8.0 或 9.0）
  2. 提供一个通用工具：用来判断“当前显卡是否大于等于某个版本”。
  3. 定义了两个快捷方式：
    • is_sm90_supported: 你是 H100 级别的卡吗？
    • is_sm100_supported: 你是下一代 Blackwell 级别的卡吗？

目的： 为了让 minisgl 这个库能根据你的硬件强弱，自动决定是否开启某些只有新显卡才支持的高级加速功能。
