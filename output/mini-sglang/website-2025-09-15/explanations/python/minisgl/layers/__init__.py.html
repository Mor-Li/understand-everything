✅ Task 2: 理解“身份证”作用 (The Package Marker)

  • 问题：既然是空的，为什么还要创建它？
  • 解释：
    • 在 Python 中，文件夹通常只是文件夹。
    • 但是，一旦你在文件夹里放了一个 __init__.py 文件，Python 就会把这个文件夹看作一个 “包” (Package)。
    • 比喻：这就好比给一个普通的纸箱子贴上了“官方配件包”的标签。有了这个标签，Python 才能允许你使用 import 语句来调用里面的代码。
  • 实际效果：正是因为有了这个空文件，你才能在别的代码里写： python import minisgl.layers

✅ Task 3: 推测 layers 文件夹的含义 (Context)

  • 解释：
    • minisgl：通常指项目名称。
    • layers（层）：在深度学习或图形计算中，这个文件夹通常用来存放神经网络的层（比如全连接层 Linear、注意力层 Attention、激活函数 ReLU 等）。

✅ Task 4: 进阶 - 如果它“不空”会写什么？ (API Exposure)
