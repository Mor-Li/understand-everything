pyproject.toml

没问题，这个文件 pyproject.toml 其实就是这个 Python 项目的 “身份证” + “施工说明书”。

如果把这个项目比作盖一栋大楼，这个文件就是告诉包工头（Python 工具链）：这楼叫啥、用啥材料、工人守则是什么、怎么验收。

为了让你更容易理解，我把它拆解成一个 5步走的任务清单 (To-Do List)，我们一步步来看这个文件到底在安排什么任务。

📋 任务清单：从零构建 minisgl 项目

✅ Task 1: 确立项目身份与基础需求 (我是谁？我需要什么？)

对应代码段： [build-system], [project]

这一部分是给 Python 打包工具（如 pip）看的。

  • 设定名字与版本：
    • 项目名叫 minisgl，版本是 0.1.0。
  • 设定运行环境：
    • 必须用 Python 3.10 或更高的版本 (requires-python = ">=3.10")。
  • 列出“必需原材料” (Dependencies)：
    • 要运行这个项目，电脑里必须先安装好这几个库：accelerate（加速计算）, msgpack（序列化）, sglang（核心依赖）, torch（PyTorch深度学习）, transformers（HuggingFace模型库）。
    • 潜台词：没这些材料，这程序跑不起来。

✅ Task 2: 告诉程序源码藏在哪里 (寻宝地图)

对应代码段： [tool.setuptools.packages.find], [tool.setuptools.package-dir]

通常代码放在根目录，但这个项目有点不一样。

  • 指路：
    • 告诉打包工具：“嘿，不要在根目录乱找，我的源代码都在 python 这个文件夹里面。”
    • where = ["python"] 和 "" = "python" 就是在做这个路径映射。

✅ Task 3: 招聘“开发人员”需要的额外工具 (装备升级)

对应代码段： [project.optional-dependencies] -> dev

这一部分是给开发者（也就是看代码的你）准备的，普通用户不需要。

  • 安装开发大礼包：
    • 如果你想参与修改代码，你需要安装 dev 这一组工具。
    • 里面包含了：pytest（做测试的）、black（自动排版的）、ruff（找茬挑错的）、mypy（检查类型的）。

✅ Task 4: 制定“代码家规” (格式与纪律)

对应代码段： [tool.black], [tool.ruff], [tool.mypy]

这是为了防止不同程序员写出的代码风格迥异，强制规定的“家规”。

  • 排版家规 (Black)：
    • 一行代码最长不能超过 100 个字符 (line-length = 100)。
    • 必须适配 Python 3.10 的语法。
  • 纠错家规 (Ruff)：
    • 这是一个非常快的新型代码检查工具。
    • 它配置了要检查哪些类型的错误（比如 W 警告, F 错误），同时也忽略了一些烦人的错误（比如 E501 行太长，因为上面 Black 已经管了）。
  • 类型家规 (Mypy)：
    • 这是最严格的“教导主任”。它要求代码必须写清楚变量类型（是整数还是字符串？）。
    • disallow_untyped_defs = true：意思是不允许定义函数时不写类型注解。
    • 但是，对于 torch 和 transformers 这些外部库，如果不写类型就算了（ignore_missing_imports = true），放过它们。

✅ Task 5: 设定“考试标准” (自动化测试)

对应代码段： [tool.pytest.ini_options]

写完代码必须考试（测试），这里规定了考试怎么考。

  • 考场位置：
    • 测试题都在 tests 文件夹里 (testpaths = ["tests"])。
  • 判卷标准：
    • 还要计算“覆盖率” (--cov=minisgl)，也就是看你的测试代码是不是把项目里的每一行代码都跑了一遍，最后生成一个 HTML 报告给你看。

📝 总结一下

如果你拿到了这个项目，这文件告诉了你：

  1. 安装：你需要 pip install .，它会自动装上 PyTorch 等依赖。
  2. 开发：如果你要改代码，运行 pip install .[dev] 把测试工具装上。
  3. 贡献：你写的代码必须符合 100 字符宽度的限制，并且通过 mypy 的严格类型检查，否则“家规”伺候（报错）。
  4. 结构：别去根目录找核心代码，去 python/ 文件夹里找。
