src/llmtuner/tuner

这里是 src/llmtuner/tuner 文件夹的“高层认知”说明。

如果不把这个文件夹看作代码，而是看作一个实体机构，那么它就是 “AI 训练总基地”。

所有关于“怎么训练模型”、“用什么方法训练”、“训练流程如何跑通”的核心逻辑，全部都汇聚在这里。

1. 🏢 这个文件夹主要负责什么？

核心职责：调度和执行各种训练任务。

如果 llmtuner 是一个大工厂，那么 tuner 文件夹就是 “生产车间”。 不管你是想让模型背书（预训练）、学说话（微调）、还是学做人（强化学习），所有的流水线启动开关和核心工艺都在这里。

2. 📄 直接文件的作用

在这个层级下，只有一个核心的直接文件：__init__.py。

  • __init__.py (总控制台 / 课程表)
    • 作用：它本身不干重活，它的作用是对外提供接口。
    • 比喻：它是训练基地的 “前台接待处”。
    • 当你从外面喊一句“我要开始 SFT 训练！”时，实际上是这个文件在接待你，然后把你指引到 sft 那个子房间去。它把深藏在各个子文件夹里的 run_pt（跑预训练）、run_sft（跑微调）等功能提取出来，让你能直接调用。

3. 📁 子文件夹的作用 (概括)

这里的子文件夹可以分为 “后勤部” 和 “四大训练营”：

🔧 后勤保障

  • core/ (核心基建部)
    • 作用：这是所有训练任务共享的基础设施。
    • 比喻：这是管水电煤和发课本的部门。不管你上什么课（SFT还是PPO），都需要这里提供的功能：加载数据（Loader）、解析参数（Parser）、适配器管理（Adapter）。没有它，其他训练营都开不了张。

🏫 四大训练营 (具体的训练模式)

  • pt/ (Pre-Training / 知识注入营)
    • 作用：增量预训练。
    • 比喻：图书馆。让模型安安静静地读大量专业书籍，只为了增加知识储备。
  • sft/ (Supervised Fine-Tuning / 技能培训营)
    • 作用：有监督微调。
    • 比喻：问答教室。老师拿着标准答案教模型：“听到这句，你要回那句”。这是让模型学会聊天的关键。
  • rm/ (Reward Modeling / 考官培训营)
    • 作用：奖励模型训练。
    • 比喻：裁判进修班。不是训练运动员，而是训练一个能打分的裁判（判别模型），教它什么是好回答，什么是坏回答。
  • ppo/ (PPO / 特种兵集训营)
    • 作用：强化学习优化。
    • 比喻：实战演练场。利用上面训练出来的“裁判”给模型打分，通过奖惩机制（强化学习），逼迫模型进化出更符合人类偏好的回答。

4. 🧠 高层认知：一句话理解这个目录

src/llmtuner/tuner 是大模型成长的“全套流水线”。

  • core 搭台子。
  • pt 练内功（学知识）。
  • sft 练招式（学会对话）。
  • rm 和 ppo 练心法（对齐人类价值观）。
  • __init__.py 则是启动这些流水线的总开关。
