src/llmtuner/tuner/sft

欢迎来到 src/llmtuner/tuner/sft 目录！这里是整个大模型微调工程中最热门、最核心的部门——有监督微调（SFT）特训营。

如果说预训练是让模型“读万卷书”（通识教育），那么这里就是让模型“行万里路”（职业培训）。

下面我用最通俗的比喻带你认识这里：

1. 这个文件夹主要负责什么？(核心功能)

这里是“模拟考试特训班”。

  • 功能：SFT (Supervised Fine-Tuning) 的核心任务是教模型“说人话”。
  • 场景：在这个目录下，我们不教模型新的物理公式或历史知识，而是拿出一堆“问题+标准答案”的试卷，训练模型学会：当用户发出指令时，该用什么样的语气、格式和逻辑去回答。
  • 一句话：这里负责把一个“博学但木讷”的书呆子模型，训练成一个“懂指令、会干活”的智能助手。

2. 直接文件的作用 (分工介绍)

根据你提供的列表，这里有两个核心文件，它们分别扮演了“接待员”和“阅卷老师”的角色。

📄 __init__.py —— 接待员 / 启动按钮

  • 角色：门口的接待处。
  • 干了啥：它只有一行代码，但这行代码是一个指向标。它告诉外部想用 SFT 功能的人：“嘿，如果你想开始微调（run_sft），不用到处乱找，我已经在后台帮你联系好具体干活的流程了，你直接按这个按钮就行。”
  • 通俗理解：它是 SFT 功能的快捷方式图标。

📄 metric.py —— 阅卷老师 / 评分机器

  • 角色：极其严格的阅卷老师。
  • 干了啥：当模型在训练过程中尝试回答问题时，这个文件负责给模型打分。
    • 它先把模型生成的“数字编码”翻译成“汉字”。
    • 用“结巴分词”把句子切开。
    • 拿着模型的答案和标准答案逐字逐句对比。
    • 最后给出 ROUGE（查重率，看你写全了没）和 BLEU（精准度，看你写对了没）两个分数。
  • 通俗理解：它是用来衡量模型学得好不好的尺子。

4. 高层认知 (一图胜千言)

你可以把这个文件夹想象成一个 “封闭式刷题班”：

  1. 外部调用 (__init__.py)：用户在外面喊了一句“开始特训！”，通过这个文件启动流程。
  2. 核心训练 (隐含的 workflow)：模型开始疯狂做题，看问题，写答案，改参数。
  3. 质量检测 (metric.py)：每做完一套题，阅卷老师就出来打分：“这次只考了 30 分，ROUGE 分数太低，继续练！”或者“不错，BLEU 分数很高，可以毕业了！”

总结： 这部分代码就是大模型微调流水线上的“指令微调”车间，负责让模型学会听懂人类的命令，并配备了专门的评分员来监控学习效果。
