src/llmtuner/tuner/sft/metric.py

没问题，这段代码对于初学者来说确实比较抽象，因为它涉及到了模型评估（Evaluation）的具体实现细节。

你可以把这段代码想象成一个“阅卷老师”。它的工作是：拿到模型写的“答案”和标准答案，然后打分，看看模型考了多少分。

我们把这个过程拆解成一个 6步的 To-Do List，一步一步带你看懂它在干什么。

📝 任务清单：阅卷流程

✅ Task 1: 明确身份与输入

代码位置：

@dataclass
class ComputeMetrics:
    tokenizer: PreTrainedTokenizer
    def __call__(self, eval_preds: ...):
        preds, labels = eval_preds

解读： * 身份：这个类叫 ComputeMetrics（计算指标），就是阅卷老师。 * 工具：它手里拿着一本字典（tokenizer），用来把数字翻译成文字。 * 输入：__call__ 是开始阅卷的命令。传入的 eval_preds 包含两样东西： 1. preds：学生考卷（模型生成的预测结果，是一堆数字ID）。 2. labels：标准答案（正确的结果，也是一堆数字ID）。

✅ Task 2: 清洗“脏”数据

代码位置：

preds = np.where(preds != IGNORE_INDEX, preds, self.tokenizer.pad_token_id)
labels = np.where(labels != IGNORE_INDEX, labels, self.tokenizer.pad_token_id)

解读： * 问题：在训练模型时，为了提高效率，我们会用一个特殊数字（IGNORE_INDEX，通常是-100）来填充空白或者标记不需要计算的地方。这些数字如果直接拿去翻译，程序会报错。 * 操作：这两行代码在做替换。 * 如果不等于 IGNORE_INDEX，保持原样。 * 如果等于 IGNORE_INDEX，把它替换成 pad_token_id（空白占位符）。 * 目的：把无法识别的“脏数据”变成可以被忽略的“空白符”，防止程序崩溃。

✅ Task 3: 将“数字”翻译成“人话”

代码位置：

decoded_preds = self.tokenizer.batch_decode(preds, skip_special_tokens=True)
decoded_labels = self.tokenizer.batch_decode(labels, skip_special_tokens=True)

解读： * 现状：目前的 preds 和 labels 还是计算机认识的数字（比如 [101, 234, 987]）。 * 操作：调用分词器的 batch_decode（批量解码）功能。 * 结果：把数字变成了人类能读懂的文本字符串（比如 "今天天气不错"）。skip_special_tokens=True 表示去掉那些系统专用的符号（如 <EOS>, <PAD>），只留纯文本。

✅ Task 4: 给中文分词 (切菜)

代码位置：

for pred, label in zip(decoded_preds, decoded_labels):
    hypothesis = list(jieba.cut(pred))
    reference = list(jieba.cut(label))

解读： * 难点：英文单词之间有空格（"I love AI"），很容易拆分。但中文是连在一起的（"我爱人工智能"）。如果不切分开，很难对比两个句子像不像。 * 工具：jieba 是 Python 中最著名的中文分词库。 * 操作： * pred (学生写的): "我爱人工智能" -> jieba -> ['我', '爱', '人工智能'] * label (标准答案): "我喜欢AI" -> jieba -> ['我', '喜欢', 'AI'] * 目的：把句子变成单词列表，为下一步打分做准备。

✅ Task 5: 核心打分 (ROUGE 和 BLEU)

这是最关键的一步，计算两个指标。

A. ROUGE 分数 (查重率) 代码位置：

rouge = Rouge()
scores = rouge.get_scores(" ".join(hypothesis), " ".join(reference))
# ... (存入 score_dict)
  • 含义：ROUGE 主要看召回率。也就是“标准答案里的词，你写出来了多少？”
  • 细节：
    • rouge-1：看单个词重合度。
    • rouge-2：看连续两个词的重合度。
    • rouge-l：看最长公共子句。
  • 逻辑：它把刚才切好的词用空格拼回去（模拟英文格式），然后算出相似度分数。

B. BLEU 分数 (精准度) 代码位置：

bleu_score = sentence_bleu([list(label)], list(pred), smoothing_function=...)
  • 含义：BLEU 主要看精确度。也就是“你写的词里，有多少是对的？”
  • 注意：这里用了 list(pred)，在 Python 里这会把字符串拆成单个字符（例如 ['我', '爱', '人', ...]）。这算的是字级别的 BLEU-4 分数。

✅ Task 6: 计算全班平均分并交卷

代码位置：

return {k: float(np.mean(v)) for k, v in score_dict.items()}

解读： * 现状：score_dict 里存的是每一个样本的分数（比如你有32个样本，里面就有32个 ROUGE-1 分数）。 * 操作：np.mean(v) 计算平均值。 * 结果：返回一个字典，告诉训练器这一批数据（Batch）的平均表现如何。 * 例如：{"rouge-1": 45.2, "bleu-4": 30.5, ...}

💡 总结

这个文件的逻辑就是： 1. 拿卷子（接收模型输出和标签）。 2. 涂改液（把无效的 -100 替换成 pad）。 3. 翻译（数字转文字）。 4. 切词（用结巴分词把中文切开）。 5. 打分（用 ROUGE 算你覆盖了多少答案，用 BLEU 算你写得准不准）。 6. 算平均（算出这一批数据的最终得分）。
