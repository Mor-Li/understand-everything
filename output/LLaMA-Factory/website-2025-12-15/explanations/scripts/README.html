scripts

这是一个非常形象的类比。如果把 LlamaFactory 的核心代码比作一个“全自动化造车工厂”（负责训练模型），那么 scripts/ 目录就是工厂旁边的“特种维修与改装车间”。

这里面的工具不负责“常规生产流水线”（常规训练），而是负责干杂活、做改装、测性能、搞特种作业的。

以下是这个目录的高层认知图谱：

1. 📂 核心功能：这里是干嘛的？

一句话总结：这里存放了一堆独立的“单兵作战武器”脚本。

当你需要做以下事情时，你会来这里找工具： * 想把模型切碎了给几百张显卡跑，或者把切碎的模型拼回来。 * 想给模型做个特殊手术（比如 PiSSA、LoftQ 初始化）再送去训练。 * 想给模型加盖楼层（LlamaPro）让它变大。 * 训练完了，想测测速度，或者自动改卷子打个分。 * 想用最快速度跑推理（vLLM）。

2. 📄 直接文件：特种工兵点名

这些直接放在根目录下的 .py 文件，每一个都是身怀绝技的“特种工兵”：

🛠️ 模型改装与手术（训练前准备）

  • llama_pro.py（楼层扩建队）：
    • 作用：把一个小模型（如 7B）像拉面一样拉长，在中间插入新层变成大模型（如 9B），为 LLaMA-Pro 训练做准备。
  • loftq_init.py（精细压缩师）：
    • 作用：为了省显存，先把模型压缩（量化），但为了不丢细节，它通过数学计算预先生成一个“补偿补丁”（LoRA），让起跑线更高。
  • pissa_init.py（外科手术刀）：
    • 作用：把模型拆成“主干”和“精华插件”（PiSSA），让你训练时只练精华，收敛更快。

🔄 格式转换与拼接（搬运工）

  • megatron_merge.py（切蛋糕/拼蛋糕大师）：
    • 作用：在 HuggingFace（通用完整版）和 Megatron（分布式切片版）格式之间互转。要么把模型切碎了给集群吃，要么把碎块拼回来给人用。
  • qwen_omni_merge.py（器官移植医生）：
    • 作用：专门针对 Qwen-Omni 模型。因为训练时把“嘴巴”（语音部分）弄丢了，这个脚本负责把训练好的“大脑”和原厂的“嘴巴”缝合回去。

🏎️ 性能测试与推理（试车手）

  • bench_qwen.py（极限测速仪）：
    • 作用：造一堆假数据，把 Qwen2-VL 模型推到极限，单纯为了看显卡跑得有多快、显存吃得有多满。
  • vllm_infer.py（极速流水线）：
    • 作用：使用 vLLM 引擎，以最快的速度让模型批量做题（推理），支持图文视频多模态。

📝 评分与阅卷（教导主任）

  • eval_bleu_rouge.py（自动阅卷机）：
    • 作用：拿模型的作业和标准答案对比，计算 BLEU（准不准）和 ROUGE（全不全）分数。

3. 📁 子文件夹：外包部门

这些文件夹里的东西已经分门别类整理好了：

  • 📁 api_example/（使用说明书）：
    • 作用：放了一些简单的 Python 脚本，教你怎么通过代码调用训练好的模型接口。
  • 📁 convert_ckpt/（旧车翻新厂）：
    • 作用：专门负责把其他格式的模型权重（比如原版 Baichuan、Qwen 的旧权重）转换成 LlamaFactory 能识别的标准格式。
  • 📁 stat_utils/（数据分析室）：
    • 作用：一堆计算器。用来算模型算力（FLOPs）、学习率（LR）、困惑度（PPL）或者统计数据长度分布。

4. 🧠 高层认知：如何快速理解？

如果把 src/ 目录看作是 “主菜”（训练核心逻辑），那么 scripts/ 目录就是 “餐具和调料”。

  • 你不需要每次都用到这里所有的脚本。
  • 大部分时候，你可能只会用到 vllm_infer.py（跑结果）和 eval_bleu_rouge.py（算分）。
  • 特殊时候，如果你要搞大规模集群训练（Megatron），或者搞学术创新（PiSSA/LlamaPro），这里的脚本就是你的救命稻草。

简单说：这里是 LlamaFactory 的“瑞士军刀”集合，平时挂在腰上不占地，关键时刻能解决棘手的技术难题。
