scripts/convert_ckpt/llamafy_qwen.py

这份代码的核心作用可以用一句话概括：“把 Qwen（通义千问）模型的格式，强行修改成 Llama（羊驼）模型的格式。”

为什么要这么做？因为 Llama 生态最成熟，很多工具、推理引擎只支持 Llama 结构。把 Qwen “伪装”成 Llama，就能直接用那些工具了。

下面我把这个脚本的工作流程拆解成一个 Task List (待办事项清单)，带你一步步看它是怎么完成“整容手术”的。

📋 任务清单：Qwen 到 Llama 的整容手术

这个脚本主要执行了以下 5 个 Task：

  1. 【准备工作】：检查环境，创建输出文件夹。
  2. 【读取旧模型】：把 Qwen 的原始权重文件（.safetensors）全部加载到内存。
  3. 【核心手术：权重转换】：遍历每一个权重参数，改名（重命名变量）并重组（切割或合并矩阵），使其符合 Llama 的命名规范。
  4. 【保存新模型】：把改好名的数据切片，保存为新的权重文件。
  5. 【修改身份证：配置文件】：读取 Qwen 的 config.json，修改参数名，另存为 Llama 格式的配置。

🧐 详细步骤讲解

Task 1: 准备工作 (Setup)

  • 代码位置：llamafy_qwen 函数 (脚本最下方)。
  • 动作：
    • 你运行命令时传入 input_dir (Qwen路径) 和 output_dir (新路径)。
    • 脚本检查 output_dir 是否存在，不存在就创建。

Task 2: 读取旧模型 (Load Weights)

  • 代码位置：save_weight 函数的开头部分。
  • 动作：
    • 它会扫描你输入文件夹里的所有 .safetensors 文件。
    • 使用 safe_open 把里面的权重数据（Tensor）全部读出来，存到一个大字典 qwen_state_dict 里。
    • 此时内存里装的是原汁原味的 Qwen 数据。

Task 3: 核心手术 (Convert Format)

这是最复杂的一步，对应代码中长长的 for key, value in ... 循环。它在做字典映射。

  • 原理：

    • Qwen 的参数叫 transformer.h...，Llama 的参数叫 model.layers...。
    • Qwen 的 Attention 层把 Q、K、V 三个矩阵拼在一起存，Llama 是分开存的。

  • 具体操作 (TODO List)：

    1. 词表层 (wte)：改名为 model.embed_tokens.weight。
    2. 最终归一化层 (ln_f)：改名为 model.norm.weight。
    3. 注意力层 (Attention)：
      • 遇到 attn.c_attn (Qwen 把 QKV 拼在一起)：
        • 切一刀：把矩阵除以3，切成三份。
        • 分别改名为 self_attn.q_proj, self_attn.k_proj, self_attn.v_proj。
      • 遇到 attn.c_proj (输出层)：改名为 self_attn.o_proj。
    4. 层归一化 (LayerNorm)：
      • ln_1 -> 改名 input_layernorm (输入前的 Norm)。
      • ln_2 -> 改名 post_attention_layernorm (注意力后的 Norm)。
    5. 前馈网络 (MLP)：
      • mlp.w1 -> mlp.up_proj
      • mlp.w2 -> mlp.gate_proj
      • mlp.c_proj -> mlp.down_proj
    6. 输出头 (lm_head)：名字不用改，直接保留。

Task 4: 保存新模型 (Save Weights)

  • 代码位置：save_weight 函数的后半部分。
  • 动作：
    • 由于模型可能很大（比如 14GB），不能存成一个巨型文件。
    • split_torch_state_dict_into_shards：这个工具负责把刚才改好名的大字典，切分成几个小块（Shard），比如每块 2GB。
    • save_file 或 torch.save：把这些小块写入硬盘。
    • 生成索引文件（model.safetensors.index.json），告诉程序哪个参数在哪个文件里。

Task 5: 修改身份证 (Save Config)

  • 代码位置：save_config 函数。
  • 动作：
    • 读取旧的 config.json。
    • 创建一个新的字典 llama2_config_dict。
    • 关键修改：
      • architectures: 强制改成 ["LlamaForCausalLM"] (告诉 Transformers 库：我是 Llama)。
      • model_type: 改成 "llama"。
      • num_key_value_heads: 计算一下 KV heads 的数量（Qwen 和 Llama 计算方式略有不同）。
      • intermediate_size: 这里的 // 2 是因为 Qwen 的原始配置里为了兼容某些旧逻辑写大了，转成 Llama 标准格式时需要除以 2 才能对齐参数量。
    • 最后把这个新字典存为 config.json。

总结

这脚本就是一个翻译器。

  • 输入：讲“Qwen 方言”的模型。
  • 过程：
    1. 把变量名翻译成“Llama 普通话”。
    2. 把连在一起的 QKV 矩阵拆散。
    3. 把配置文件里的“身份证号”改成 Llama。
  • 输出：一个看起来完全像 Llama，但核心权重依然是 Qwen 训练出来的模型。
