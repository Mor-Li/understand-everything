scripts/llama_pro.py

这份代码其实在做一件非常有意思的事情，叫做 “模型层拓展” (Block Expansion)，其核心思想源自 LLaMA-Pro 这篇论文。

简单来说，它的目的是：把一个训练好的小模型（比如 7B），通过“插队”的方式塞进去一些新层，把它变成一个更大的模型（比如 9B），然后只训练这些新层，让模型变聪明。

为了让你听懂，我把这个代码的逻辑拆解成一个 “施工队改造大楼” 的 ToDo List。

🛠️ 任务清单：如何给大模型“加盖”楼层

假设原来的模型是一栋 32层 的大楼（Llama-2-7b），我们要给它新增 8层（num_expand=8），变成 40层。

✅ Step 1: 施工前核算 (配置检查)

  • 代码对应： block_expansion 函数开头部分。
  • 动作：
    1. 读取原大楼图纸（config）。
    2. 计算原来的层数（32层）。
    3. 算术检查： 32层能不能被新增的8层整除？（32 / 8 = 4）。这意味着：每隔 4 层旧楼层，就要插入 1 层新楼层。
    4. 修改图纸：把总层数从 32 改成 40，保存新图纸。

✅ Step 2: 准备材料 (加载模型)

  • 代码对应： tokenizer 和 model 的加载部分。
  • 动作：
    1. 把原来的模型权重（state_dict）全部搬到内存里。
    2. 准备一个空的列表（output_state_dict），用来存放新的40层大楼的权重。

✅ Step 3: 逐层盖楼与“插队” (核心逻辑)

  • 代码对应： for i in range(num_layers): 循环部分。

  • 动作： 这是一个循环，从第0层走到第31层（原模型）。

    • 动作 A (搬运旧层)：

      • 拿到原模型的第 i 层。
      • 给它改个名字（重编号），比如原来的第0层还是第0层，但原来的第5层可能因为前面插了队，变成了第6层。
      • 直接把参数复制过去。

    • 动作 B (判断是否插入新层)：

      • 逻辑： if (i + 1) % split == 0:
      • 如果当前层数是 4 的倍数（比如第4层、第8层...），就在这里插入一层全新的楼层。

✅ Step 4: 装修新楼层 (零初始化技巧)

  • 代码对应： if "down_proj" in key or "o_proj" in key:
  • 这是最关键的一步！ 新插入的这一层，参数从哪来？
    • 大部分参数（Attention, MLP的输入部分）： 直接 复制 上一层的参数（torch.clone）。
    • 输出参数（down_proj, o_proj）： 全部 设为 0 (torch.zeros_like)。
  • 为什么这么做？
    • 如果输出是0，那么这一层对数据的影响就是“没有影响”（输出为0，加到残差连接上还是原样）。
    • 这意味着：刚改造完还没训练时，这栋40层大楼的功能和原来32层大楼一模一样，完全不会报错或乱说话。 这为后续训练打下了完美的基础。

✅ Step 5: 补全其他设施 (非层参数)

  • 代码对应： 循环结束后的 for key, value in state_dict.items():
  • 动作： 楼层盖好了，别忘了大楼的“地基”（Embedding层）和“楼顶”（LM Head / Norm层）。把这些没动过的参数原封不动地搬进新模型。

✅ Step 6: 验收与存档 (保存模型)

  • 代码对应： split_torch_state_dict_into_shards 和 save_file。
  • 动作：
    1. 因为模型变大了，一个文件存不下，需要切分成碎片（Shards）。
    2. 保存为 .safetensors 或 .bin 格式。
    3. 生成索引文件（index json），告诉加载器哪个参数在哪个文件里。

✅ Step 7: 留下说明书 (打印训练指南)

  • 代码对应： 最后几个 print。
  • 动作： 告诉用户：
    • “新模型做好了！”
    • “你去微调的时候，记得选 freeze 模式。”
    • “只训练我新加的那 8 层 (freeze_trainable_layers: 8)，旧的层冻结别动。”

总结

这段代码在干嘛？ 它在做一个“无损扩容”。它把一个 Llama 模型像拉面一样拉长了，在中间均匀地插入了新层。

新层有什么特点？ 新层的输出权重被初始化为 0。这保证了扩容后的模型在微调之前，表现和原模型完全一致（这就是所谓的 Identity Initialization）。

之后要做什么？ 你需要拿着这个输出的新模型路径，去进行微调训练。训练时，原有的知识（旧层）会被冻结保留，模型会利用新插入的层去学习新的知识（比如特定领域的知识）。这就是 LLaMA-Pro 的核心玩法。
