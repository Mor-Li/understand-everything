scripts/eval_bleu_rouge.py

这份代码其实是一个“自动阅卷机”。

它的主要作用是：当你训练好一个 AI 模型，让它做了一些题目（比如翻译或文本摘要）后，这个脚本用来给模型的答案打分。它使用了两个最经典的评价指标：BLEU 和 ROUGE。

为了让你更容易理解，我把它拆解成一个 “阅卷老师的任务清单 (To-Do List)”，一步步带你看它是怎么工作的。

阅卷老师的任务清单 (Task List)

  1. 准备工具箱 (导入必要的打分工具库)
  2. 收取考卷 (读取包含“模型预测”和“标准答案”的文件)
  3. 制定评分标准 (定义具体的打分函数 compute_metrics)
    • 3.1 分词处理 (把句子切开)
    • 3.2 计算 BLEU 分数 (看写对了多少)
    • 3.3 计算 ROUGE 分数 (看覆盖了多少)
  4. 开始批量阅卷 (多线程并行处理所有数据)
  5. 计算平均分并公布成绩 (汇总结果并保存文件)

详细步骤讲解

Task 1: 准备工具箱 (Imports & Setup)

代码一开始引入了一堆库，你可以理解为阅卷老师在桌子上摆好了红笔、计算器和参考书。 * jieba: 这是一个中文分词工具。因为中文没有空格，电脑看不懂“我爱你”，需要切分成“我/爱/你”才能处理。 * nltk (BLEU): 用来计算 BLEU 分数，通常用于机器翻译评价。 * rouge_chinese: 用来计算 ROUGE 分数，通常用于文本摘要评价。

Task 2: 收取考卷 (Main Function Start)

对应代码：def main(filename): ... load_dataset(...) * 脚本接收一个 filename（文件名）。 * 这个文件里存着成千上万条数据，每一条都有两个关键字段： * predict: 考生的答案（模型生成的文本）。 * label: 标准答案（人工写的正确文本）。

Task 3: 制定评分标准 (Core Logic: compute_metrics)

这是代码最核心的部分。对于每一道题（每一个样本 sample），它都要做以下几件事：

  • 3.1 分词处理 (Tokenization)

    • 代码用 jieba.cut 把考生的答案和标准答案都切碎成词语列表。
    • 目的：为了让 ROUGE 算法能对比词语的重合度。

  • 3.2 计算 BLEU 分数 (Precision 导向)

    • 对应代码：sentence_bleu(...)
    • 核心逻辑：它把句子拆成单个字（list(sample["predict"])），然后看考生的答案里，有多少字（或字组）是出现在标准答案里的。
    • 通俗理解：考生的翻译准不准确？是不是在胡编乱造？
    • 注意：这里算的是 BLEU-4，意味着它不仅看单个字，还看连续的4个字是否匹配。

  • 3.3 计算 ROUGE 分数 (Recall 导向)

    • 对应代码：rouge.get_scores(...)
    • 核心逻辑：它对比分词后的列表，计算三个指标：
      • rouge-1: 单个词的重合度。
      • rouge-2: 连续两个词的重合度。
      • rouge-l: 最长公共子序列（句子结构像不像）。
    • 通俗理解：考生的答案全不全？标准答案里的要点，你是不是都写出来了？

  • 3.4 格式化分数

    • 最后把所有算出的小数（比如 0.85）乘以 100（变成 85.0），保留4位小数，方便阅读。

Task 4: 开始批量阅卷 (Parallel Processing)

对应代码：dataset.map(compute_metrics, num_proc=8, ...) * 如果有 10,000 道题，一道道算太慢了。 * num_proc=8 的意思是：雇佣 8 个阅卷老师同时改卷。这叫多进程并行处理，能极大提高速度。

Task 5: 计算平均分并公布成绩 (Aggregation & Output)

对应代码：for task, scores in ... 及之后 * 算总分：所有题目的分数算出来后，代码会按指标分类（BLEU-4, ROUGE-1 等）。 * 求平均：sum(scores) / len(scores)，计算出模型在整套试卷上的平均表现。 * 打印成绩单：在屏幕上打印出类似 rouge-l: 45.2312 的结果。 * 存档：最后把结果写入 predictions_score.json 文件，方便你以后查看或画图表。

总结

这就好比一次全自动的语文考试评分： 1. 输入：包含模型生成文本的文件。 2. 过程：切词 -> 算 BLEU (准不准) -> 算 ROUGE (全不全) -> 8线程加速。 3. 输出：一个 JSON 文件，告诉你这个模型到底考了多少分。
