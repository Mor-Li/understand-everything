pyproject.toml

这份文件 pyproject.toml 对于 Python 项目来说，就像是一个“项目的身份证 + 施工说明书”。它不是用来运行的代码，而是用来告诉电脑（和其他程序员）这个项目叫什么、怎么安装、代码风格要长什么样。

别被那些奇怪的缩写（如 C408, E501）吓到。为了让你看懂，我为你制定了一个 “从小白到看懂配置”的 4 步学习清单 (Task To-Do List)。

我们一步一步把这个文件拆解开：

📝 Task 1: 搞清楚“我是谁”和“怎么安装我”

目标： 理解文件的基础身份信息。 对应代码段： [build-system] 和 [project]

这部分是给 Python 安装工具（比如 pip）看的。

  • [build-system] (施工队):
    • requires = ["setuptools>=61.0"]: 这行代码说：“要想安装我，你的电脑里必须先有 setuptools 这个工具，而且版本要新（大于61.0）。”
    • build-backend: 指定了具体的“施工队长”是 setuptools。
  • [project] (身份证):
    • name = "llamafactory": 项目的名字叫 LLaMA Factory。
    • requires-python = ">=3.9.0": 必须用 Python 3.9 或更高版本才能运行。
    • dynamic = [...]: 这里列出了一堆东西（比如版本号 version、依赖包 dependencies）。意思就是：“这些信息我不在这个文件里写死，你去别的地方（比如代码里或 requirements.txt）读取。” 这是一种灵活的写法。

🧹 Task 2: 设定“代码纪律委员” (Ruff 基础设置)

目标： 理解代码风格检查工具 Ruff 的基本规则。 对应代码段： [tool.ruff]

Ruff 是一个现在非常火的工具，用来检查代码写得规不规范。这部分就像是给程序员定的“家规”。

  • target-version = "py39": 检查代码时，假设是运行在 Python 3.9 环境下的。
  • line-length = 119: 家规第一条，一行代码最长不能超过 119 个字符，太长了要换行。
  • indent-width = 4: 家规第二条，缩进必须是 4 个空格（Python 的标准）。

🚫 Task 3: 设定“可以无视的警告”和“必须遵守的规则”

目标： 理解 Ruff 的详细过滤规则。 对应代码段： [tool.ruff.lint]

这部分最长，也最容易让人晕，其实它就是一堆“开关”。

  • ignore = [...] (白名单/睁一只眼闭一只眼):
    • 这里列出了一堆代码，比如 E501 (行太长)、D100 (缺少文档)。
    • 意思就是：Ruff 检查员，虽然标准规定要写文档、行不能太长，但在这个项目里，请你忽略这些问题，不要报错。
  • extend-select = [...] (必须检查的项目):
    • 这里列出了 E (错误), W (警告), I (导入排序) 等。
    • 意思就是：除了默认检查的，你还要额外帮我检查这些类型的错误。
  • [tool.ruff.lint.isort] (整理收纳):
    • 这是专门管 import (导入包) 顺序的。它规定了哪些是“自家的包” (llamafactory)，哪些是“第三方的包” (torch, transformers 等)，并且要求它们按顺序排好，中间空两行。

🚦 Task 4: 设定“交通规则” (UV 依赖冲突)

目标： 防止安装了不兼容的软件。 对应代码段： [tool.uv]

uv 是一个比 pip 更快的安装工具。这部分定义了互斥关系。

  • conflicts (不共戴天):
    • 代码里列出了几组“死对头”。
    • 例如： toml [ { extra = "torch-npu" }, # 华为昇腾 NPU 的支持包 { extra = "vllm" }, # 一个显存优化库 ]
    • 意思就是：用户不能同时安装 torch-npu 和 vllm 这两个功能。二者选其一，因为它们在一起会打架（不兼容）。
    • 同理，它也规定了 sglang 和其他包也不能混着用。

总结 (Summary)

如果把这个项目比作盖房子，这个文件的意思是：

  1. 施工队：请用 Setuptools 团队来盖房。
  2. 户主信息：房子叫 LLaMA Factory，地基必须是 Python 3.9 以上。
  3. 装修标准 (Ruff)：墙面要平整（缩进4格），不要太宽（119字符）。有些小瑕疵（比如没写说明书）就别啰嗦了，直接忽略。但在材料分类（import 排序）上必须整整齐齐。
  4. 入住规则 (UV)：如果你装了华为的 NPU 插件，就别装 vLLM 插件，这两个家具尺寸冲突，放不到一个屋里。
