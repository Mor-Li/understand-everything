data

这个 data 目录是 LLaMA-Factory 项目的 “教材仓库”。

如果要训练一个 AI 模型，你就相当于在教一个学生。这个文件夹里装的全是给 AI 学习用的书（数据） 以及 怎么读书的说明书（配置）。

以下是通俗易懂的解读：

1. 这个文件夹主要负责什么？（功能）

它是 AI 的“粮仓”和“后勤部”。

这里不仅存放着训练数据（虽然大部分是演示用的样本），更重要的是，它定义了数据该长什么样以及程序该去哪里找数据。程序在训练时，不会满硬盘乱找，它只会盯着这个文件夹里的“登记表”看。

2. 这里的直接文件分别是干什么的？

我们可以把这些文件分为三类：管理员、说明书 和 教材样本。

A. 核心管理员 (最重要的文件) 👮‍♂️

  • 📄 dataset_info.json
    • 比喻：这是数据的 “户口本” 或 “图书馆索引卡”。
    • 作用：这是整个文件夹里最重要的文件。当你把自己的数据文件扔进来时，程序是看不见的。你必须在这个文件里“登记”一下：给数据起个名字，告诉程序文件名叫什么，哪一列是问题，哪一列是答案。没在这里登记的数据，程序一律不认。

B. 说明书 📖

  • 📄 README.md / README_zh.md
    • 比喻：“数据制作指南”。
    • 作用：教你（人类）如何把你的 Excel 或文本整理成 AI 能看懂的 JSON 格式，以及如何在 dataset_info.json 里进行登记。

C. 教材样本 (各种 Demo 文件) 📚

剩下的那些 .json, .jsonl, .txt 文件，全都是样题。它们不是完整的训练集（通常只有几百条），而是为了演示不同科目的教材格式。

  • 基础问答课 (SFT)：

    • alpaca_en_demo.json / alpaca_zh_demo.json / wiki_demo.txt: 最标准的“一问一答”教材。教 AI 怎么回答常识问题、翻译、写文章。
    • identity.json: “自我认知课”。专门教 AI 回答“你是谁”、“谁把你造出来的”。

  • 审美与价值观课 (DPO/KTO)：

    • dpo_en_demo.json / dpo_zh_demo.json / kto_en_demo.json / v1_dpo_demo.jsonl: “好坏分辨课”。给 AI 两个答案，告诉它哪个是好的，哪个是坏的，让它学会人类的偏好。

  • 多媒体课 (Multimodal)：

    • mllm_demo.json / mllm_video_demo.json / mllm_audio_demo.json: “看图/看片/听力说话课”。教 AI 理解图片、视频和声音内容。

  • 职业技能课 (Tools/Agent)：

    • glaive_toolcall_*.json / reason_tool_use_demo_*.jsonl: “工具使用课”。教 AI 怎么调用计算器、搜索引擎等外部工具，而不是在那瞎编。

  • 配置文件示例：

    • v1_sft_demo.yaml / v1_dpo_demo.yaml: 这是给训练程序看的“课程表”，告诉程序今天用哪几本书来上课。

3. 子文件夹的作用？（如有）

(注：你提供的列表中没有列出子文件夹，但通常 data 目录下会有存放图片/视频的文件夹，如 mllm_demo_data)

  • 作用：“多媒体素材库”。
  • 如果你的教材里涉及图片或视频（比如 mllm_demo.json），JSON 文件里只写了文件名，真正的图片/视频文件实体就存放在这些子文件夹里。

4. 高层认知：一句话理解这部分代码

不要被这么多文件吓到，你只需要关注两件事：

  1. 照猫画虎：随便打开一个和你想做的任务类似的 _demo.json 文件，看懂它的格式，然后把你的数据整理成那样。
  2. 登记造册：把你的文件放进来，然后在 dataset_info.json 里加几行字注册一下。

搞定这两步，你的数据就能喂给模型开始训练了。
