data/README_zh.md

这份文档主要是在讲 “怎么把你自己的数据，喂给 LLaMA-Factory 这个框架去训练模型”。

因为它支持很多种训练方式（指令微调、预训练、DPO偏好训练等）和很多种数据格式，所以文档看起来很杂乱。

为了让你看懂，我把它拆解成一个 “4步走”的 To-Do List。你只需要按照这个流程操作即可。

核心任务清单 (To-Do List)

  1. [决策] 选定数据格式：
    • 如果是简单的“一问一答”，选 Alpaca 格式。
    • 如果是“多轮对话”（像微信聊天记录），选 ShareGPT 格式。
  2. [制作] 准备数据文件：
    • 按照选定的格式，把你的数据整理成一个 .json 文件。
  3. [归档] 放置文件：
    • 把做好的 json 文件放到项目的 data/ 文件夹下。
  4. [注册] 登记“身份证”：
    • 打开 data/dataset_info.json 文件，告诉程序你的文件名叫什么，里面的列名对应什么意思。

详细步骤讲解

任务 1：选定数据格式 (Alpaca vs ShareGPT)

情况 A：Alpaca 格式（简单模式） * 适用场景：绝大多数指令微调（SFT）。你只需要模型根据指令回答问题。 * 结构：每一条数据包含三个主要部分： * instruction: 题目/指令 * input: 补充材料（可选，比如阅读理解的文章） * output: 标准答案

情况 B：ShareGPT 格式（进阶/对话模式） * 适用场景：训练模型进行多轮对话，或者你需要区分 User（用户）和 Assistant（AI）。 * 结构：每一条数据是一个列表，模拟对话过程： * from: 说话的人（human 或 gpt） * value: 说话的内容

任务 2：准备数据文件 (JSON 样例)

如果你选了 Alpaca 格式，你的 JSON 文件 (my_data.json) 长这样：

[
  {
    "instruction": "请解释什么是人工智能。",
    "input": "",
    "output": "人工智能是计算机科学的一个分支..."
  },
  {
    "instruction": "把这句话翻译成英文。",
    "input": "今天天气真好。",
    "output": "The weather is nice today."
  }
]

如果你选了 ShareGPT 格式，你的 JSON 文件 (my_chat.json) 长这样：

[
  {
    "conversations": [
      {
        "from": "human",
        "value": "你好，你是谁？"
      },
      {
        "from": "gpt",
        "value": "我是你的AI助手。"
      },
      {
        "from": "human",
        "value": "你能帮我写代码吗？"
      },
      {
        "from": "gpt",
        "value": "当然可以，请告诉我具体需求。"
      }
    ]
  }
]

任务 3：放置文件

这一步最简单。假设你的项目根目录下有一个 data 文件夹。 把刚才生成的 my_data.json 或 my_chat.json 直接扔进去。

任务 4：注册“身份证” (修改 dataset_info.json)

这是文档里最让人头晕的部分，但其实逻辑很简单：你需要做一个“映射表”，告诉程序你的 JSON 文件里的 Key 对应程序里的什么功能。

打开 data/dataset_info.json，在里面添加一段配置。

配置模板 1：对应 Alpaca 格式

"我的自定义数据集名称": {
  "file_name": "my_data.json", 
  "columns": {
    "prompt": "instruction",  // 告诉程序：我的 instruction 列是提示词
    "query": "input",         // 告诉程序：我的 input 列是输入
    "response": "output"      // 告诉程序：我的 output 列是答案
  }
}

配置模板 2：对应 ShareGPT 格式

"我的对话数据集名称": {
  "file_name": "my_chat.json",
  "formatting": "sharegpt",   // 必须声明这是 sharegpt 格式
  "columns": {
    "messages": "conversations" // 告诉程序：我的 conversations 列里存着对话列表
  }
}

进阶概念解释 (看不懂可以先跳过)

文档里剩下的部分是在讲特殊情况，这里简单概括：

  • System (系统提示词): 如果你想给模型设定人设（比如“你是一个暴躁的厨师”），可以在 JSON 里加一个 system 字段，并在注册时映射它。
  • History (历史): 在 Alpaca 格式里，如果想强行塞入历史对话，可以用这个字段。但现在一般推荐直接用 ShareGPT 格式来处理多轮对话。
  • 偏好数据集 (Ranking):
    • 这是给 DPO/Reward Model 训练用的。
    • 你需要提供两个答案：chosen (好的回答) 和 rejected (坏的回答)。
    • 模型会学习“要像 chosen 那样说话，不要像 rejected 那样说话”。
  • 多模态 (Images/Videos):
    • 如果要训练看图说话，需要在 JSON 里加一个 images 字段，里面放图片的路径。

总结

你现在的首要任务是： 1. 造数据：搞成 JSON 格式。 2. 改配置：在 dataset_info.json 里加几行字，把文件名和列名对上。 3. 运行：在训练命令里指定 --dataset 我的自定义数据集名称。
