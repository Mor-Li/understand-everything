data/README.md

这份文档（data/README.md）其实是 LLaMA-Factory（一个非常流行的微调大模型的工具）的数据准备说明书。

它的核心逻辑只有一句话：告诉程序你的数据长什么样，以及去哪里找这些数据。

为了让你听懂，我们把“训练模型”想象成“教学生考试”。 你需要准备两样东西： 1. 习题册（你的数据文件，比如 my_data.json）。 2. 课程大纲（dataset_info.json，告诉程序这本习题册叫什么名字，哪一列是题目，哪一列是答案）。

下面是一个为你定制的 Task To-Do List，按顺序执行即可：

✅ Task 1: 决定你的“习题册”格式 (选一种)

LLaMA-Factory 主要支持两种最常用的格式：Alpaca 格式 和 ShareGPT 格式。

🟢 选项 A：Alpaca 格式 (简单模式)

适用场景：简单的“一问一答”，或者带有简短历史记录的对话。 数据结构： * instruction: 题目（必填） * input: 补充材料（选填，比如给一段文章让模型摘要） * output: 答案（必填） * history: 历史对话（选填）

你的 Todo： 把你的数据整理成下面这种 JSON 格式：

[
  {
    "instruction": "请解释什么是人工智能。",
    "input": "",
    "output": "人工智能是指由计算机系统模拟的人类智能..."
  },
  {
    "instruction": "把这句话翻译成英文。",
    "input": "今天天气很好。",
    "output": "The weather is nice today."
  }
]

🔵 选项 B：ShareGPT 格式 (进阶/聊天模式)

适用场景：像 ChatGPT 那样的多轮连续对话，或者涉及角色扮演。 数据结构： * conversations: 一个列表，里面包含 from (谁说的) 和 value (说了啥)。 * 角色通常是 human (人类) 和 gpt (模型)。

你的 Todo： 把你的数据整理成下面这种 JSON 格式：

[
  {
    "conversations": [
      { "from": "human", "value": "你好" },
      { "from": "gpt", "value": "你好！有什么我可以帮你的吗？" },
      { "from": "human", "value": "给我讲个笑话" },
      { "from": "gpt", "value": "为什么企鹅只有肚子是白的？因为手短洗不到背。" }
    ]
  }
]

✅ Task 2: 把你的数据文件放对位置

你的 Todo： 1. 把你做好的 JSON 文件（比如命名为 my_custom_data.json）。 2. 扔到 data 文件夹里（和 dataset_info.json 在一起）。

✅ Task 3: 填写“课程大纲” (注册数据)

这是最关键的一步！程序不会自动扫描文件，你必须在 dataset_info.json 这个文件里“注册”你的数据。

你需要告诉程序：我的 JSON 文件里，哪个字段对应“问题”，哪个字段对应“答案”。

情况 1：如果你选了 Alpaca 格式 (选项 A)

打开 dataset_info.json，添加以下内容：

"my_dataset_demo": {  // 1. 给你的数据集起个名字，训练时用这个名字
  "file_name": "my_custom_data.json", // 2. 你的文件名
  "columns": {
    "prompt": "instruction", // 告诉程序：prompt(提示词) 在我文件里的 "instruction" 这一列
    "query": "input",        // 告诉程序：query(查询/输入) 在我文件里的 "input" 这一列
    "response": "output",    // 告诉程序：response(回复) 在我文件里的 "output" 这一列
    "system": "system",      // (可选) 系统提示词
    "history": "history"     // (可选) 历史记录
  }
}

情况 2：如果你选了 ShareGPT 格式 (选项 B)

打开 dataset_info.json，添加以下内容：

"my_chat_dataset": {
  "file_name": "my_custom_data.json",
  "formatting": "sharegpt", // ⚠️ 重要：必须声明这是 sharegpt 格式
  "columns": {
    "messages": "conversations" // 告诉程序：消息列表在我文件里的 "conversations" 这一列
  }
}

✅ Task 4: 特殊情况 (如果你有更高级的需求)

文档里剩下的部分是在讲特殊任务，如果你暂时不需要，可以先不看。我简单列一下：

  • 偏好训练 (DPO/ORPO)：如果你想让模型学习“哪个回答更好”，你的数据里需要有 chosen (好的回答) 和 rejected (坏的回答) 两列。并在注册时加上 "ranking": true。
  • OpenAI 格式：其实就是 ShareGPT 的变种，只是字段名变成了 role (user/assistant) 和 content。
  • 多模态 (图片/视频/音频)：
    • 需要在数据里加一列 images（放图片路径）。
    • 在对话里写上 <image> 占位符。
    • 在注册时配置 "images": "images"。

总结你的工作流

  1. 做数据：打开 Excel 或编辑器，搞出 instruction 和 output，保存为 my_data.json。
  2. 放文件：把文件放入 data/ 目录。
  3. 改配置：打开 dataset_info.json，复制粘贴一段配置，把文件名改成你的。
  4. 去训练：在运行训练命令时，指定 --dataset my_dataset_demo (你刚才起的名字)。

现在回头看那个文档，你应该能看懂了：它就是在列举不同格式下，你的 JSON 应该长什么样，以及 dataset_info.json 该怎么写。
