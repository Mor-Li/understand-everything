src/llamafactory/data/processor

这是一个非常核心的文件夹。如果把训练大模型比作“教学生读书”，那么 src/llamafactory/data/processor 就是“教材编写组”。

这里的代码负责把各种乱七八糟的原始数据（txt, json, csv），加工成大模型能直接“吃”进去的、整整齐齐的数字考卷（Token IDs）。

以下是通俗易懂的解读：

1. 这个文件夹主要负责什么？

核心功能：数据“预处理”与“格式化”。

大模型看不懂汉字，也看不懂图片文件，它只认识数字。这个文件夹里的代码就像一个个翻译官，它们根据你选择的训练模式（是预训练？还是微调？还是强化学习？），把原始素材“翻译”成模型训练专用的格式。

它主要做三件事： 1. 分词（Tokenization）： 把字变成数字。 2. 加特技（Special Tokens）： 加上“开始符”、“结束符”、“用户说话符”。 3. 定规矩（Masking/Labeling）： 告诉模型“这一段你要背诵（算 Loss）”，“那一段你只读不背（不算 Loss）”。

2. 各个文件的角色分工（教材编写组的成员）

我们可以把这些文件看作负责不同科目的教研员：

🛠️ 基础工具

  • processor_utils.py (后勤部/工具箱)
    • 这是所有教研员的工具箱。
    • 它不直接出题，但它提供了大家都需要的工具：比如“大剪刀”（infer_seqlen，把太长的文章剪短）、“胶水”（greedy_knapsack，把短句子拼在一起省空间）。它还定义了所有处理器的“基本守则”（Base Class）。
  • __init__.py (接待员)
    • 它负责对外接待。当你喊“我要做 SFT 数据处理”时，它负责把你这就指引到 supervised.py 那里去。

📚 不同的上课模式

  • pretrain.py (通识阅读课 - Pre-Training)

    • 任务：给模型看海量的书。
    • 怎么做：不需要区分“提问”和“回答”。就是把一段段话扔给模型，让它学会预测下一个字。
    • 比喻：让学生通读《百科全书》，背下来就行。

  • supervised.py (问答特训课 - SFT)

    • 任务：让模型学会当助手。
    • 怎么做：处理“用户提问 + AI回答”的数据。它会把“用户提问”部分遮住（不计分），只让模型学习怎么写“AI回答”。
    • 比喻：给学生做《五年高考三年模拟》，只背标准答案，题目不用背。

  • pairwise.py (辩论比较课 - DPO/Reward Modeling)

    • 任务：培养模型的审美和偏好。
    • 怎么做：处理“成对”的数据。同一个问题，给两个回答（A好，B坏）。
    • 比喻：给学生看两篇文章，告诉他“A比B写得好”，让学生学会分辨优劣。

  • feedback.py (是非判断课 - KTO)

    • 任务：另一种偏好学习。
    • 怎么做：不需要成对比较，而是直接给一个回答打标签——“这个是赞（True）”或者“这个是踩（False）”。
    • 比喻：老师批改作业，直接在回答上打勾或打叉。

  • unsupervised.py (自习课)

    • 任务：无监督学习。
    • 怎么做：通常用于把这就结构化的数据（如对话）当作纯文本来读，或者处理特定格式的无标签数据。目前用得相对少一些，逻辑接近 pretrain.py。

3. 子文件夹的作用

(注：根据你提供的列表，该目录下没有子文件夹。如果有，通常也是存放更具体的辅助工具或特定插件的。)

4. 高层认知：一图胜千言

你可以这样理解整个流程：

原始数据 (Raw Text) ⬇️ processor/ 目录 (中央厨房) * pretrain.py 做大锅饭（量大管饱） * supervised.py 做精致套餐（营养搭配） * pairwise.py 做品鉴菜（区分好坏） * processor_utils.py 提供菜刀和餐盘 ⬇️ 模型输入 (Input IDs & Labels)

一句话总结： 这个文件夹是 LlamaFactory 的数据加工流水线，它决定了你的原始数据会被切成什么形状、喂给模型时是什么口味。
