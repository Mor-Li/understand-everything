src/llamafactory/hparams/evaluation_args.py

这段代码其实就是给 AI 模型“安排一场考试”时填写的“报名表”。

在编程中，这叫做“配置类”（Configuration Class）。当你想要测试（评估）一个大模型的能力时，你需要告诉程序很多细节：考什么？考中文还是英文？给不给提示？结果存哪？

为了让你看懂，我把你（作为考官）需要做的决定列成了一个 To-Do List。代码中的每一行，其实就是为了完成这个清单上的某一项任务。

📝 考官的任务清单 (To-Do List)

想象你要给一个 AI 监考，你需要按顺序确认以下 5 件事：

  1. Task 1: 确定考卷内容 (考数学还是考历史？)
  2. Task 2: 设定考试难度与语言 (中文卷还是英文卷？给不给例题？)
  3. Task 3: 安排考场效率 (一次做几道题？)
  4. Task 4: 管理试卷来源 (去哪下载试卷？)
  5. Task 5: 确定成绩单存哪里 (由于怕覆盖旧成绩，这里有特殊规定)

🔍 逐步代码解读

现在我们对照上面的清单，一步步看代码里是怎么写的：

第一步：定义这个“报名表”

@dataclass
class EvaluationArguments:
    r"""Arguments pertaining to specify the evaluation parameters."""
  • 解读：@dataclass 是 Python 的一个语法糖，意思是“这是一个专门用来存数据的盒子”。这个盒子叫 EvaluationArguments（评估参数），也就是我们的“考试报名表”。

Task 1: 确定考卷内容

    task: str = field(
        metadata={"help": "Name of the evaluation task."},
    )
    task_dir: str = field(
        default="evaluation",
        metadata={"help": "Path to the folder containing the evaluation datasets."},
    )
  • task (必填)：你要考什么科目？比如填 "mmlu"（综合能力测试）或者 "gsm8k"（数学题）。
  • task_dir (默认: "evaluation")：试卷放在哪个文件夹里？程序会去这个路径下找题。

Task 2: 设定考试难度与语言

    lang: Literal["en", "zh"] = field(
        default="en",
        metadata={"help": "Language used at evaluation."},
    )
    n_shot: int = field(
        default=5,
        metadata={"help": "Number of examplars for few-shot learning."},
    )
  • lang (默认: "en")：考卷语言。选 en (英语) 还是 zh (中文)。
  • n_shot (默认: 5)：这叫“少样本学习”（Few-shot）。意思是：在让 AI 做新题之前，先给它看几个做好的例题？
    • 如果设为 0，就是“裸考”（Zero-shot），不给例题直接问。
    • 这里默认给 5 个例题，让 AI 照猫画虎，通常分数会高一点。

Task 3: 安排考场效率与公平性

    batch_size: int = field(
        default=4,
        metadata={"help": "The batch size per GPU for evaluation."},
    )
    seed: int = field(
        default=42,
        metadata={"help": "Random seed to be used with data loaders."},
    )
  • batch_size (默认: 4)：批处理大小。意思是一次性把 4 道题塞给 GPU 算。数字越大跑得越快，但显存容易爆。
  • seed (默认: 42)：随机种子。为了保证“公平”，如果你明天再跑一次测试，只要种子一样，随机抽取的题目顺序、生成的随机数就和今天一模一样，方便复现结果。

Task 4: 管理试卷来源

    download_mode: DownloadMode = field(
        default=DownloadMode.REUSE_DATASET_IF_EXISTS,
        metadata={"help": "Download mode used for the evaluation datasets."},
    )
  • download_mode：下载模式。默认是 REUSE_DATASET_IF_EXISTS，意思是：如果电脑里已经有这套卷子了，就别重新下载了，直接用现成的（省流量、省时间）。

Task 5: 确定成绩单存哪里 (含安全检查)

    save_dir: Optional[str] = field(
        default=None,
        metadata={"help": "Path to save the evaluation results."},
    )

    def __post_init__(self):
        if self.save_dir is not None and os.path.exists(self.save_dir):
            raise ValueError("`save_dir` already exists, use another one.")
  • save_dir：考完试，成绩单（JSON文件或图表）存到哪个文件夹？
  • __post_init__ (考前最后检查)：这是一个自动执行的函数。
    • 逻辑：如果你指定了一个保存路径（save_dir），并且这个文件夹已经存在了（os.path.exists），程序就会报错（raise ValueError）。
    • 为什么？ 为了防止你手滑，把上次辛苦跑出来的测试结果给覆盖掉了。它强制你必须换一个新的文件夹名字。

总结

这个文件本身不干活（不跑模型，不具体算分），它只是定义规则。

它告诉程序：以后谁要发起评估任务，必须告诉我这 8 个参数（task, batch_size, n_shot 等等）。如果没填，我就用默认值（比如默认考英文，默认给5个例题）。
