src/llamafactory/hparams

你好！这是关于 src/llamafactory/hparams 目录的“通俗版”说明书。

你可以把这个文件夹看作是整个 LlamaFactory 系统的 “中央控制室” 或者 “设置菜单”。

这里不负责“造车”（写模型架构），也不负责“开车”（跑训练循环），它的唯一作用就是定义 “车该怎么开”。所有的开关、旋钮、仪表盘的定义都在这里。

1. 这个文件夹（src/llamafactory/hparams）主要负责什么？

核心功能：参数定义与解析（Configuration Definition & Parsing）。

想象你要指挥一场庞大的战役（训练大模型），你不能直接冲上去乱喊。你需要填写各种详细的“作战计划表”： * 用什么武器？（模型参数） * 粮草在哪？（数据参数） * 打什么战术？（微调参数） * 什么时候进攻？（训练参数）

这个文件夹里的代码，就是把这些“计划表”定义成 Python 的类（Class），并且负责把你填写的命令（比如命令行里的 --learning_rate 2e-5）翻译成程序能读懂的内部变量。

2. 各个直接文件的作用（比喻说明）

为了方便理解，我们将这些文件比作 “超级士兵训练营” 的各个部门：

  • parser.py —— 【前台接待与安检员】

    • 作用：这是整个文件夹的入口。
    • 比喻：当你带着一大堆要求（命令行参数）来到训练营时，它是第一个接待你的。它负责收集你所有的表格，检查有没有填错（比如你既要在 CPU 上跑又要开 FlashAttention，它就会报错），然后把表格分发给下面各个部门。

  • model_args.py —— 【征兵办（选人）】

    • 作用：定义模型相关的配置。
    • 比喻：决定招募什么样的士兵。是招 Llama-3 还是 Qwen？是个头大的（70B）还是个头小的（7B）？要不要为了省钱把装备简配（量化 Quantization）？

  • data_args.py —— 【教材处（选书）】

    • 作用：定义数据路径、预处理方式。
    • 比喻：决定给士兵看什么书。是看维基百科（预训练）还是看对话记录（指令微调）？书太厚了要不要撕掉一部分（截断）？

  • finetuning_args.py —— 【特训教官（战术）】

    • 作用：LlamaFactory 特有的微调技术配置。
    • 比喻：决定用什么特殊手段变强。是全身强化（全量微调）？还是只戴个外骨骼机甲（LoRA）？还是做人类反馈强化（RLHF/PPO）？

  • training_args.py —— 【教务处（课表）】

    • 作用：基础的训练循环配置（继承自 HuggingFace）。
    • 比喻：制定上课的具体规则。一天上几节课（Epoch）？一次进几个人（Batch Size）？考得不好要不要留级（学习率调度）？

  • generating_args.py —— 【公关部（发言）】

    • 作用：推理和生成时的参数。
    • 比喻：训练好后，教士兵怎么对外说话。是严谨死板（Temperature=0），还是幽默风趣（Temperature高）？一次说多少字（Max Tokens）？

  • evaluation_args.py —— 【考试中心（测验）】

    • 作用：评估任务的配置。
    • 比喻：决定怎么验收训练成果。做几套卷子（Tasks）？是考中文还是英文？给不给参考范例（Few-shot）？

  • __init__.py —— 【目录索引】

    • 作用：导出上述模块。
    • 比喻：办事大厅的指引牌，告诉你哪个部门在哪。

3. 子文件夹的作用

(注：在你提供的文件结构中，hparams 目录下并没有子文件夹，只有文件。如果实际项目中存在 __pycache__ 等，那是 Python 自动生成的缓存，无需关心。)

在此上下文中，这是一个扁平的结构，所有配置逻辑都直接平铺在这一层。

4. 高层认知：如何快速理解这部分代码？

要理解这个文件夹，你只需要记住一句话：

这里是“变量”与“逻辑”的分界线。

  • 在这个文件夹之外（比如 src/llamafactory/train），代码写的是“怎么做”（How to train），那里的逻辑是固定的，一般不需要改。
  • 在这个文件夹之内，代码定义的是“用什么做”（With what parameters），这里定义了所有你在命令行能修改的选项。

当你想要知道 LlamaFactory 支持哪些新奇的微调技术（比如 GaLore, DoRA）或者想知道某个参数（比如 cutoff_len）具体是什么意思时，直接来这里找对应的 _args.py 文件即可。
