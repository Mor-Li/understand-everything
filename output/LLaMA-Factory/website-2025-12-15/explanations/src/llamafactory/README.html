src/llamafactory

你好！欢迎来到 LlamaFactory 的 “总部大楼”（src/llamafactory）。

这是整个项目的根目录，也是一切开始的地方。如果不看里面的具体房间（子文件夹），只看这一层，它就是一个巨大的调度中心。

以下是通俗易懂的解读：

1. 🏢 当前这个文件夹主要负责什么功能？

核心功能：接待、分流与指挥。

你可以把它想象成一个繁忙的机场塔台或者公司前台。 当你输入命令（比如 llamafactory-cli train）时，你的指令首先到达这里。这个文件夹里的代码负责： 1. 验票：确认你是谁，想干什么（是想训练？还是想聊天？）。 2. 安检：检查你的环境（是不是 Windows？有没有多张显卡？）。 3. 派单：把你分配给具体的部门（子文件夹）去干活。

它自己不负责具体的“炼丹”（训练），它只负责把任务准确地分发下去。

2. 📄 这个文件夹下的各个直接文件分别是干什么的？

这一层只有三个核心文件，它们构成了启动的“三步走”：

  • __init__.py —— 【身份证】

    • 作用：它很简单，主要就是亮出版本号（比如 0.9.0）。
    • 比喻：公司门口的招牌。告诉你：“你现在进的是 LlamaFactory 的大门，不是别的软件。”

  • cli.py —— 【门卫 / 安检员】

    • 作用：这是程序的第一入口。
      • 它负责解决系统的兼容性问题（比如给 Windows 系统打补丁防止多进程崩溃）。
      • 它还会检查你有没有开启“V1 新版”开关。
    • 比喻：大楼门口的保安。他不管具体业务，只负责确认环境安全，然后把你指引到大堂。

  • launcher.py —— 【大堂经理 / 总调度】

    • 作用：这是最忙碌的人。
      • 解析需求：他听你说“我要训练”或“我要开网页版”。
      • 摇人（分布式）：如果你有好几张显卡，他会自动帮你组建团队（构建 torchrun 命令），让多张显卡一起工作，而不需要你自己去敲复杂的分布式指令。
      • 分派任务：最后，他会把你的需求转接给 train/、chat/ 或 webui/ 等具体的部门。
    • 比喻：机场的调度员。他决定这架飞机是自己飞，还是需要叫几辆牵引车（多卡）来拉，并最终发出“起飞”指令。

3. 📁 子文件夹的作用是什么？（部门概览）

如果把这里比作一家大公司，子文件夹就是各个职能部门：

  • 对外窗口类：

    • webui/：网页营业厅。负责把复杂的功能做成可视化的网页界面。
    • api/：电话接线员。给其他软件提供调用的接口。
    • cli.py (同级文件)：命令行窗口。

  • 核心业务类（干活的）：

    • train/：炼丹房。负责具体的模型训练逻辑（SFT, DPO 等）。
    • chat/：翻译室。负责加载模型并进行对话推理。
    • eval/：质检部。负责给模型考试，评估能力。
    • v1/：新厂区。新一代的架构设计，整合了核心流程。

  • 后勤保障类（提供资源的）：

    • data/：图书馆。负责处理、清洗和加载数据。
    • model/：车库。负责模型的加载、打补丁和适配器（LoRA）管理。
    • hparams/：档案室。负责管理所有的配置参数和说明书。

  • 工具与外包类：

    • extras/：杂物间。放一些通用的常量、日志工具等。
    • third_party/：外包团队。引入的外部强力插件（如 Muon 优化器）。

4. 🧠 高层认知：一句话理解

src/llamafactory 就是一个“万能遥控器”。

你不需要知道底层的 PyTorch 怎么写，也不需要知道显卡怎么通信。你只要按下这个遥控器上的按钮（运行 launcher.py），它就会自动帮你协调底下的十几个部门，把大模型训练这件复杂的事情搞定。
