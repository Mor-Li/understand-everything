src/llamafactory/train/ppo/workflow.py

这份代码文件 workflow.py 其实是 LlamaFactory 中执行 PPO（强化学习，RLHF）训练的“总指挥”。

你可以把它想象成一个装修工头或者电影导演。它的工作不是具体去搬砖（底层计算），而是负责把所有人叫到现场，分配任务，然后喊“Action”开始干活。

为了让你听懂，我把这个复杂的 PPO 训练过程拆解成一个 “特训班 To-Do List”。我们要做的是训练一个 AI（学生），让它学会说话更讨人喜欢。

📝 PPO 特训班 To-Do List

  1. 准备翻译官 (加载分词器 Tokenizer)
  2. 准备课本 (加载数据集 Dataset)
  3. 叫学生进教室 (加载主模型 Model)
  4. 布置考场 (设置数据整理器 Collator)
  5. 叫“旧学生”进教室 (加载参考模型 Ref Model)
  6. 叫老师进教室 (加载奖励模型 Reward Model)
  7. 任命班主任 (初始化 Trainer)
  8. 开始上课并考试 (开始训练 Train)
  9. 颁发毕业证 (保存模型 Save)

🔍 逐步代码对照讲解

现在我们按照上面的 List，一步步看代码里是怎么实现的：

Task 1: 准备翻译官 (Tokenizer)

代码：

tokenizer_module = load_tokenizer(model_args)
tokenizer = tokenizer_module["tokenizer"]
template = get_template_and_fix_tokenizer(tokenizer, data_args)

讲解： 机器听不懂中文英文，只懂数字。这一步是加载“字典”，把文字转成数字。template 是对话模版（比如 User: ... Assistant: ...），确保学生懂得对话的格式。

Task 2: 准备课本 (Dataset)

代码：

dataset_module = get_dataset(template, model_args, data_args, training_args, stage="ppo", **tokenizer_module)

讲解： 这里加载训练数据。注意 stage="ppo"，说明这是专门为了强化学习准备的数据（通常包含 Prompt，即“问题”）。

Task 3: 叫学生进教室 (Main Model)

代码：

model = load_model(tokenizer, model_args, finetuning_args, training_args.do_train, add_valuehead=True)

讲解： 这是我们要训练的主角。 * 重点：add_valuehead=True。这相当于给学生装了一个“自我评估器”，让他不仅能回答问题，还能估算自己回答得好不好（这是 PPO 算法必须的）。

Task 4: 布置考场 (Collator & Padding)

代码：

tokenizer.padding_side = "left"  # PPO 需要生成文本，生成时通常用左填充
data_collator = MultiModalDataCollatorForSeq2Seq(template=template, model=model, **tokenizer_module)

讲解： * 左填充：因为 PPO 训练通过“提问-生成回答”来进行，生成文本时，空白占位符（Padding）通常放在左边，这样生成的文字才能连贯地往右接。 * Collator：负责把杂乱的数据打包成整齐的批次（Batch），喂给模型吃。

Task 5: 叫“旧学生”进教室 (Ref Model)

代码：

ref_model = create_ref_model(model_args, finetuning_args, add_valuehead=True)

讲解： 为什么要这个？ Ref Model 是没训练之前的“主角”。 PPO 训练中，我们希望学生进步，但不希望他变成疯子（完全胡言乱语）。所以我们需要时刻对比“现在的学生”和“以前的学生”，如果差别太大，就要惩罚一下，让他保持初心。

Task 6: 叫老师进教室 (Reward Model)

代码：

reward_model = create_reward_model(model, model_args, finetuning_args)

讲解： 这是裁判/老师。它的作用不是生成文本，而是打分。 学生回答了一个问题，老师看一眼，打个分（比如 +10 分或 -5 分）。学生根据这个分数去调整自己的说话方式。

Task 7: 任命班主任 (Initialize Trainer)

代码：

ppo_trainer: CustomPPOTrainer = CustomPPOTrainer(
    model=model,              # 学生
    reward_model=reward_model,# 老师
    ref_model=ref_model,      # 旧学生（参照物）
    ...
)

讲解： 这里把上面所有人（学生、老师、旧学生、课本）都塞进 CustomPPOTrainer 里。这个 Trainer 包含了 PPO 算法的所有数学逻辑。

Task 8 & 9: 开始上课、考试、发证 (Train & Save)

代码：

if training_args.do_train:
    ppo_trainer.ppo_train(...) # 开始特训！
    ppo_trainer.save_model()   # 训练完保存模型权重
    if training_args.should_save:
        fix_valuehead_checkpoint(...) # 修正保存格式
    ppo_trainer.save_state()   # 保存训练状态（方便以后断点续传）
    if ... plot_loss(...)      # 画出分数走势图

讲解： * ppo_train()：这是最核心的一步，模型开始不断的“生成回答 -> 老师打分 -> 计算差距 -> 修改参数”。 * plot_loss：画图，看看学生是不是越来越聪明（Reward 变高），以及是不是学得太累了（Loss 变化）。

总结

这个脚本本身不涉及复杂的数学公式（公式都在 CustomPPOTrainer 里），它的作用就是组装。

一句话概括： 它加载了三个模型（正在学的、没学的、打分的），准备好数据，然后启动训练器让它们开始互相博弈，最后保存结果。
