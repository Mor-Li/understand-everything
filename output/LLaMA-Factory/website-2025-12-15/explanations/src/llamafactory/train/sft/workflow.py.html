src/llamafactory/train/sft/workflow.py

这个文件 workflow.py 其实就是 LLaMA-Factory 进行 SFT（有监督微调）时的“总指挥”或“流程图”。

你可以把它想象成一个项目经理，手里拿着一张任务清单（ToDo List），按顺序指挥各个部门（加载数据、加载模型、开始训练、评估等）协同工作。

为了让你看懂，我把你在这个脚本中需要完成的工作拆解成了一个 “SFT 微调流水线任务清单”。

📋 SFT 微调流水线 Task List

我们将整个代码逻辑拆分为 4 个阶段，共 8 个主要任务。

第一阶段：准备工作 (Preparation)

  • [ ] Task 1: 找翻译官 (Tokenizer) - 加载分词器，决定怎么把字变成数字。
  • [ ] Task 2: 准备教材 (Dataset) - 加载训练数据，并根据模板处理好。
  • [ ] Task 3: 请出大脑 (Model) - 加载大模型本体。

第二阶段：配置环境 (Setup)

  • [ ] Task 4: 打包员 (Data Collator) - 决定怎么把数据打包成一个个 Batch 喂给模型。
  • [ ] Task 5: 制定评分标准 (Metrics) - 设定怎么判断模型学得好不好（比如算准确率）。
  • [ ] Task 6: 聘请教练 (Trainer) - 初始化训练器，把上面所有的东西都交给它。

第三阶段：执行任务 (Execution)

  • [ ] Task 7: 开始特训 (Train) - 如果设定了要训练，就开始跑训练循环，并保存进度。

第四阶段：测试与收尾 (Evaluation & Finish)

  • [ ] Task 8: 考试与应用 (Eval/Predict) - 训练完后进行测试，或者用模型生成结果，最后写个“结案报告”（Model Card）。

🔍 逐步代码解读

现在我们对照着代码，一步步把上面的 Task 讲清楚。

Task 1: 找翻译官 (Tokenizer)

代码位置：run_sft 函数开头

tokenizer_module = load_tokenizer(model_args)
tokenizer = tokenizer_module["tokenizer"]
template = get_template_and_fix_tokenizer(tokenizer, data_args)
  • 讲人话：模型看不懂中文英文，只看懂数字。这里加载 Tokenizer，并确定对话模板（Template，比如是 User/Assistant 格式还是其他格式）。

Task 2: 准备教材 (Dataset)

代码位置：紧接着上面

dataset_module = get_dataset(template, model_args, data_args, training_args, stage="sft", **tokenizer_module)
  • 讲人话：从硬盘读取你的 JSON 数据，根据刚才的模板，把文本转换成模型能读懂的 ID 列表。

Task 3: 请出大脑 (Model)

代码位置：

model = load_model(tokenizer, model_args, finetuning_args, training_args.do_train)
  • 讲人话：加载 PyTorch 模型（比如 Llama-3, Qwen 等）。如果是量化模型（为了省显存），这里也会做一些特殊处理。

Task 4: 打包员 (Data Collator)

代码位置：

data_collator = SFTDataCollatorWith4DAttentionMask(...)
  • 讲人话：这是个关键组件。数据长短不一，这个“打包员”负责：
    1. 把短的数据补齐（Padding）。
    2. 把 Input 和 Label 对齐。
    3. 处理 Mask（告诉模型哪些部分是问题，不需要预测；哪些是答案，需要预测）。

Task 5: 制定评分标准 (Metrics) & 生成参数

代码位置：

metric_module = {}
if training_args.predict_with_generate:
    metric_module["compute_metrics"] = ComputeSimilarity(...) # 算相似度（比如BLEU/ROUGE）
elif finetuning_args.compute_accuracy:
    metric_module["compute_metrics"] = ComputeAccuracy()      # 算准确率
  • 讲人话：
    • 如果是像翻译任务那样需要生成文本，就用相似度来评测。
    • 如果是做选择题或者简单的微调，通常看准确率。
    • 代码后面还有一大段关于 gen_kwargs 的逻辑，那是为了兼容不同版本的 Transformers 库，设定模型生成时的参数（比如何时停止生成 eos_token_id）。

Task 6: 聘请教练 (Trainer)

代码位置：

trainer = CustomSeq2SeqTrainer(
    model=model,
    args=training_args,
    data_collator=data_collator,
    ...
)
  • 讲人话：CustomSeq2SeqTrainer 是 LlamaFactory 定制的训练器（继承自 HuggingFace Trainer）。你把刚才准备的模型、参数、数据打包员、评分标准全都丢给它。它是实际干活的主力。

Task 7: 开始特训 (Train)

代码位置：

if training_args.do_train:
    train_result = trainer.train(...)
    trainer.save_model()
    # ... 画图画 Loss 曲线 ...
    plot_loss(...)
  • 讲人话：
    1. trainer.train()：开始跑进度条，显卡开始转。
    2. trainer.save_model()：训练完了，把练好的权重保存到硬盘。
    3. plot_loss：画出那个 Loss 下降的折线图，让你知道模型是不是收敛了。

Task 8: 考试与应用 (Eval/Predict)

代码位置：后面的一大段 if 判断

if training_args.do_eval:
    metrics = trainer.evaluate(...) # 考试

if training_args.do_predict:
    # ...
    predict_results = trainer.predict(...) # 预测
  • 讲人话：
    • Eval: 用验证集考考模型，看看分数。
    • Predict: 给模型一些没见过的数据，让它生成答案并保存下来。
    • 最后一行 create_modelcard_and_push 是自动生成一个 Readme 文件，记录这次训练用了什么参数，方便你上传到 HuggingFace。

总结

这段代码看起来复杂，其实就是按部就班的流水线：

  1. 进货（Load Tokenizer/Model/Data）
  2. 加工（Data Collator 处理数据）
  3. 组装（初始化 Trainer）
  4. 开工（Train）
  5. 质检（Eval/Predict）

你只需要关注 run_sft 这个函数，它就是把这些步骤串起来的绳子。
