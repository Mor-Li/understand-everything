src/llamafactory/extras/constants.py

这份文件看起来很长，但其实逻辑非常简单，它 90% 的内容都是在重复做同一件事：“登记造册”。

你可以把这个文件理解为 LlamaFactory 这个项目的 “大字典” 或者 “配置中心”。它定义了项目里用到的所有固定名字、选项和模型信息，防止在其他代码里写错。

为了帮你理解，我制定了一个 5步走的 Task List（任务清单），我们一步步来拆解它：

✅ Task 1：理解“基础常量” (定义文件名和占位符)

目标：看懂文件最开始的那几十行变量定义。 解释： 代码的前 100 行左右，是在定义各种固定的字符串。这样做的好处是，如果以后要改文件名，改这里一个地方就行了，不用满世界找。

  • 占位符：
    • AUDIO_PLACEHOLDER, IMAGE_PLACEHOLDER：告诉程序，如果遇到 <image> 这种文字，它代表一张图片。
  • 文件名：
    • DATA_CONFIG = "dataset_info.json"：告诉程序，数据集的配置文件叫这个名字。
    • TRAINER_LOG = "trainer_log.jsonl"：训练日志存成这个文件名。
  • 训练设置：
    • METHODS = ["full", "freeze", "lora", "oft"]：定义了支持哪几种微调方式（全量、冻结、LoRA等）。
    • TRAINING_STAGES：定义了训练阶段的简称（比如 "Supervised Fine-Tuning" 简称 "sft"）。

总结：这一部分就是把项目中用到的“死名字”定义成变量。

✅ Task 2：理解“枚举类” (定义下拉菜单选项)

目标：看懂 class AttentionFunction, class DownloadSource 等类。 解释： 这些继承自 Enum 的类，其实就是为了限制用户的选择范围，就像网页上的下拉菜单。

  • DownloadSource：你下载模型要去哪里下？
    • DEFAULT = "hf" (HuggingFace)
    • MODELSCOPE = "ms" (魔搭社区，国内下载快)
  • QuantizationMethod：量化方法选哪个？(bnb, gptq, awq 等)
  • AttentionFunction：注意力机制用哪种算法？(sdpa, fa2 等)

总结：这一部分定义了各种功能的“可选项”。

✅ Task 4：浏览“模型大名单” (这一步最长)

目标：看懂从第 160 行一直到文件结束的内容。 解释： 你看到的这几千行代码，全都是在调用 Task 3 里的那个函数。这里就是 LlamaFactory 支持的所有模型的花名册。

举个例子（代码中的一段）：

register_model_group(
    models={
        "DeepSeek-V3-Chat": {  # 模型在 LlamaFactory 里的名字
            DownloadSource.DEFAULT: "deepseek-ai/DeepSeek-V3", # 在 HuggingFace 的路径
            DownloadSource.MODELSCOPE: "deepseek-ai/DeepSeek-V3", # 在魔搭的路径
        },
    },
    template="deepseek3", # 指定它使用 deepseek3 的对话模板
)

这段代码的意思是： 1. 如果用户在界面上选了 "DeepSeek-V3-Chat"。 2. 系统就知道去 HuggingFace 的 "deepseek-ai/DeepSeek-V3" 下载。 3. 系统知道跟它对话时，要套用 "deepseek3" 的格式模板。

总结：这几千行代码没有任何复杂的逻辑，纯粹是数据录入。它列出了 Llama, Qwen, Baichuan, Mistral, Gemma 等几百个模型的下载地址和配置。

✅ Task 5：全貌总结

目标：把以上步骤串起来。

这个文件的作用就是建立一个索引库： 1. 用户说：“我要训练 Llama-3-8B-Instruct”。 2. 程序查这个文件： * 去哪里下载？ -> 查 register_model_group 里的记录。 * 用什么对话格式？ -> 查 template="llama3"。 * 能不能看图？ -> 查 multimodal 标记。 * 训练日志存哪？ -> 查 TRAINER_LOG 常量。

为什么你要读懂它？

如果你想在 LlamaFactory 里添加一个它原本不支持的新模型，你就需要在这个文件里照葫芦画瓢，加一段 register_model_group 的代码，告诉系统你的模型叫什么、在哪里下载、用什么模板。

一句话概括：这是 LlamaFactory 的通讯录和配置字典。
