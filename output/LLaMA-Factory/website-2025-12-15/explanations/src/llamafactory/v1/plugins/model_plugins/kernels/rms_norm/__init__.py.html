✅ Task 1: 理解基础 —— 什么是“归一化” (Normalization)？

目标：明白为什么模型需要这个东西。

  • 通俗解释： 想象你在批改试卷。语文卷子满分 150 分，数学卷子满分 100 分。如果直接比较分数，120 分的语文和 90 分的数学很难说谁更好。 为了公平比较，或者为了让数据“整齐”，我们需要把它们拉到同一个标准（比如都换算成百分制，或者都减去平均分）。这就是归一化。
  • 在模型里的作用： 在大模型（LLM）的神经网络里，数据在层与层之间传递时，数字可能会变得极大（爆炸）或者极小（消失）。归一化层（Normalization Layer）就像一个稳压器，保证数据在传递过程中数值稳定，让模型训练得更稳、更快。

✅ Task 2: 进阶概念 —— 什么是 RMS Norm？

目标：明白它和传统方法的区别。

  • 背景： 以前最常用的是 LayerNorm（层归一化）。它在做归一化时，要算两个东西：均值（平均值）和方差（波动程度）。
    • LayerNorm 逻辑：先减去平均值（Centering），再除以方差（Scaling）。
  • RMS Norm (Root Mean Square Normalization)： 后来研究人员发现，“减去平均值”这一步其实对大模型效果影响不大，但计算起来很费时间。 于是 RMS Norm 出现了。它省去了“减去平均值”的步骤，直接根据数据的均方根（RMS）进行缩放。
  • 结论： RMS Norm 是 LayerNorm 的简化版。计算更简单、速度更快，而且效果一样好甚至更好。现在的 LLaMA 模型全都在用这个。

✅ Task 3: 核心技术 —— 什么是 Kernel (内核/算子)？

目标：理解路径里 kernels 这个词的含义。

  • 通俗解释： Python 这种编程语言虽然好写，但是跑得慢。当你需要在大模型里做几亿次 RMS Norm 计算时，用纯 Python 写就像是用勺子挖游泳池。 Kernel 在这里指的是一段专门为显卡（GPU）优化过的底层代码（通常用 CUDA 或 Triton 编写）。
  • 作用： 它就像是一个专业的挖掘机。这个文件夹里的代码，目的是绕过慢吞吞的 Python，直接指挥显卡用最快的速度完成 RMS Norm 的计算。
