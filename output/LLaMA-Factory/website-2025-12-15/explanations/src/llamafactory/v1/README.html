src/llamafactory/v1

你好！欢迎来到 LLaMA-Factory 的 核心业务总部 —— src/llamafactory/v1。

如果说整个项目是一个巨大的工厂，那么 v1 目录就是目前正在运营的第 1 号厂区。所有的核心技术、生产流水线、指挥中心都在这里。

下面我们用最通俗的方式来拆解它：

1. 🏢 这个文件夹主要负责什么？

核心功能：统筹与执行。

这个文件夹是 LLaMA-Factory 真正干活的地方。它把“怎么读取数据”、“怎么加载模型”、“怎么开始训练”、“怎么使用硬件加速”这些复杂的逻辑，全部打包在这个 v1 版本里。

不管是微调（Fine-tuning）、推理（Inference）还是评估（Evaluation），所有的指令最终都会汇聚到这里，由这里的代码调度各个部门协同工作。

2. 📄 直接文件分别是干什么的？

这里有两个直接文件，它们的角色非常清晰：

  • __init__.py（挂牌）
    • 角色：部门门牌。
    • 作用：虽然它是空的，但它的存在告诉 Python：“嘿，v1 是一个正经的代码包，里面的东西都可以被外界引用。”
  • launcher.py（总指挥 / 调度台）
    • 角色：任务分发中心。
    • 作用：这是你和程序交互的第一入口。
      • 当你在命令行输入 llamafactory-cli sft（我要微调）时，这个文件会立马响应。
      • 它负责解析你的命令（是想训练？还是想聊天？），然后像接线员一样，把任务转接给具体的部门（比如转接给 trainers 里的 SFT 训练器）。
      • 一句话：它不亲自干苦力，它负责叫醒干苦力的人。

3. 📁 子文件夹的作用是什么？（部门概览）

为了完成训练大模型这项艰巨的任务，这个厂区设立了 6 个专门的部门：

  • config/（规划部）
    • 作用：制定规则。负责定义所有的参数（学习率、Batch size等），确保大家按统一的标准干活。
  • core/（基建部）
    • 作用：提供地基。定义了数据怎么流转、模型怎么加载、训练循环的基本骨架。这是工厂的流水线底座。
  • trainers/（生产车间）
    • 作用：具体执行。这里有针对不同任务的老师傅（SFT、DPO、RM），根据 launcher.py 的指令，真正开始“炼丹”。
  • accelerator/（动力部）
    • 作用：硬件加速。负责榨干显卡性能，管理分布式训练，让模型跑得更快。
  • plugins/（改装部）
    • 作用：特殊适配。如果你有特殊的模型结构或特殊的数据格式，这里负责提供适配插件。
  • utils/（后勤部）
    • 作用：通用工具。提供日志记录、常量定义、数据类型转换等杂七杂八的支持。

4. 🧠 高层认知：一句话理解

src/llamafactory/v1 就是一个“全功能的微调操作系统”。

  • launcher.py 是鼠标和键盘（接收指令）；
  • config 是控制面板（设置参数）；
  • core 和 trainers 是CPU和内存（处理核心逻辑）；
  • accelerator 是显卡驱动（加速计算）。

你在这个目录下看到的一切，都是为了让“训练大模型”这件事变得像安装软件一样标准化、流程化。
