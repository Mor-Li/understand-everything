src/llamafactory/webui/components/data.py

这份代码主要是在 LlamaFactory 的网页界面（WebUI）中实现一个“数据集预览”的功能。简单来说，就是让你在训练模型之前，能先点一下按钮，看看你的数据长什么样，有没有格式错误。

为了让你更容易理解，我把这份代码要做的事情拆解成一个 Task To-Do List（任务清单），然后一步一步带你完成这些任务。

📋 任务清单 (Task To-Do List)

我们要实现一个“数据预览器”，需要完成以下步骤：

  1. 【规则设定】：规定一页显示几条数据，怎么算“上一页”和“下一页”。
  2. 【资格检查】：检查用户选的数据集能不能预览（文件是否存在？格式对不对？）。
  3. 【读取文件】：编写一个能打开并读取 .json 或 .jsonl 文件的工具。
  4. 【获取内容】：根据当前页码，去文件里抓取对应的那几条数据。
  5. 【搭建界面】：画出按钮、显示框，并把上面所有的逻辑连接起来（点击按钮 -> 触发功能）。

🪜 逐步讲解

1. 【规则设定】翻页逻辑

代码最开始定义了一些基础规则，主要是为了处理“分页”，防止数据太多一下全显示出来卡死页面。

  • 代码位置： ```python PAGE_SIZE = 2 # 一页只看2条数据（为了预览，不用看太多）

    def prev_page(page_index: int) -> int: # 如果当前不是第0页，就减1；否则保持不变 return page_index - 1 if page_index > 0 else page_index

    def next_page(page_index: int, total_num: int) -> int: # 如果还有下一页的数据，就加1；否则保持不变 return page_index + 1 if (page_index + 1) * PAGE_SIZE < total_num else page_index ``` * 白话解释： 这里定义了翻页的数学逻辑。就像看书一样，防止你翻到第 -1 页，或者翻到超过书本总页数的地方。

2. 【资格检查】能不能预览？ (can_preview)

在用户点击“预览”之前，程序得先判断一下：用户选的这个数据集，本地到底有没有？

  • 代码位置：def can_preview(...)
  • 白话解释：
    1. 找户口本：尝试打开 dataset_info.json（这是 LlamaFactory 记录所有数据集信息的总表）。
    2. 查名字：看用户选的这个数据集在表里有没有记录文件名 (file_name)。
    3. 查实体：去硬盘上检查这个文件或文件夹是不是真的存在。
    4. 结果：如果一切正常，返回一个 interactive=True 的按钮（按钮变亮，可以点）；否则按钮变灰，不能点。

3. 【读取文件】万能读取器 (_load_data_file)

这是个幕后苦力函数，专门用来把硬盘上的文件读进内存。

  • 代码位置：def _load_data_file(...)
  • 白话解释：
    • 如果是 .json 结尾，用 json.load 一次性读完。
    • 如果是 .jsonl 结尾（每行一个json），就一行一行读。
    • 如果是其他，就直接按行读文本。

4. 【获取内容】拿到当前页的数据 (get_preview)

当用户真的点了“预览”或者“下一页”时，这个函数开始工作。

  • 代码位置：def get_preview(...)
  • 白话解释：
    1. 加载数据：调用上面的“万能读取器”把数据读进来。如果是文件夹，它会把里面所有文件的内容拼起来。
    2. 切片：根据当前的 page_index（页码）和 PAGE_SIZE（每页2条），切出你要看的那一小块数据。
      • 比如：第0页，就切出列表的 [0:2]；第1页，就切出 [2:4]。
    3. 返回：返回总数据量、切好的数据样本、以及让显示框变成“可见”状态。

5. 【搭建界面】组装控制台 (create_preview_box)

这是最长的一个函数，它用 Gradio 库画出了你在网页上看到的那个弹窗。

  • 代码位置：def create_preview_box(...)
  • 白话解释：
    • 画界面：
      • data_preview_btn: “预览数据集”的主按钮。
      • preview_box: 一个默认隐藏的弹窗。
      • preview_count, page_index: 显示总条数和当前页码。
      • prev_btn, next_btn, close_btn: 上一页、下一页、关闭按钮。
      • preview_samples: 一个用来漂亮地展示 JSON 数据的框。
    • 连电线（绑定事件）：
      • dataset.change(...): 当你在下拉菜单选了不同的数据集时 -> 触发 can_preview 检查按钮能不能点 -> 并把页码重置为0。
      • data_preview_btn.click(...): 点击预览按钮 -> 触发 get_preview 获取数据 -> 弹窗显示出来。
      • prev_btn.click(...): 点击上一页 -> 算页码 -> 重新 get_preview。
      • next_btn.click(...): 点击下一页 -> 算页码 -> 重新 get_preview。
      • close_btn.click(...): 点击关闭 -> 把弹窗隐藏 (visible=False)。

总结

这个文件的核心逻辑就是： 用户选数据集 -> 检查文件是否存在 -> (用户点预览) -> 读取文件 -> 切出前2条数据 -> 在弹窗里展示出来 -> (用户点翻页) -> 切出下2条展示。

它就是一个简单的数据查看器，目的是防止你直接拿错误的数据去训练模型。
