src/llamafactory/webui/locales.py

这份代码文件其实不是复杂的程序逻辑，而是一个“多语言翻译字典”（或者叫语言包）。

它的作用只有一个：让 LLaMA Factory 的网页界面（WebUI）能够根据用户的设置，显示中文、英文、俄文、韩文或日文。

你可以把它想象成餐厅里的一本菜单，每一道菜下面都写了5种语言的介绍。

为了让你更容易理解，我为你列了一个 “阅读与理解任务清单 (To-Do List)”，并一步步带你拆解它的内容。

📋 任务清单：一步步读懂这个文件

✅ Task 1：理解文件的整体结构

  • 观点：这个文件由两个巨大的“仓库”（Python 字典）组成。
  • 解释：
    1. LOCALES = { ... }：存放界面上固定显示的文字（比如按钮名字、输入框标题）。
    2. ALERTS = { ... }：存放系统弹出的提示信息（比如“训练完成”、“出错了”）。

✅ Task 2：拆解一个具体的界面元素（以 LOCALES 为例）

  • 观点：每一个界面元素都有一个唯一的“身份证号”（ID），里面包含了不同语言的翻译。
  • 步骤：
    1. 找到代码中的 model_name（这是模型名称输入框的 ID）。
    2. 你会看到它下面有 en (英语), ru (俄语), zh (中文), ko (韩语), ja (日语)。
    3. 每个语言里有两个属性：
      • label: 显示在界面上的标题（例如中文是“模型名称”）。
      • info: 鼠标悬停时显示的帮助提示（例如中文是“输入首单词以检索模型”）。

✅ Task 3：拆解一个系统提示信息（以 ALERTS 为例）

  • 观点：当程序运行状态发生改变时，需要告诉用户发生了什么，这里定义了这些话术。
  • 步骤：
    1. 找到代码底部的 ALERTS 区域。
    2. 看 info_finished 这个条目。
    3. 它的中文翻译是 "训练完毕。"。
    4. 这意味着，当代码里的训练程序跑完时，它会调用 info_finished，界面上就会弹窗显示“训练完毕”。

✅ Task 4：理解为什么要这么写

  • 观点：为了“国际化”（i18n）。
  • 解释：程序员在写界面代码时，不会直接写中文或英文，而是写代码 get_text("start_btn")。
    • 如果用户选了中文，程序就来这个文件找 start_btn -> zh -> 得到 "开始"。
    • 如果用户选了英文，程序就来这个文件找 start_btn -> en -> 得到 "Start"。

🔍 详细图解：文中的观点拆解

如果我们要把这个文件看作一本书，它的内容逻辑是这样的：

第一部分：界面上的静态文字 (LOCALES)

这一部分定义了你在网页上能看到的所有按钮和标签。

  • 标题与副标题：
    • title: 定义了网页最上面的大标题 "LLaMA Factory..."。
    • subtitle: 定义了 GitHub 链接和文档链接。
  • 基础设置：
    • lang: 语言选择下拉框。
    • model_name / model_path: 选择模型的地方。
  • 高级参数（你需要一步步配置的参数）：
    • finetuning_type: 微调方法（如 LoRA, Full）。
    • learning_rate: 学习率。
    • num_train_epochs: 训练轮数。
    • batch_size: 批处理大小。
    • 注意：代码里不仅给了翻译，还通过 info 字段解释了这个参数是干嘛的。比如 rope_scaling 的中文 info 是 "RoPE 插值时使用的方法"。
  • 不同功能的标签页：
    • lora_tab: LoRA 参数设置。
    • rlhf_tab: RLHF（强化学习）参数设置。
    • galore_tab / badam_tab: 各种优化器的设置。
  • 操作按钮：
    • start_btn: "开始"。
    • stop_btn: "中断"。
    • export_btn: "开始导出"。

第二部分：动态反馈与警告 (ALERTS)

这一部分定义了程序和用户“对话”的内容。

  • 错误提示 (Error)：
    • err_no_model: 如果你没选模型就点开始，会提示 "请选择模型。"
    • err_conflict: 如果已经在训练了你又点开始，会提示 "任务已存在，请先中断训练。"
  • 状态通知 (Info)：
    • info_loading: "加载中……"
    • info_loaded: "模型已加载，可以开始聊天了！"
    • info_thinking: 思考模式模型的提示 "🌀 思考中..."。

总结

这个文件讲了什么？ 它没有讲任何“道理”或“算法”，它只是一个多语言对照表。

它的作用是什么？ 它保证了无论你是中国人、美国人还是俄罗斯人，在使用 LLaMA Factory 这个工具时，都能看到自己熟悉的语言界面。

如果你是使用者： 你不需要修改它，你只需要知道，你在界面上看到的每一个中文字，都来自于这个文件里的 "zh" 这一行。

如果你是开发者： 如果你想给界面加一个新按钮，或者觉得现在的翻译不准确（比如想把“开始”改成“启动”），你就需要来修改这个文件。
