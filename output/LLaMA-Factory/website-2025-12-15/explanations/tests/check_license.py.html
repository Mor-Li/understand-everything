tests/check_license.py

这段代码其实是一个“自动安检员”。

它的核心作用是：检查项目里所有的 Python 代码文件，看它们的第一行有没有写上正确的版权声明（Copyright）。

如果不符合要求，它就会报错，阻止代码提交或合并。

下面我把它拆解成一个 To-Do List (任务清单)，带你一步步看它是怎么工作的：

任务清单：版权检查流程

Task 1: 设定“通关密语” (定义检查标准)

首先，代码定义了必须出现的三个关键词。 * 代码位置: KEYWORDS = ("Copyright", "2025", "LlamaFactory") * 含义: 任何被检查的文件的第一行，必须同时包含这三个词。如果少了一个（比如年份不对，或者没写 LlamaFactory），就算违规。

Task 2: 确定“搜查范围” (获取输入参数)

程序启动时，会看你给了它哪些文件夹路径。 * 代码位置: for check_dir in sys.argv[1:]: * 含义: 当你在命令行运行这个脚本时（例如 python check_license.py src tests），src 和 tests 就是要搜查的文件夹。

Task 3: 锁定“嫌疑目标” (寻找 .py 文件)

它需要在文件夹里找出所有的 Python 源代码文件，忽略其他类型的文件（如图片、文档）。 * 代码位置: path_list.extend(Path(check_dir).glob("**/*.py")) * 含义: * glob("**/*.py"): 这是一个递归搜索，意思是“不管藏在多深的子文件夹里，只要是以 .py 结尾的文件，都给我找出来”。 * path_list: 把找到的所有文件路径存到一个名单里。

Task 4: 逐个“审讯” (读取文件内容)

现在名单有了，开始一个一个打开看。 * 代码位置: python for path in path_list: with open(path.absolute(), encoding="utf-8") as f: file_content = f.read().strip().split("\n") * 含义: 打开文件，读取所有内容，并把内容按行切割。file_content[0] 就是文件的第一行。

Task 5: 排除“空壳” (跳过空文件)

如果文件是空的，或者第一行就是空的，就不检查了。 * 代码位置: if not file_content[0]: continue * 含义: 防止程序因为读取空文件而出错，直接跳过进入下一个文件。

Task 6: 核验“身份证明” (断言检查)

这是最关键的一步。它会打印正在检查哪个文件，然后进行验证。 * 代码位置: python print(f"Check license: {path}") assert all(keyword in file_content[0] for keyword in KEYWORDS), f"File {path} does not contain license." * 含义: * print: 告诉你“我正在查这个文件哦”。 * assert all(...): 这是一个“断言”。它会检查文件的第一行是否同时包含 Task 1 中定义的三个关键词（Copyright, 2025, LlamaFactory）。 * 结果: * 如果包含: 顺利通过，继续查下一个文件。 * 如果不包含: 程序直接崩溃 (报错)，并抛出那句狠话：File ... does not contain license.（该文件没有版权声明）。

总结

这个脚本就像一个工厂门口的保安： 1. 接指令：老板说去查 A 区和 B 区（命令行参数）。 2. 找人：找出所有穿工服的人（.py 文件）。 3. 查证件：看每个人胸牌的第一行是不是写着“LlamaFactory 2025 Copyright”。 4. 处理：有一个人没写，立马拉响警报（报错），停止生产线。
