docker/docker-cuda/README.md

这份文档其实是一份操作手册。它的核心目的是：教你如何在 Docker（一种虚拟化环境）里运行 LLaMA Factory（一个 AI 模型训练工具），并且必须让这个 Docker 能用到你电脑上的 NVIDIA 显卡（GPU）。

如果不做这些配置，Docker 就像一个与世隔绝的房间，它看不到你昂贵的显卡，也就没法跑 AI 训练。

为了让你更容易理解，我把你当作一个装修工，我们要在一个空房间（Linux 系统）里搭建一个能做满汉全席（跑 AI）的高级厨房（Docker 容器）。

下面是按顺序执行的 To-Do List (任务清单)：

第一阶段：打地基（安装必要软件）

这一部分对应文档中的 Prerequisites（先决条件）。

  • [ ] Task 1: 安装 Docker (厨房外壳)

    • 原文对应: Docker: The container runtime
    • 解释: 你得先有 Docker 这个软件。这就像你得先盖好厨房的房子。
    • 操作: 在你的 Linux 系统里运行 sudo apt-get install docker.io。

  • [ ] Task 2: 安装 Docker Compose (自动装修图纸)

    • 原文对应: Docker Compose
    • 解释: 这是一个能让你“一键启动”的工具，不用每次都手动敲一堆命令。
    • 操作: 运行 sudo apt-get install docker-compose。

  • [ ] Task 3: 安装 NVIDIA Container Toolkit (打通显卡的管道) 这是最重要的一步！

    • 原文对应: NVIDIA Container Toolkit
    • 解释: Docker 默认是“瞎”的，它看不见你电脑上的显卡。这个工具就像是一根连接线，把物理显卡插进虚拟的 Docker 厨房里。如果不装这个，你的 AI 跑不起来。
    • 操作: 按照文档里的一长串命令（curl ... 和 sudo apt-get install ...）执行，最后别忘了重启 Docker (sudo systemctl restart docker)。

第二阶段：验收测试（确认显卡能用）

这一部分对应文档中的 Verify GPU Access（验证 GPU 访问）。

  • [ ] Task 4: 测试显卡连接
    • 原文对应: sudo docker run --rm --gpus all ... nvidia-smi
    • 解释: 就像装修完先开灯试试亮不亮。这条命令会启动一个小容器，并在里面运行 nvidia-smi（查看显卡信息的命令）。
    • 成功标志: 如果你在屏幕上看到了显卡的型号和显存信息，说明“管道”接通了。

第三阶段：正式开工（启动 LLaMA Factory）

这一部分对应文档中的 Usage（使用方法）。文档提供了两种方法，建议用第一种。

  • [ ] Task 5: 启动环境 (推荐方法)

    • 原文对应: Using Docker Compose (Recommended)
    • 解释: 利用刚才装的 Docker Compose，按照预设的配置一键启动。
    • 操作:
      1. 进入目录：cd docker/docker-cuda/
      2. 后台启动：docker compose up -d (这会自动下载镜像并运行)
      3. 进入容器内部：docker compose exec llamafactory bash (现在你就进入到配置好的 AI 环境里了)。

  • [ ] (备选) Task 5-B: 手动构建并启动 (如果你不想用 Compose)

    • 原文对应: Using Docker Run
    • 解释: 这是“硬核模式”。你自己手动打包镜像 (docker build)，然后手动写很长的命令来运行它 (docker run ...)。
    • 注意: 除非 Task 5 失败，否则通常不需要看这一节。

第四阶段：故障排查（如果出问题）

这一部分对应文档中的 Troubleshooting（疑难解答）。

  • [ ] Task 6: 检查为何找不到显卡

    • 原文对应: GPU Not Detected
    • 解释: 如果进到容器里发现没显卡，检查 Task 3 做没做？Docker 重启了吗？宿主机的显卡驱动装好了吗？

  • [ ] Task 7: 解决权限报错

    • 原文对应: Permission Denied
    • 解释: 如果提示你没权限运行 Docker，需要把你当前的用户加到 docker 用户组里。
    • 操作: sudo usermod -aG docker $USER，然后注销重新登录。

总结

这份文件的核心逻辑就是： 1. 装 Docker。 2. 装 NVIDIA 插件（让 Docker 能用显卡）。 3. 测试一下显卡能不能用。 4. 用 docker compose 一键启动 LLaMA Factory。
