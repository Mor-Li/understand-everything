tests/llamafy_qwen.py

这份代码的核心功能非常简单：它是一个“翻译器”。

它的作用是将 Qwen（千问） 模型的文件格式，转换成 LLaMA2 模型的格式。

为什么要这么做？ 因为很多开源工具（比如某些推理引擎、微调框架）原生支持 LLaMA 格式非常完美，但可能还不支持 Qwen。把 Qwen “伪装”成 LLaMA，就可以直接用那些工具了。

为了让你看懂，我把这个脚本的工作流程拆解成一个 “搬家重组”的 To-Do List（任务清单）。想象你正在把一架乐高积木（Qwen）拆散，按照另一张图纸（LLaMA）重新拼装起来。

📋 任务清单 (To-Do List)

  1. 准备工作：检查工具包版本，创建存放新模型的文件夹。
  2. 核心任务 A：搬运和改装零件 (权重转换 save_weight)
    • 2.1 从旧仓库（Qwen文件夹）把所有零件（权重）搬出来。
    • 2.2 关键步骤：给零件改名、拆分或重组（映射字典）。
      • 简单的：直接改名（贴新标签）。
      • 复杂的：把合在一起的零件切开（比如 Q、K、V 矩阵）。
    • 2.3 把改装好的零件打包（分块 Sharding）。
    • 2.4 把新零件存入新仓库。
  3. 核心任务 B：修改说明书 (配置转换 save_config)
    • 3.1 读取旧说明书 (config.json)。
    • 3.2 填写一张新的 LLaMA 格式说明书表格。
    • 3.3 保存新说明书。

🧐 逐步详细讲解

下面我按照上面的清单，结合代码给你讲讲它具体干了啥。

1. 准备工作

代码的入口在最下面 if __name__ == "__main__":，它用了一个叫 fire 的库来把函数变成命令行工具。 主函数 llamafy_qwen 做了第一件事：

os.makedirs(output_dir, exist_ok=False) # 创建输出目录，如果已存在就报错

这就好比：“先把新房子打扫干净，准备搬进去。”

2. 核心任务 A：搬运和改装零件 (save_weight 函数)

这是整个脚本最难也最重要的部分。

2.1 加载旧权重

# 遍历输入目录，加载所有的 .safetensors 文件
for filepath in tqdm(os.listdir(input_dir)...):
    with safe_open(...) as f:
        # 把旧模型的参数全部读到一个大字典 qwen_state_dict 里
        qwen_state_dict[key] = f.get_tensor(key)

解释：把 Qwen 模型的所有参数（比如神经网络的权重矩阵）全部读到内存里。

2.2 转换逻辑 (最核心的循环) 代码开始遍历 qwen_state_dict，然后往 llama2_state_dict (新字典) 里填东西。这里充满了 if...elif...，这就是在做映射。

  • 简单改名：

    • Qwen 叫 wte (Word Token Embeddings)，LLaMA 叫 model.embed_tokens.weight。
    • Qwen 叫 ln_f (Final Layer Norm)，LLaMA 叫 model.norm.weight。
    • Qwen 的层叫 transformer.h，LLaMA 叫 model.layers。

  • 复杂拆解 (Attention 部分)： Qwen 的注意力机制（Attention）把 Query(Q), Key(K), Value(V) 三个矩阵拼在了一起，叫 c_attn。但 LLaMA 要求它们是分开的。 python if "attn.c_attn" in key: proj_size = value.size(0) // 3 # 算出总长度的三分之一 # 切第一段给 Q llama2_state_dict[key.replace("attn.c_attn", "self_attn.q_proj")] = value[:proj_size, ...] # 切第二段给 K llama2_state_dict[key.replace("attn.c_attn", "self_attn.k_proj")] = value[proj_size : 2 * proj_size, ...] # 切第三段给 V llama2_state_dict[key.replace("attn.c_attn", "self_attn.v_proj")] = value[2 * proj_size :, ...] 解释：就像 Qwen 把洗发水、护发素、沐浴露装在一个大瓶子里，而 LLaMA 需要三个小瓶子。所以代码要把大张量切成三份。

  • 其他改名：

    • mlp.w1 -> mlp.up_proj
    • mlp.w2 -> mlp.gate_proj
    • mlp.c_proj -> mlp.down_proj
    • 这些都是前馈神经网络（MLP）部分的权重改名，对应 LLaMA 的命名规范。

2.3 & 2.4 打包与保存

# 切分文件（如果模型太大，比如14B，一个文件存不下，要切成多个 shard）

解释：把转换好的新字典保存成文件，如果文件太大就切分成 model-00001-of-00003.safetensors 这种格式。

3. 核心任务 B：修改说明书 (save_config 函数)

模型光有权重（肌肉）不行，还得有配置（大脑设定），告诉程序多少层、多大维度。

# 读取 Qwen 的配置
with open(os.path.join(input_dir, CONFIG_NAME), "r"...) as f:
    qwen_config_dict: Dict[str, Any] = json.load(f)

# 创建一个新的 LLaMA 配置字典
llama2_config_dict["architectures"] = ["LlamaForCausalLM"] # 关键！告诉HF这是LLaMA
llama2_config_dict["model_type"] = "llama"                 # 关键！类型设为 llama

关键的数学转换：

# Qwen 的 intermediate_size (中间层大小) 和 LLaMA 的定义可能有一倍的差距
llama2_config_dict["intermediate_size"] = qwen_config_dict["intermediate_size"] // 2

# 计算 KV heads 的数量
llama2_config_dict["num_key_value_heads"] = qwen_config_dict["hidden_size"] // qwen_config_dict["kv_channels"]

解释：这里主要是把 Qwen config.json 里的参数值，填到 LLaMA 能够识别的字段名里。有些数值定义不一样（比如除以2），需要做简单的数学运算。

总结

这个脚本就是把 Qwen 模型做了一次 “整容手术”： 1. 把骨架（权重 Tensor）拆开、重组、改名，变成 LLaMA 的骨架。 2. 把身份证（Config）上的名字和参数改成 LLaMA 的格式。

执行完这个脚本后，你得到的文件夹里的模型，对于 HuggingFace Transformers 库来说，就是一个标准的 LLaMA 模型了。
