src/llmtuner/webui/components

这里是 src/llmtuner/webui/components 文件夹的通俗导览。

1. 这个文件夹主要负责什么？（核心定位）

如果把整个 WebUI（网页界面）比作一套房子，那么这个 components 文件夹就是“装修队”。

  • 它的核心任务：画界面。
  • 它不负责思考（那是由后台引擎负责的），它只负责摆放家具：这里放一个按钮，那里放一个输入框，中间放一个图表。
  • 它把网页分成了不同的“房间”（标签页），每个 Python 文件负责装修其中一个房间。

2. 各个文件的分工（房间介绍）

这些文件大多对应网页上的一个标签页 (Tab) 或者一个通用组件。我们可以把它们看作不同的“功能区”：

  • top.py（顶部控制台）

    • 角色：这是房子的总电闸和导航栏。
    • 作用：画出网页最上面那一排。你在这里选择“我要训练哪个模型”、“用中文还是英文”、“模型文件在哪”。它是全局的设置区。

  • train.py（训练房 / 健身房）

    • 角色：这是教 AI 读书认字的地方。
    • 作用：画出“训练”标签页。里面摆满了调节参数的旋钮（学习率、轮数），还有一个“开始训练”的大按钮，以及显示训练进度（Loss曲线）的屏幕。

  • infer.py（聊天室）

    • 角色：这是检验 AI 学习成果的会客室。
    • 作用：画出“推理/聊天”标签页。这里有加载模型的开关，以及和 AI 对话的区域。

  • eval.py（考场）

    • 角色：这是给 AI 进行标准化考试的地方。
    • 作用：画出“评估”标签页。你在这里选择考卷（数据集），系统会自动给 AI 打分，看它聪不聪明。

  • data.py（图书档案室）

    • 角色：这是检查教材的地方。
    • 作用：画出数据集预览窗口。防止你拿错书，它允许你在训练前先看一眼数据文件里写了啥。

  • export.py（打包发货区）

    • 角色：这是把训练好的 AI 打包带走的地方。
    • 作用：画出“导出”标签页。当你训练满意了，在这里点击按钮，把模型合并、压缩，保存成文件，方便以后使用。

  • chatbot.py（对讲机组件）

    • 角色：这是一个通用零件。
    • 作用：它专门负责画那个“一问一答”的聊天气泡窗口。infer.py（聊天室）里用的那个聊天框，就是从这里拿过去的。

  • __init__.py（菜单/大堂经理）

    • 角色：对外接口。
    • 作用：它不干活，它只负责把上面这些“房间”整理好，方便主程序一次性调用。

3. 子文件夹的作用

(注：根据你提供的列表，当前目录下没有子文件夹，只有文件。如果未来有，通常也是存放更细碎的 UI 小零件。)

4. 高层认知（一句话总结）

src/llmtuner/webui/components 就是一个“Gradio 界面组件库”。

只要你想修改网页上“长什么样”（比如加个按钮、改个文字、换个布局），或者想知道某个按钮点了之后“触发了什么命令”，就来这个文件夹里找对应的文件。
