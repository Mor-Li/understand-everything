src/llmtuner/train/sft/metric.py

这份代码文件的核心作用就像是一位“阅卷老师”。

在训练大模型（SFT，有监督微调）时，模型会生成一些答案，我们需要知道它回答得好不好。这个文件就是用来给模型生成的答案打分的。

为了让你更容易理解，我把它拆解成一个“阅卷流程 To-Do List”，每一步对应代码里的一个动作：

阅卷流程 To-Do List

  1. 准备工具箱 (引入依赖)
  2. 接收考卷 (获取模型预测值和标准答案)
  3. 清理涂改痕迹 (处理特殊标记)
  4. 翻译天书 (将数字编号转回文字)
  5. 逐题批改 (循环处理每一条数据)
    • 5.1 切分词语 (中文分词)
    • 5.2 计算 ROUGE 分数 (查全率/内容覆盖度)
    • 5.3 计算 BLEU 分数 (准确率/翻译流畅度)
  6. 计算平均分 (输出最终成绩)

详细步骤讲解

1. 准备工具箱 (Imports)

代码最开头的一堆 import。 * 观点：要批改中文作业，得有懂中文的工具。 * 解释：代码引入了 jieba（用来把中文句子切成词）、nltk（算 BLEU 分）、rouge_chinese（算 ROUGE 分）。如果没有这些库，阅卷老师就“罢工”了。

2. 接收考卷 (__call__ 函数入口)

def __call__(self, eval_preds: Sequence[Union[np.ndarray, Tuple[np.ndarray]]]) -> Dict[str, float]:
    preds, labels = eval_preds
  • 观点：拿到模型写的答案（preds）和标准答案（labels）。
  • 解释：这里的输入全是数字（Token IDs），因为计算机只认识数字，不认识汉字。

3. 清理涂改痕迹 (处理 IGNORE_INDEX)

preds = np.where(preds != IGNORE_INDEX, preds, self.tokenizer.pad_token_id)
labels = np.where(labels != IGNORE_INDEX, labels, self.tokenizer.pad_token_id)
  • 观点：训练时有些不需要关注的地方被标记为 -100 (即 IGNORE_INDEX)，如果不处理，转换成文字时会报错。
  • 解释：这步把那些“忽略标记”替换成“填充标记”（Pad Token），相当于把试卷上的墨团擦干净，变成空白，防止后面翻译出错。

4. 翻译天书 (Batch Decode)

decoded_preds = self.tokenizer.batch_decode(preds, skip_special_tokens=True)
decoded_labels = self.tokenizer.batch_decode(labels, skip_special_tokens=True)
  • 观点：把数字还原成人类能读懂的文字。
  • 解释：
    • 比如 [101, 234, 567] -> 变成 "今天天气不错"。
    • skip_special_tokens=True 意思是去掉那些 <s>, <pad> 等计算机专用的符号，只留内容。

5. 逐题批改 (Loop & Jieba)

for pred, label in zip(decoded_preds, decoded_labels):
    hypothesis = list(jieba.cut(pred))
    reference = list(jieba.cut(label))
  • 观点：中文不像英文有空格，必须先把句子切成词，才能对比相似度。
  • 解释：
    • 模型写的："我喜欢吃苹果" -> 切分后：['我', '喜欢', '吃', '苹果']
    • 标准答案："我爱吃苹果" -> 切分后：['我', '爱', '吃', '苹果']
    • 这一步用了 jieba.cut，这是中文NLP里最关键的一步。

5.2 计算 ROUGE 分数

rouge = Rouge()
scores = rouge.get_scores(" ".join(hypothesis), " ".join(reference))
  • 观点：看看模型写的答案里，包含了多少标准答案的关键词（侧重“召回率”）。
  • 解释：
    • Rouge-1: 单个词重合了多少？
    • Rouge-2: 连续两个词重合了多少？
    • Rouge-L: 最长的一串公共词有多长？
    • 如果句子是空的，就直接给 0 分。

5.3 计算 BLEU 分数

bleu_score = sentence_bleu([list(label)], list(pred), smoothing_function=SmoothingFunction().method3)
  • 观点：看看模型写的句子有多像人话，是否准确（侧重“精确度”）。
  • 解释：BLEU-4 原本是用来评价机器翻译好坏的，现在常用来评价大模型生成的文本是否通顺、准确。

6. 计算平均分 (Return Mean)

return {k: float(np.mean(v)) for k, v in score_dict.items()}
  • 观点：不能只看一道题的分数，要看全班（整个Batch）的平均分。
  • 解释：代码把这一批次里所有句子的 ROUGE-1, ROUGE-2, ROUGE-L, BLEU-4 分数分别加起来求平均值，最后返回给训练器，告诉它：“你这一轮训练，考了多少分”。

总结

这个脚本就是一个“中文文本评分器”。它把模型输出的数字转成中文，切词，然后对比标准答案，算出 ROUGE 和 BLEU 分数，用来衡量模型训练的效果好坏。
