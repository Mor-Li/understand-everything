src

这里是 src 目录的“向导手册”。

如果把整个项目比作一辆超级跑车，那么 src 目录就是这辆车的驾驶室。你以后操作这辆车（训练模型、测试模型、聊天），基本都是坐在这个目录里，按下不同的“按钮”（运行脚本）。

1. 🏎️ 当前文件夹 (src) 是干嘛的？

核心定位：操作台 / 启动中心

虽然这里叫 src (Source Code 源代码)，但对于你（用户）来说，这里存放的其实是一堆“启动脚本”。

这层目录下的文件基本不包含复杂的算法逻辑（算法都藏在子文件夹里），它们的作用只有一个：接收你的指令，然后去唤醒后台的引擎开始干活。

2. 🔘 各个“按钮” (直接文件) 是干什么的？

为了方便理解，我把这些 Python 文件分成了三类按钮：

第一类：让模型“上学” (训练相关)

  • 📄 train_web.py (傻瓜模式)
    • 比喻：触屏控制板。
    • 作用：运行它，会弹出一个网页。你可以在网页上点点鼠标，就能开始训练模型。不需要敲复杂的代码，适合新手。
  • 📄 train_bash.py (专家模式)
    • 比喻：工业控制台。
    • 作用：这是给喜欢用命令行（黑框框）的高手准备的。它不弹网页，直接读取你的命令参数开始训练。适合需要批量自动化运行的场景。

第二类：和模型“聊天” (使用相关)

  • 📄 web_demo.py (网页聊天)
    • 比喻：接待前台。
    • 作用：启动一个网页，让你像用 ChatGPT 一样，在浏览器里和你的模型打字聊天。
  • 📄 cli_demo.py (黑框聊天)
    • 比喻：对讲机。
    • 作用：在终端（命令行）里直接和模型聊天。没有花哨的界面，只有纯文字，速度快，极客最爱。
  • 📄 api_demo.py (后台服务)
    • 比喻：外卖窗口。
    • 作用：把模型变成一个 API 服务。它不给人直接看，而是给其他程序（比如你写的另一个 APP）调用的。

第三类：杂项工具 (辅助功能)

  • 📄 evaluate.py (考试)
    • 比喻：阅卷机。
    • 作用：给模型发一套试卷（测试集），算算它能考多少分，看看训练效果好不好。
  • 📄 export_model.py (打包)
    • 比喻：封装车间。
    • 作用：当你用 LoRA（一种微调技术）训练完后，模型是“本体+补丁”的状态。这个脚本负责把补丁永久“焊”在本体上，导出一个完整的、可以直接使用的模型文件。

3. 📂 子文件夹 (llmtuner) 是什么？

  • 📁 llmtuner/
    • 比喻：引擎室 / 核心黑盒。
    • 作用：这是整个项目的心脏。上面提到的所有 .py 文件，最后都会去调用这里的代码。所有的脏活累活（加载数据、计算梯度、模型架构）都在这里面完成。
    • 注意：作为驾驶员（用户），你通常不需要打开这里修引擎，你只需要在外面按按钮（运行 src 下的脚本）就行。

💡 高层认知：一句话理解 src

src 目录就是你的“遥控器”。

  • 你想训练？按 train_web.py。
  • 你想聊天？按 web_demo.py。
  • 你想打包？按 export_model.py。

你不需要知道遥控器内部的电路板（llmtuner）是怎么焊的，你只需要知道按哪个键能实现什么功能。
