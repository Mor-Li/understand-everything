data/README_zh.md

别担心，这段文档其实就是一本“如何把你的数据喂给 AI 吃”的操作手册。它主要讲了两件事：你的数据文件应该长什么样，以及怎么在配置文件里登记你的数据。

为了让你更容易理解，我把它拆解成一个 4 步走的 To-Do List（任务清单）。你只需要按照这个顺序一步步来即可。

📋 任务清单 (To-Do List)

  1. 【准备食材】决定你的数据格式：看看你的数据适合“一问一答”模式（Alpaca），还是“多轮对话”模式（ShareGPT）。
  2. 【清洗食材】把数据整理成 JSON 文件：根据上一步的选择，把你的文本整理成符合规范的 JSON 格式。
  3. 【写菜单】配置 dataset_info.json：告诉系统你的文件名叫什么，里面的每一列数据代表什么意思。
  4. 【开始做菜】启动训练：在运行命令时指定你的数据集名称。

详细步骤讲解

🟢 Task 1：【准备食材】决定数据格式

这个项目支持两种主流的数据格式。你需要看你手头的数据长什么样：

  • 选项 A：Alpaca 格式（最常用，适合指令微调）
    • 场景：你需要模型完成具体的指令，或者简单的一问一答。
    • 结构：包含“指令”、“输入（可选）”、“回答”。
  • 选项 B：ShareGPT 格式（适合多轮对话）
    • 场景：你想训练模型像 ChatGPT 那样进行连续的对话。
    • 结构：包含一个列表，模拟“人类说一句，AI 回一句”的过程。

🟢 Task 2：【清洗食材】整理数据文件

选好格式后，你需要把你的数据存成一个 .json 文件（比如 my_data.json）。

如果你选了 A (Alpaca 格式)： 你的文件内容应该长这样：

[
  {
    "instruction": "请把这句话翻译成英文", 
    "input": "今天天气真好。",
    "output": "The weather is nice today."
  },
  {
    "instruction": "介绍一下你自己",
    "input": "",
    "output": "我是你训练出来的 AI 助手。"
  }
]
  • instruction: 用户给的命令。
  • input: 补充信息（没有可以留空）。
  • output: 你希望 AI 学会的标准答案。

如果你选了 B (ShareGPT 格式)： 你的文件内容应该长这样：

[
  {
    "conversations": [
      { "from": "human", "value": "你好" },
      { "from": "gpt", "value": "你好！有什么我可以帮你的吗？" },
      { "from": "human", "value": "讲个笑话" },
      { "from": "gpt", "value": "有一天..." }
    ]
  }
]
  • from: 说话的人是谁（human 代表人，gpt 代表模型）。
  • value: 说话的内容。

🟢 Task 3：【写菜单】配置 dataset_info.json

这是最关键的一步，也是文档里代码最多的地方。你需要打开项目里的 dataset_info.json 文件，在里面添加一段代码，告诉程序怎么读你刚才准备好的 my_data.json。

假设给你的数据集起个名字叫 "我的自定义数据"，你需要添加如下内容：

"我的自定义数据": {
  "file_name": "my_data.json",  // 1. 告诉程序你的文件在哪
  "formatting": "alpaca",       // 2. 告诉程序这是 Alpaca 格式 (如果是 ShareGPT 就填 sharegpt)

  // 3. columns (列映射)：这是为了把你的字段名和系统默认的字段名对上号
  "columns": {
    "prompt": "instruction",    // 系统里的 prompt 对应你文件里的 instruction
    "query": "input",           // 系统里的 query 对应你文件里的 input
    "response": "output"        // 系统里的 response 对应你文件里的 output
  }
}

为什么要写 columns？ 假如你的数据文件里用的不是 instruction，而是用的 question 这个词，那你就在这里写 "prompt": "question"。这样系统就懂了：“哦，原来这一列就是问题啊”。

🟢 Task 4：【开始做菜】使用数据

配置好之后，当你运行训练脚本时，只需要加上这个参数：

--dataset 我的自定义数据

程序就会自动去 dataset_info.json 里找 "我的自定义数据"，然后根据你写的配置去读取 my_data.json，最后开始训练。

总结一下文中的几个“高级概念”（看不懂可以先跳过）

  1. History (历史对话)：在 Alpaca 格式里，如果你想加入之前的对话历史，可以用 history 字段。
  2. System (系统提示词)：如果你想给 AI 设定人设（比如“你是一个翻译官”），可以用 system 字段。
  3. 偏好数据集 (Ranking)：这是用来做 RLHF（强化学习）的。如果你的数据里有两个答案，一个好一个坏，用来教 AI 分辨好坏，就需要开启 "ranking": true，并且 output 里要放两个答案。

建议： 作为新手，先只关注 Task 2 中的 Alpaca 格式 和 Task 3 的基础配置 即可，跑通了再研究别的。
