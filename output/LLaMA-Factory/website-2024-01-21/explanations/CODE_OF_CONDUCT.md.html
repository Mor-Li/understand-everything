CODE_OF_CONDUCT.md

这份文件叫做 CODE_OF_CONDUCT.md，中文通常翻译为 “行为准则”。

简单来说，这就像是这个开源社区的 “班规” 或者 “家规”。它不是用来教你怎么写代码的，而是用来规定大家在社区里如何做人、如何交流，以确保这里不会出现吵架、歧视或者骚扰。

既然你想要一个 Task List（任务清单）的形式，那我们就把这份文件想象成你加入这个社区需要完成的 “入职培训清单”。

以下是为你整理的 “社区生存指南 Todo List”，我们一步步来看：

✅ Task 1: 签署“入社誓词” (Our Pledge)

原文对应部分： Our Pledge * 你需要做什么： 心理默认同意这一点。 * 这一步讲了啥： * 作为社区的一员，大家承诺要创造一个无骚扰的环境。 * 重点： 不管对方的年龄、胖瘦、残疾与否、种族、性别、性取向、宗教信仰或技术水平如何，都要一视同仁。 * 目标： 让社区保持开放、欢迎、多元和健康。

✅ Task 2: 学习“红线”与“绿线” (Our Standards)

原文对应部分： Our Standards * 你需要做什么： 记住哪些事被鼓励（绿线），哪些事绝对不能干（红线）。 * 这一步讲了啥： * 👍 鼓励的行为 (Green Flags)： * 对人友善，有同理心。 * 尊重不同的意见和经验。 * 能够优雅地接受别人的批评建议。 * 犯错要道歉，并从中吸取教训。 * 凡事多为社区整体利益着想。 * 🚫 禁止的行为 (Red Flags)： * 性骚扰： 开黄色玩笑、性暗示、追求别人。 * 网络暴力： 骂人、侮辱性评论、人身攻击、谈论敏感政治话题攻击他人。 * 人肉搜索： 未经允许公开别人的隐私（如住址、私人邮箱）。 * 任何在职场上会被认为不合适的行为。

✅ Task 3: 认识“执法者” (Enforcement Responsibilities)

原文对应部分： Enforcement Responsibilities * 你需要做什么： 知道谁是老大，谁有权管事。 * 这一步讲了啥： * 谁管事： 社区的管理者（Leaders/Maintainers）。 * 权力： 如果他们觉得你的言论或代码不符合上述规定，他们有权删除、编辑、拒绝你的评论、代码或Wiki编辑。 * 义务： 他们需要解释为什么要删你的东西（在适当的时候）。

✅ Task 4: 搞清“管辖范围” (Scope)

原文对应部分： Scope * 你需要做什么： 知道这些规矩在哪儿生效。 * 这一步讲了啥： * 哪里生效： 所有的社区空间（比如 GitHub Issue 区、讨论区）。 * 特殊情况： 如果你代表社区在外面活动（比如用官方账号发推特，或者作为代表参加线下大会），你也得遵守这些规矩。

✅ Task 5: 掌握“报警电话” (Enforcement)

原文对应部分： Enforcement * 你需要做什么： 记下举报方式。 * 这一步讲了啥： * 如果你被欺负了，或者看到别人违规，可以发邮件举报。 * 举报邮箱： hoshihiyouga AT gmail DOT com * 承诺： 管理员会保护举报人的隐私，并迅速、公正地调查。

✅ Task 6: 了解“刑法量刑” (Enforcement Guidelines)

原文对应部分： Enforcement Guidelines * 你需要做什么： 了解违规的后果，别去触碰。 * 这一步讲了啥： 管理员会根据情节轻重，按以下 4 个等级进行处罚： 1. 纠正 (Correction)： * 情节： 说了不合适的话，或者不专业。 * 后果： 私下警告你，可能会要求你公开道歉。 2. 警告 (Warning)： * 情节： 违规了一次或几次。 * 后果： 给你发正式警告。在一段时间内，禁止你和相关人员互动（包括私聊和社交媒体）。如果再犯就封号。 3. 短期封禁 (Temporary Ban)： * 情节： 严重违规，或者持续骚扰。 * 后果： 关“小黑屋”。一段时间内禁止你在社区说话或互动。 4. 永久封禁 (Permanent Ban)： * 情节： 屡教不改，骚扰个人，或者攻击特定群体。 * 后果： 彻底拉黑，永久驱逐出社区。

总结

这篇文档其实就是告诉你：在这个圈子里混，要讲文明懂礼貌，不要搞歧视和骚扰。如果你乱来，管理员有权删帖甚至封你的号。如果你被欺负了，记得发邮件告状。
