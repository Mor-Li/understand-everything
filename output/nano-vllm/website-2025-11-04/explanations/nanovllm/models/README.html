nanovllm/models

这里是 nanovllm/models 目录的“导游手册”。

这个目录是整个项目的“角色大厅”或“军火库”。

1. 🏎️ 这个文件夹主要负责什么？（核心功能）

如果把 nanovllm 整个项目比作一个赛车游戏引擎，那么 models 文件夹就是存放具体赛车设计图的地方。

  • 定义大脑结构：这里存放了不同种类大模型（如 Qwen, Llama 等）的具体网络架构。
  • 多卡并行的指挥官：它不仅定义了模型长什么样，还重点定义了“怎么切分模型”。因为这些模型太大了，必须要把它们切开放在不同的显卡（GPU）上跑，这里的代码就负责指挥“谁负责算左半边，谁负责算右半边”。

2. 📄 直接文件是干什么的？

目前的目录里只有一个核心文件：

  • qwen3.py：
    • 这是 Qwen3 (通义千问3) 模型的“施工蓝图”。
    • 它不是简单地调用库，而是用 PyTorch 从零搭建了一个 Qwen3。
    • 核心任务：它告诉电脑，一个 Qwen3 机器人由哪些零件组成（注意力机制、MLP、归一化层），以及数据流进去后，该怎么一层层处理，最后吐出预测结果。
    • 特殊技能：它内置了“分身术”（Tensor Parallelism）。代码里写满了如何把庞大的矩阵运算拆解给多个 GPU 同时处理的逻辑。

3. 📁 子文件夹的作用？

(注意：根据你提供的目录结构，当前 models 下没有子文件夹。但在类似项目中，如果有子文件夹，通常的作用如下)

  • 如果有子文件夹，它们通常是用来存放“通用零件”的（比如各种通用的 Layer 定义），或者是为了支持“其他品牌的模型”（比如一个文件夹放 Llama，一个放 Mistral）。但在目前这个结构下，所有东西都集成在 .py 文件里了。

🧠 4. 高层认知（一句话理解）

nanovllm/models 就是一本“乐高搭建指南大全”。

当你想要运行 Qwen3 时，程序就会来这里翻看 qwen3.py 这本指南，按照里面的步骤，一步步把数学公式组装成一个能思考的 AI 大脑，并且安排好各个显卡工人的分工。
