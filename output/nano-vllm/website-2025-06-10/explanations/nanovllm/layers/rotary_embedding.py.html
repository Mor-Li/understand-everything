nanovllm/layers/rotary_embedding.py

这份代码实现的是 RoPE (Rotary Positional Embedding，旋转位置编码)。这是目前大模型（如 Llama 3, Mistral, Qwen）中最主流的位置编码方式。

它的核心思想是：通过“旋转”向量的角度来表示“位置”信息，而不是像以前那样简单地把位置向量加在词向量上。

既然你觉得难懂，我们把它拆解成一个 5步的学习清单 (To-Do List)，从概念到代码逐个击破。

📋 学习任务清单 (To-Do List)

  5. Task 05：封装 (get_rope) —— 方便调用的外壳。

🚀 逐步讲解

✅ Task 01：搞懂核心概念 —— 为什么要“旋转”？

在 Transformer 里，模型需要知道“我爱你”和“你爱我”的区别，这就需要位置编码。 RoPE 的做法很巧妙： * 它把词向量想象成二维平面上的箭头。 * 第 1 个词，把箭头逆时针转 $\theta$ 度。 * 第 2 个词，把箭头逆时针转 $2\theta$ 度。 * 第 m 个词，把箭头逆时针转 $m\theta$ 度。

这样，两个词之间的相对位置，就变成了它们之间夹角的差值。代码里所有的 sin 和 cos 都是为了算这个旋转。

✅ Task 02：准备工作 (__init__) —— 预先算好“旋转角度表”

既然每个位置旋转的角度是固定的，我们不需要每次运行都算一遍，可以在模型初始化时算好存起来。

看 RotaryEmbedding 类的 __init__ 部分：

# 1. 计算频率 (inv_freq)
# 这里虽然看着复杂，其实就是在算不同维度对应的“转速”
# 有的维度转得快，有的维度转得慢 (为了捕捉长距离和短距离依赖)
inv_freq = 1.0 / (base**(torch.arange(0, self.rotary_dim, 2, dtype=torch.float) / self.rotary_dim))

# 2. 生成位置序列 (t)
# 比如 max_position_embeddings=100，这里就是 [0, 1, 2, ..., 99]
t = torch.arange(self.max_position_embeddings, dtype=torch.float)

# 3. 计算所有位置的角度 (freqs)
# 外积运算：位置 * 频率 = 最终的角度
freqs = torch.einsum("i,j -> ij", t, inv_freq)

# 4. 算出 cos 和 sin 并拼接缓存
# 既然旋转公式里要用 cos 和 sin，干脆直接算好存起来
cos = freqs.cos()
sin = freqs.sin()
cache = torch.cat((cos, sin), dim=-1)

# 5. 存入 buffer (类似存入硬盘，不会被当做模型参数更新)
self.register_buffer("cos_sin_cache", cache, persistent=False)

总结： 这一步就是造了一张巨大的“查表单”，告诉我“第 50 个词在第 4 个维度应该转多少度（对应的 cos/sin 是多少）”。

✅ Task 03：核心数学 (apply_rotary_emb) —— 怎么实施旋转？

这是文件中最上面的函数，也是最让初学者头大的数学部分。它实现了二维向量的旋转公式： $$x' = x \cos\theta - y \sin\theta$$ $$y' = x \sin\theta + y \cos\theta$$

看代码：

def apply_rotary_emb(x, cos, sin):
    # 调整 cos/sin 的形状以便广播机制运算
    cos = cos.unsqueeze(-2)
    sin = sin.unsqueeze(-2)

    # 【关键步骤】把向量 x 切成两半：x1 和 x2
    # 比如向量是 [a, b, c, d]，切成 x1=[a, b], x2=[c, d]
    # RoPE 是把向量两两配对进行旋转的
    x1, x2 = torch.chunk(x.to(torch.float32), 2, dim=-1)

    # 套用旋转公式：
    # 新的第一半 = x1 * cos - x2 * sin
    y1 = x1 * cos - x2 * sin
    # 新的第二半 = x2 * cos + x1 * sin
    y2 = x2 * cos + x1 * sin

    # 把旋转后的两半拼回去
    return torch.cat((y1, y2), dim=-1).to(x.dtype)

总结： 这个函数不管你是谁，只负责执行“旋转”这个动作。它把向量劈成两半，混合一下（乘以 sin/cos），再拼回去。

✅ Task 04：应用流程 (forward) —— 查表并旋转 Query 和 Key

这一步是模型真正跑起来时调用的地方。RoPE 只作用于 Attention 里的 Query (Q) 和 Key (K)，不作用于 Value (V)。

def forward(self, positions, query, key):
    # 1. 拿到当前这批数据的位置 ID (比如 [0, 1, 2...])
    positions = positions.flatten()

    # 2. 【查表】
    # 根据位置 ID，从刚才 init 里算好的 cache 中取出对应的 cos 和 sin
    cos_sin = self.cos_sin_cache[positions]
    cos, sin = cos_sin.chunk(2, dim=-1) # 把 cos 和 sin 分开

    # 3. 调整 Query 的形状以便计算
    query_shape = query.shape
    query = query.view(num_tokens, -1, self.head_size)

    # 4. 【执行旋转】 调用 Task 03 的函数
    # 把 Query 转一下
    query = apply_rotary_emb(query, cos, sin).view(query_shape)

    # 5. 【执行旋转】 
    # 把 Key 也转一下
    key_shape = key.shape
    key = key.view(num_tokens, -1, self.head_size)
    key = apply_rotary_emb(key, cos, sin).view(key_shape)

    # 6. 返回旋转后的 Q 和 K
    return query, key

总结： 1. 你给我 Q 和 K，以及它们的位置。 2. 我去表里查一下这个位置对应的旋转参数。 3. 把 Q 和 K 转一下。 4. 交还给你去算 Attention。

✅ Task 05：封装 (get_rope) —— 方便调用的外壳

最后这个函数只是一个工厂函数，用了 @lru_cache 装饰器。

@lru_cache(1)
def get_rope(...):
    # 如果参数一样，就直接返回之前创建好的对象，不用重复创建
    # 这是一个单例模式的变种，为了节省内存和初始化时间
    rotary_emb = RotaryEmbedding(...)
    return rotary_emb

💡 一句话总结全篇

这个文件定义了一个给向量加位置信息的组件。它不像以前那样做“加法”（Vector + Position），而是做“乘法/旋转”（Vector $\times$ Rotation Matrix），就像给钟表的指针根据时间拨动角度一样，这样模型就能更精准地理解词语的顺序了。
