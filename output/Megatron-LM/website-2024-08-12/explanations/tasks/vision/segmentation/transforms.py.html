tasks/vision/segmentation/transforms.py

这份代码看起来很长，涉及很多数学和图像处理的操作，看不懂是很正常的。

简单来说，这个文件的作用是 “数据增强” (Data Augmentation)。

想象你在教一个小孩子认“猫”。如果你只给他看这一张正脸、光线完美的猫的照片，以后他看到侧脸的猫、或者晚上光线暗的猫，可能就不认识了。 所以，我们需要把这一张照片进行各种折腾：调亮一点、调暗一点、歪着放、放大看、缩小看、甚至把颜色改得奇怪一点。这样训练出来的AI（模型）才更皮实、更聪明。

这个文件就是定义了这一系列“折腾”图片的方法。

下面我列一个 To-Do List，带你一步步拆解这些代码在干什么：

✅ Task 1: 理解核心概念 —— "变换" (Transforms)

首先你要明白，这个文件里的每一个 class（类），都是一种“折腾”图片的手法。 * 输入：一张原始图片（Image）和它的标签（Mask/Segmentation Map）。 * 输出：被“折腾”过后的图片和标签。

注意点：对于语义分割（Segmentation）任务，最重要的是图片变了，标签也要跟着变。比如图片向左翻转了，标签也要向左翻转，否则就标错了。

✅ Task 2: 给图片“加滤镜” —— PhotoMetricDistortion

代码对应：class PhotoMetricDistortion 功能：这是最复杂的一个类，它的目的是改变图片的颜色、光照，但不改变形状。

  • 步骤分解：
    1. 亮度 (Brightness)：随机把照片调亮或调暗。
    2. 对比度 (Contrast)：让黑的更黑，白的更白，或者反之。
    3. 颜色空间转换：代码里看到了 mmcv.bgr2hsv 吗？它是把图片从“红绿蓝”模式转成“色调/饱和度/亮度”模式，方便修改颜色。
    4. 饱和度 (Saturation)：让颜色更鲜艳或更平淡。
    5. 色调 (Hue)：改变颜色的基调（比如把红衣服变成轻微偏紫）。

通俗理解：就像你发朋友圈前，用修图软件随机给照片加了一堆滤镜，一会儿曝光过度，一会儿颜色发黄。这能让AI学会“不管光线颜色怎么变，猫还是猫”。

✅ Task 3: 把图片“切小块” —— RandomCrop

代码对应：class RandomCrop 功能：从大图里随机切出一块小的矩形区域。

  • 为什么要做这个？
    • 显卡内存有限，可能塞不下几千像素的大图，必须切成比如 512x512 的小块来训练。
  • 难点逻辑讲解：
    • Padding (填充)：如果你的原图比要切的大小还要小怎么办？代码里用 ImageOps.expand 给图片边缘补黑色（填充），强行凑够大小。
    • Cat Max Ratio (重要)：代码里有一个 for _ in range(10) 的循环。这是为了防止切出来的图全是“背景”（比如天空），没有我们要识别的物体。它会尝试切10次，尽量保证切出来的图里有有效的内容。

通俗理解：拿一把剪刀，闭着眼睛在照片上剪下一块正方形。如果照片太小，就先把它贴在一张大黑纸上再剪。

✅ Task 4: 忽大忽小再裁剪 —— RandomSizeAndCrop

代码对应：class RandomSizeAndCrop 功能：先缩放，再裁剪。

  • 逻辑：
    1. 先生成一个随机数（比如 0.5 到 2.0 之间）。
    2. 把图片和标签按这个比例放大或缩小 (resize)。
    3. 然后再调用上面的 RandomCrop 切一刀。

通俗理解：这就好比模拟物体“远近”的变化。放大了看（近处）和缩小了看（远处），AI都要能认出来。

✅ Task 5: 照镜子 —— RandomHorizontallyFlip

代码对应：class RandomHorizontallyFlip 功能：随机左右翻转。

  • 逻辑：
    • 扔个硬币（random.random() < 0.5），如果是正面，就把图片左右翻转。
    • 关键点：img.transpose(...) 和 mask.transpose(...) 同时执行。图片翻了，标签必须跟着翻。

通俗理解：让AI学会识别朝左看的猫，也能识别朝右看的猫。

✅ Task 6: 另一套调色工具 —— ColorJitter

代码对应： * class ColorJitter * 以及上面的 adjust_brightness, adjust_contrast 等函数。

功能：这其实是 Task 2 (PhotoMetricDistortion) 的另一种实现方式。 * PhotoMetricDistortion 更多是用 numpy 和 mmcv 库来算矩阵，速度快，主要用于工业级库。 * ColorJitter 这里是用 PIL (Python Imaging Library) 和 torchvision 来实现的，逻辑更简单直观。

逻辑：它定义了亮度、对比度、饱和度、色调四个参数，然后随机打乱顺序（np.random.shuffle），依次应用到图片上。

总结：这个文件讲了个什么故事？

这个文件就是一条流水线 (Pipeline)。

当一张训练图片进入模型之前，它会经历： 1. 忽大忽小 (RandomSizeAndCrop) 2. 随机被切一刀 (RandomCrop) 3. 随机左右翻转 (RandomHorizontallyFlip) 4. 颜色随机变异 (PhotoMetricDistortion 或 ColorJitter)

经过这一套“折磨”，原本的一张图可以变出无限种花样，喂给 AI 吃，让 AI 练就火眼金睛。
