docs/llama_mistral.md

这份文档主要是在讲：如何在 Megatron-LM 这个框架里加载、训练和推理 Llama 系列（Llama-2, Llama-3）以及 Mistral 模型。

简单来说，Megatron-LM 是一个用来训练超大模型的工具，而 Llama/Mistral 是开源界最火的模型。这个文档就是教你如何把这两个东西“嫁接”起来。

为了让你更容易理解，我把文档内容整理成了一个“任务清单 (To-Do List)”，你只需要按这个流程一步步走就行：

核心任务清单 (To-Do List)

第一阶段：准备工作 (下载)

  1. 确定模型版本：
    • 你要用 Llama-2，Llama-3，还是 Mistral-7b？
    • 注意：Mistral 目前只支持 v0.3 版本，不支持旧的 v0.1/v0.2。
  2. 申请并下载权重：
    • 去 Meta 官网或者 HuggingFace (HF) 申请下载权限。
    • 下载下来的文件通常有两种格式：Meta 原生格式 或者 HuggingFace 格式。这两种 Megatron 都支持，但处理方式略有不同。

第二阶段：环境配置 (安装依赖)

根据你选择的模型，你需要安装额外的 Python 包，否则跑不起来： * 如果是 Llama-2：确保 transformers 版本 >= 4.31.0。 * 如果是 Llama-3： * 安装 tiktoken (pip install tiktoken)。 * 从源码安装 Meta 的 llama 包（需要 git clone Meta 的仓库然后 pip install -e .）。 * 如果是 Mistral： * 安装 mistral-common (pip install mistral-common)。

第三阶段：权重转换 (最关键的一步)

你下载的模型权重（Meta格式或HF格式）是不能直接在 Megatron 里用的，必须用脚本转换成 Megatron 能读懂的格式。

  1. 找到转换脚本：
    • 使用 Megatron 源码里的 tools/checkpoint/convert.py。
  2. 设置关键参数：
    • --loader llama_mistral：告诉脚本我们要转的是 Llama/Mistral 类模型。
    • --model-size：指定模型大小（比如 llama2-7B, llama3-70B, mistral-7B 等）。
    • --target-tensor-parallel-size (TP)：这一点很重要，文档给出了参考表。
      • 7B/8B 模型通常设为 TP=1。
      • 13B 模型设为 TP=2。
      • 70B 模型设为 TP=8。
  3. 执行转换：
    • 运行命令，将输入目录（你下载的权重）转换为输出目录（Megatron 格式权重）。

第四阶段：启动模型 (运行)

转换完后，你就可以用 Megatron 的标准启动脚本来加载模型了（用于推理或微调）。

  1. 配置启动参数：
    • 文档列出了一串必须加的参数，直接复制粘贴即可。
    • 关键参数包括：
      • --tokenizer-type：Llama2Tokenizer / Llama3Tokenizer / MistralTokenizer。
      • --normalization RMSNorm：因为这些模型都用 RMSNorm。
      • --position-embedding-type rope：使用旋转位置编码。
      • --load：指向你刚才转换好的文件夹路径。

文档中的其他关键信息点

除了上面的操作步骤，文档还提到了一些值得注意的观点和数据：

  1. 实验性质提醒：

    • 文档开头和中间多次强调，目前对 Llama-3 和 Mistral 的支持还是“实验性”的 (Experimental)，意味着可能还在测试中，不一定百分百稳定。

  2. 基准测试 (Benchmark Results)：

    • 文档花了很多篇幅列出表格，对比了“原生 Llama-2 运行结果”和“Megatron 版 Llama-2 运行结果”。
    • 结论：两者的误差极小（平均误差只有 0.15%）。
    • 观点：这证明了 Megatron 的转换和推理代码是准确可靠的。虽然数值上有微小差异（主要是因为矩阵乘法处理方式、旋转位置编码的数学实现细节不同），但对模型能力没有影响。

  3. 其他 Llama 类模型：

    • 文档最后提到，像 Yi-34B 这种架构跟 Llama 很像的模型，通常也可以参考 Llama-3 的流程进行转换和加载。

总结

这篇文档就是一本“转码说明书”。它告诉你：别管你从网上下载的是什么格式的 Llama/Mistral 权重，先装好依赖，用我的脚本转成 Megatron 格式，然后加上特定的参数，你就能在 Megatron-LM 里跑起来了。
