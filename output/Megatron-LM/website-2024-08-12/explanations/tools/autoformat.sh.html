tools/autoformat.sh

这段代码看起来充满了各种符号和命令，确实容易让人头大。但其实它就像一个“自动清洁工”，专门负责把写得乱七八糟的 Python 代码整理得整整齐齐。

它的核心逻辑可以概括为：“只整理你这次修改过的、位于核心目录下的 Python 文件。”

为了让你看懂，我把这段脚本的执行逻辑拆解成一个 Task Todo List（任务清单）。脚本运行时，实际上就是在按顺序执行下面这 4 个任务：

📋 脚本执行任务清单 (Task List)

✅ Task 1: 开启“严格模式”与“啰嗦模式”

对应代码： set -euox pipefail * 这是在干嘛？ 这行代码是在给脚本立规矩。 * 严格模式 (-euo pipefail)：如果脚本里有任何一步出错了（比如找不到命令、变量没定义），立刻停止运行，不要硬撑。 * 啰嗦模式 (-x)：把你执行的每一行命令都打印在屏幕上，方便我看清楚你在干啥。 * 通俗理解： 就像告诉工人：“干活细致点，一步做错马上停手，而且每做一步都要大声汇报。”

✅ Task 2: 找出“脏衣服” (定位需要整理的文件)

对应代码：

CHANGED_FILES=$(git diff --name-only --diff-filter=d --merge-base origin/main megatron/core | grep '\.py$' || true)
  • 这是在干嘛？ 这是整个脚本最聪明的地方。它没有无脑整理所有代码，而是去寻找增量修改。
    • git diff ... origin/main：它会看你当前的代码和主分支（origin/main）相比，改动了哪些地方。
    • megatron/core：它限定了范围，只关心 megatron/core 这个文件夹下的改动。
    • grep '\.py$'：它只关心后缀是 .py 的 Python 文件。
  • 通俗理解： 就像清洁工进屋，不是把全家打扫一遍，而是只把你刚才弄乱的、扔在卧室里的衣服找出来准备洗。如果没有改动文件，这个列表就是空的。

✅ Task 3: 确定是“只检查”还是“动手修”

对应代码：

CHECK_ONLY=${CHECK_ONLY:-false}
if [[ $CHECK_ONLY == true ]]; then ...
  • 这是在干嘛？ 检查环境变量 CHECK_ONLY。
    • 如果 CHECK_ONLY=true：脚本进入“质检员”模式。它只会看代码乱不乱，如果乱了就报错，但绝对不会自动帮你改文件（添加 --check 和 --diff 参数）。这通常是在服务器自动测试（CI）时用的。
    • 如果 CHECK_ONLY=false (默认)：脚本进入“保洁员”模式。它会直接动手把乱的代码改整齐。
  • 通俗理解：
    • 模式 A (Check)：教导主任来检查卫生，发现垃圾就扣分（报错），但不帮你扫。
    • 模式 B (Format)：保洁阿姨来打扫，发现垃圾直接扫掉（自动修改代码）。

✅ Task 4: 开始干活 (调用工具)

对应代码：

if [[ -n "$CHANGED_FILES" ]]; then
    black ... $CHANGED_FILES
    isort ... $CHANGED_FILES
else
    echo Changeset is empty...
fi
  • 这是在干嘛？
    • 如果有文件变动 (if [[ -n ...]])：
      1. 运行 black：这是一个非常有名的 Python 代码格式化工具。它负责把代码的缩进、空格、换行弄得漂漂亮亮。
      2. 运行 isort：这是一个专门整理 import (导包) 语句的工具。它会把你引用的库按字母顺序排好。
    • 如果没有文件变动 (else)：
      • 直接输出一句：“没啥改动，一切安好”，然后收工。
  • 通俗理解：
    • 如果 Task 2 找到了“脏衣服”，先扔进洗衣机（black），再拿出来叠整齐（isort）。
    • 如果没找到脏衣服，就喝口茶休息。

💡 总结一下文中的核心观点

这个脚本体现了现代软件开发的一个重要理念：增量维护 (Incremental Maintenance)。

  1. 不要全量扫描：项目很大，每次都格式化几千个文件太慢了。脚本只处理 git diff 出来的差异文件，速度极快。
  2. 自动化规范：不靠人的自觉性来保持代码整洁，而是靠脚本（black 和 isort）强制执行。
  3. CI/CD 友好：通过 CHECK_ONLY 开关，这个脚本既可以在你本地电脑上帮你修代码，也可以在云端服务器上检查你有没有乱写代码。
