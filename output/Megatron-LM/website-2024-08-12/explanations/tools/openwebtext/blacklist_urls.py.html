tools/openwebtext/blacklist_urls.py

这份代码的主要目的是清洗数据。

具体来说，它是为了准备训练人工智能（比如类似GPT的模型）所需的文本数据。它会读取一大堆网址（URL），然后把那些“垃圾”或者“不合适”的网址剔除掉，最后只留下高质量的网址保存下来。

下面我按照你的要求，先列一个“任务清单 (Todo List)”，让你一眼看懂它的工作流程，然后再逐步详细讲解。

📋 脚本的任务清单 (Task List)

如果把这个脚本想象成一个图书管理员，他的工作流程是这样的：

  1. 准备工作：拿到两张“黑名单”：
    • 第一张写着禁止的网站（比如色情网站、购物网站、只有图片的网站）。
    • 第二张写着禁止的文件类型（比如 .jpg 图片, .zip 压缩包, .exe 程序）。
  2. 接收任务：从命令行读取输入文件夹路径（哪里有脏数据）和输出文件路径（洗干净的数据放哪）。
  3. 搜集文件：把输入文件夹里所有的 .txt 文件都找出来。
  4. 开始筛选（核心循环）：拿起每一个网址，按顺序做以下检查：
    • 检查 1：这个网址是不是在“网站黑名单”里？如果是 ➡️ 扔掉。
    • 检查 2：这个网址是不是在“文件类型黑名单”里？如果是 ➡️ 扔掉。
    • 检查 3：这个网址是不是太短了（少于8个字符）？如果是 ➡️ 扔掉。
    • 检查 4：这个网址格式是不是写错了（比如没有 http://）？如果是 ➡️ 扔掉。
    • 检查 5：这个网址之前是不是已经见过了（重复）？如果是 ➡️ 扔掉。
  5. 通过筛选：如果以上检查都通过，把这个网址暂时存起来。
  6. 汇报进度：每处理10万个网址，告诉老板（用户）一声：“我现在处理了多少，扔掉了多少”。
  7. 完工存档：把所有留下的“好网址”写入到最终的输出文件中。

🧐 逐步详细讲解

下面我们结合代码，一步一步看它是怎么实现上述观点的。

第一步：定义“坏人”名单 (The Blacklists)

代码的一开始花了很长的篇幅定义了两个列表。

1. 域名黑名单 (domain_blacklist)

domain_blacklist = set([
    '500px', 'amazon', 'pornhub', 'reddit', 'twitter', ...
])
  • 观点：并不是所有互联网上的文本都适合训练AI。
  • 为什么拉黑这些？
    • 色情网站 (如 pornhub)：内容不适宜。
    • 购物网站 (如 amazon, walmart)：充满了商品描述和广告，不是自然语言对话。
    • 社交媒体/图片站 (如 instagram, imgur, twitter)：通常文字很少，或者充满了标签、表情符号，且很多内容需要登录可见。
    • 二进制文件站 (如 github)：虽然有代码，但这里可能只想抓取纯文本文章。

2. 扩展名黑名单 (extentions_blacklist)

extentions_blacklist = (
    '.avi', '.jpg', '.zip', '.exe', '.pdf', ...
)
  • 观点：我们需要的是网页（HTML），而不是下载文件。
  • 为什么拉黑这些？ 训练大语言模型需要的是文字。如果你给它一个 .mp4 视频或者 .exe 安装包，它读不懂，甚至会报错。

第二步：定义判断规则 (Helper Functions)

脚本写了几个函数来执行具体的判断逻辑。

  1. domain_is_in_blacklist(url):

    • 使用了 tldextract 库。比如你给它 https://www.amazon.com/product...，它能提取出 amazon 这个核心域名，然后去黑名单里比对。

  2. extention_is_in_blacklist(url):

    • 检查网址的结尾。如果网址以 .jpg 或 .pdf 结尾，就返回 True（表示要拉黑）。

  3. url_is_malformed(url):

    • 使用正则表达式 (re 模块)。这是一串复杂的符号，用来验证一个字符串长得像不像一个标准的网址（必须有 http/https，有域名等）。如果长得不像，就是“畸形 (malformed)”的。

总结

这篇代码其实就是一个过滤器。 它认为：好的训练数据 = 合法的网址 - 色情/购物/社交网站 - 非文本文件 - 错误格式 - 重复项。
