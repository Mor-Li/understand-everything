examples/multimodal/manual_prompts.json

这份文件虽然看着全是英文和符号，但其实它一点都不复杂。它不是复杂的程序代码，而是一份“话术清单”（或者叫提示词库）。

为了让你彻底搞懂，我为你设计了一个5步走的“学习任务清单” (To-Do List)。请按照顺序，我们一步一步来解锁这份文件的含义。

✅ 任务 1：搞懂这份文件的“身份”

目标： 理解这个文件是干什么用的。

  • 背景知识： 这是一个用于多模态 AI（Multimodal AI，即能看懂图、也能读懂字的AI）的配置文件。
  • 核心概念： 这份 JSON 文件其实就是一个“指令包”。
  • 通俗解释： 想象你在训练一个刚学会看东西的机器人。你不能每次都只对它说同一个词。为了测试它是不是真的聪明，你需要用各种不同的问法来考它。这份文件里存的，就是这些“不同的问法”。

✅ 任务 2：解锁第一关 —— "Captioning"

目标： 理解文件中的第一个模块 Captioning。

  • 原文片段： json "Captioning": { ... "Describe what's happening...", "Write a short caption..." }
  • 概念翻译： Captioning 在这里指的是 “图像描述”（Image Captioning），通俗叫法是 “看图说话”。
  • 这一步在做什么？
    • 这里列出的 5 句话，都是在命令 AI：“请你看一眼这张图，然后告诉我图里有什么。”
    • 比如：
      • "Can you briefly explain what you see...?" (你能简单解释下你看到了什么吗？)
      • "Describe what's happening..." (描述一下图里正在发生什么。)
  • 总结： 这一部分是让 AI 练习概括图片内容的能力。

✅ 任务 3：解锁第二关 —— "OCR"

目标： 理解文件中的第二个模块 OCR。

  • 原文片段： json "OCR": { ... "Can you read the text...", "Transcribe all the text..." }
  • 概念翻译： OCR 是 Optical Character Recognition 的缩写，意思是 “文字识别”，通俗叫法是 “图片认字”。
  • 这一步在做什么？
    • 这里列出的 5 句话，都是在命令 AI：“不要管图里风景美不美，请把图里出现的‘文字’给我念出来。”
    • 比如：
      • "Can you read the text from image...?" (你能读出图里的字吗？)
      • "Transcribe all the text you find." (把你找到的所有字都抄写下来。)
  • 总结： 这一部分是让 AI 练习从图片中提取文字的能力。

✅ 任务 4：解锁第三关 —— "VQA"

目标： 理解文件中的第三个模块 VQA。

  • 原文片段： json "VQA": { ... "Given the image, answer the following question...", "What is the answer..." }
  • 概念翻译： VQA 是 Visual Question Answering 的缩写，意思是 “视觉问答”，通俗叫法是 “看图答题”。
  • 这一步在做什么？
    • 这就比前两步高级了。不是单纯的描述，也不是单纯的认字，而是根据图片回答具体问题。
    • 这里列出的句子通常是“前缀”，后面会接具体的问题。
    • 比如：
      • "Answer the following question: [这里会填入具体问题]" (回答以下问题：...)
      • "Given the image, answer... with few words." (看了这张图，请用简短的语言回答...)
  • 总结： 这一部分是让 AI 练习理解图片逻辑并回答特定问题的能力。

✅ 任务 5：终极总结

目标： 串联所有知识点。

现在你回头看这份文件，它其实就是把 AI 处理图片的三种主要能力分类列了出来，并给每种能力准备了几句常用的开场白：

  1. Captioning (看图说话)： 帮我概括这张图。
  2. OCR (图片认字)： 把图里的字打出来。
  3. VQA (看图答题)： 我问你答。

为什么要写这个文件？ 在开发 AI 程序时，程序员通过随机抽取这些句子作为“提示词（Prompt）”发给 AI，可以增加训练数据的丰富性，或者测试 AI 在不同提问方式下是不是都能听懂人话。
