3️⃣ 任务三：检查“身体指标” (解读 num-zeros)

目标：看懂 num-zeros 这一段。

"num-zeros": {..., "values": [2044.0, 2242.0, ..., 2436.0]}
  • 什么是 num-zeros：这通常指在计算过程中，有多少个数据（通常是梯度）变成了 0。
  • 为什么要看这个：
    • 如果是 0：说明模型可能死掉了（没有梯度更新）。
    • 如果是 几百万：说明可能所有东西都变成 0 了，训练失效。
    • 这里的数值 (~2000左右)：这是一个监控指标，用来观察模型内部是不是有异常的“稀疏”情况。在正常的大模型训练中，这个数字只要不剧烈爆炸或归零，通常只是作为一个记录。

👉 结论：指标在 2000 左右浮动，看起来比较平稳，没有出现极端的异常值。
