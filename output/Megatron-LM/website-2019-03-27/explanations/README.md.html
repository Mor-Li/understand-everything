README.md

这份文档其实是 Megatron 项目的说明书。简单来说，Megatron 是一个用来训练超大规模 AI 模型（主要是 BERT）的工具，特点是快且支持多显卡并行。

如果把这篇文档看作一个任务清单（Todo List），我们可以把它拆解成以下 4 个阶段。请按照这个顺序阅读，就能明白它在讲什么：

✅ 阶段一：搞清楚这是干嘛的 (Introduction)

任务： 确认这个项目的核心目标。 * 文档观点： 这是一个专门用来训练大型 Transformer（BERT）模型的代码库。 * 你的理解： 它的卖点是“大规模”和“高性能”。比如，他们用了 64 张 V100 显卡，只用了 3 天就训练好了 BERT Large 模型。

✅ 阶段二：准备工作环境 (Setup)

任务： 在你的电脑/服务器上配置好运行环境。 * 步骤 1： 必须使用 Python 3.6。 * 步骤 2： 安装 PyTorch（带 GPU 支持的版本）。 * 步骤 3： 安装依赖包。文档建议创建一个虚拟环境（virtualenv）来隔离环境，避免弄坏你电脑里现有的设置。 * 核心指令： pip install -r requirements.txt

✅ 阶段三：准备训练数据 (Collecting Wikipedia Training Data)

任务： 只有代码没用，你得给模型“喂”书读。这里教你怎么准备数据。 * 步骤 1： 下载维基百科（Wikipedia）的数据包。 * 步骤 2： 使用一个叫 WikiExtractor.py 的工具把数据提取出来。 * 步骤 3： 关键点： 要把数据存成 json 格式（每行一个 json 对象），因为这个代码库最喜欢吃这种格式的数据。 * 步骤 4： 如果内存不够大，记得开启 --lazy-loader 选项，这样数据会从硬盘慢慢读，不会撑爆内存。

✅ 阶段四：开始训练 (Usage)

任务： 选一种方式启动训练。文档提供了 4 种 不同的启动脚本（就像菜谱），你可以根据需求选一个：

  1. 新手/调试模式 (BERT Pretraining)

    • 适用场景： 你只有一张显卡，或者只是想跑通代码试试看，不是为了真正训练大模型。
    • 操作： 运行 bash scripts/pretrain_bert.sh。
    • 细节： 文档中间那一大段代码（python pretrain_bert.py ...）就是具体的参数设置，比如层数（24层）、隐藏层大小（1024）等。

  2. 正经训练模式 (Distributed BERT Pretraining)

    • 适用场景： 你有多张显卡，甚至多台服务器，想搞真正的并行训练。
    • 操作： 运行 bash scripts/pretrain_bert_distributed.sh。
    • 原理： 利用 PyTorch 的分布式工具，让多张卡一起干活。

  3. 极速模式 (Distributed BERT Pretraining with TFRecords)

    • 适用场景： 你想训练得更快，减少数据处理的时间。
    • 操作： 运行 bash scripts/pretrain_bert_tfrecords_distributed.sh。
    • 原理： 把数据预先转换成 TFRecord 格式（TensorFlow 的格式），这种格式读取速度极快。

  4. 自定义字典模式 (Train Custom Sentence Piece Tokenizer...)

    • 适用场景： 你不想用 BERT 原生的字典，想用自己的分词方式（比如针对特定语言或领域）。
    • 操作： 运行 bash scripts/pretrain_bert_sentencepiece.sh。
    • 功能： 它会自动训练一个新的分词器（Tokenizer），然后用这个新字典去训练 BERT。

总结

这篇文档就是在说： 1. 我是谁： 我是 Megatron，训练 BERT 贼快。 2. 怎么装： 用 Python 3.6 和 PyTorch。 3. 怎么喂数据： 去下维基百科，转成 JSON 给我。 4. 怎么跑： 给你 4 个脚本，想单卡跑、多卡跑、还是极速跑，自己选一个执行。
