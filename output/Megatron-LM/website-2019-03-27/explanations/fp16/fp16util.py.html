fp16/fp16util.py

这份代码是早期 PyTorch 进行 混合精度训练 (Mixed Precision Training / FP16 Training) 的工具库。

简单来说，它的核心目的是：让模型跑得更快（用 FP16 半精度），但这会导致精度不够，所以需要用一套复杂的流程来保证模型能正常收敛。

为了让你看懂，我把这个文件要做的事情拆解成一个 Task Todo List，然后对应代码一步步给你讲。

核心任务清单 (Todo List)

要实现混合精度训练，我们需要完成以下步骤：

  1. [模型转换]：把神经网络的大部分层转成 FP16（半精度），因为这样计算快、省显存。
  2. [保护特殊层]：BatchNorm 层必须保持 FP32（单精度），因为在 FP16 下它极不稳定。
  3. [创建主权重]：在内存里备份一份 FP32 的“主权重 (Master Weights)”。
    • 原因：FP16 精度太低，微小的梯度更新会被忽略（下溢出），所以更新权重要在 FP32 上进行。
  4. [梯度搬运]：反向传播算出 FP16 的梯度后，把它拷贝给 FP32 的主权重。
  5. [权重同步]：优化器更新完 FP32 的主权重后，把新权重拷贝回 FP16 的模型，供下一轮使用。

逐步代码讲解

第一步：模型转换与保护特殊层

目标：把模型转成 FP16，但放过 BatchNorm 层。

代码对应： * tofp16 (类) * BN_convert_float (函数) * network_to_half (函数) * FP16Model (类)

讲解： * tofp16: 一个极其简单的层，它的作用就是把流经它的数据变成半精度 (input.half())。 * BN_convert_float: 这是一个递归函数。它会遍历模型的所有层，如果发现是 BatchNorm 层，就强制把它转回 FP32 (module.float())。这是为了防止训练崩溃。 * FP16Model: 这是一个包装器。 * 在 __init__ 里，它调用 convert_network 把你的模型转成 FP16（同时跳过 BatchNorm）。 * 在 forward 里，它会自动把输入数据转成 FP16，然后再喂给网络。

总结：这部分代码负责把你的模型变成“计算速度快但精度略低”的状态。

第二步：创建 FP32 主权重 (Master Weights)

目标：为了防止更新时精度丢失，我们需要一份高精度的权重备份。

代码对应： * prep_param_lists (函数)

讲解： 这个函数是整个流程的核心准备工作。 1. 它接收你的 FP16 模型 (model)。 2. 它提取出模型参数，然后 .clone().float().detach()。意思是：复制一份，转成 FP32，并切断与原图的联系。 3. 这就得到了 Master Params（主参数）。 4. flat_master=True 是什么？ * 这是一个性能优化技巧。它把几千个小的参数张量（Tensor）压扁（Flatten）成一个巨大的长条张量。显卡处理一大块连续内存比处理无数小碎片要快得多。

总结：现在我们有两套参数： 1. Model Params (FP16): 在显卡上跑前向/反向传播，速度快。 2. Master Params (FP32): 躺在内存里，专门等着被优化器更新，精度高。

第三步：梯度搬运 (Model Grads -> Master Grads)

目标：模型跑完反向传播后，梯度在 FP16 参数上。我们需要把这些梯度搬运到 FP32 主参数上，这样优化器才能工作。

代码对应： * model_grads_to_master_grads (函数)

讲解： * 当你调用 loss.backward() 后，FP16 的模型参数里有了 .grad（梯度）。 * 这个函数的作用就是把 FP16 的梯度值 复制 (Copy) 到 FP32 的主参数的 .grad 属性里。 * 如果开启了 flat_master，它会先把分散的 FP16 梯度拼成一个大张量，再拷过去。

第四步：权重同步 (Master Params -> Model Params)

目标：优化器（Optimizer）更新了 FP32 的主参数后，FP16 模型手里的参数就过时了。需要把更新后的值同步回去。

代码对应： * master_params_to_model_params (函数)

讲解： * 这是训练循环的最后一步。 * 优化器（比如 Adam 或 SGD）操作的是 FP32 的 master_params。 * 更新完成后，这个函数把 FP32 的新数值 复制 回 FP16 的模型参数中。 * 同样，如果用了 flat_master，它会负责把那个巨大的长条张量“解压”回原本的模型结构中。

剩下的辅助代码

  • convert_module / convert_network: 辅助函数，用于递归地把模型参数转成指定的数据类型（dtype），通常用于初始化。
  • backwards_debug_hook: 调试用的。如果有人不小心直接对主参数求导了，这个钩子会报错提醒。
  • to_python_float / clip_grad_norm: 兼容性补丁，处理不同 PyTorch 版本的差异。

整个流程图解 (Mental Model)

如果不看代码，这个文件实现的训练流程是这样的：

  1. 准备阶段:

    • 模型: FP16 (BN层除外)
    • 备份: FP32 (Master Weights)

  2. 训练循环 (Loop):

    • Forward: 输入 -> FP16模型 -> Loss
    • Backward: Loss -> 算出 FP16 梯度
    • Copy Grads: FP16 梯度 --(复制)--> FP32 梯度 (model_grads_to_master_grads)
    • Update: 优化器利用 FP32 梯度更新 FP32 Master Weights
    • Sync Weights: FP32 Master Weights --(复制)--> FP16 模型参数 (master_params_to_model_params)

这个文件 (fp16util.py) 就是提供了上述流程中复制、转换、同步所需的全部工具函数。
