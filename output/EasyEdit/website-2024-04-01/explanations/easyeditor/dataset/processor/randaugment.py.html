easyeditor/dataset/processor/randaugment.py

这个文件 randaugment.py 看起来很复杂，但其实它只做了一件事：给图片“捣乱”（数据增强）。

在训练 AI 模型时，为了让 AI 更聪明、更鲁棒（robust），我们不能只给它看原本的图片，还要给它看旋转的、变色的、模糊的图片。这个文件就是用来自动生成这些“变种”图片的。

为了让你看懂，我把它拆解成一个 5步的学习清单 (Todo List)，我们一步步来攻克。

📋 学习清单 (Task List)

  1. Task 01: 理解基础工具 (Augmentation Functions)
    • 目标：看懂那些 _func 结尾的函数是干嘛的。
  2. Task 02: 理解“强度”控制 (Level to Args)
    • 目标：看懂如何把一个数字（0-10）变成具体的旋转角度或颜色强度。
  3. Task 03: 理解配置字典 (Dictionaries)
    • 目标：看懂代码是如何把名字（String）和函数对应起来的。
  4. Task 04: 核心逻辑 (RandomAugment Class)
    • 目标：看懂它是如何随机挑选几个操作并应用在图片上的。
  5. Task 05: 视频处理 (VideoRandomAugment Class)
    • 目标：了解它是如何处理视频帧（连续图片）的。

🚀 逐步讲解

✅ Task 01: 理解基础工具 (Augmentation Functions)

文件的前半部分（大约第 15 行到 230 行）定义了一大堆函数。你可以把这些函数想象成 Photoshop 里的滤镜。

  • 几何变换类：
    • rotate_func: 旋转图片。
    • shear_x_func / shear_y_func: 错切（把图片拉斜）。
    • translate_x_func / translate_y_func: 平移（把图片上下左右挪动）。
    • cutout_func: 随机挖掉图片的一块（变成黑色）。
  • 颜色/像素变换类：
    • autocontrast_func: 自动对比度。
    • solarize_func: 曝光过度效果（像底片一样）。
    • color_func: 调整饱和度。
    • contrast_func: 调整对比度。
    • brightness_func: 调整亮度。
    • sharpness_func: 调整锐度。
    • equalize_func: 直方图均衡化（增强细节）。

重点：这些函数内部主要使用了 cv2 (OpenCV) 和 numpy 来操作像素矩阵，你不必深究每一行数学公式，只要知道输入是一张图，输出是处理后的图。

✅ Task 02: 理解“强度”控制 (Level to Args)

代码中段（大约 233 行到 290 行），有一堆 ..._level_to_args 的函数。

为什么要这个？ 因为不同的操作需要的参数不一样。 * 旋转需要的是“度数”（比如 30度）。 * 调节亮度需要的是“因子”（比如 1.5倍）。

RandAugment 的设计哲学是：用一个统一的数字 M (Magnitude, 范围通常是 0 到 10) 来控制所有操作的强度。

  • 举例 rotate_level_to_args：
    • 如果你给 level=0，它算出角度是 0度。
    • 如果你给 level=10 (MAX_LEVEL)，它算出角度是 30度。
    • 它负责把统一的“强度等级”翻译成具体的“参数”。

✅ Task 03: 理解配置字典 (Dictionaries)

大约第 293 行到 333 行，有两个字典：func_dict 和 arg_dict。

这就像是一个菜单： * func_dict: 字符串 "Rotate" -> 对应 rotate_func 函数。 * arg_dict: 字符串 "Rotate" -> 对应 rotate_level_to_args 参数计算逻辑。

这样程序就可以通过名字（String）来调用具体的功能了。

✅ Task 04: 核心逻辑 (RandomAugment Class)

这是最关键的部分（第 336 行 class RandomAugment）。这就是这整个文件的核心算法。

它的逻辑非常简单，只有三步：

  1. 初始化 (__init__):
    • 设定 N: 一次要对图片做几个操作？（比如 N=2，表示随机挑2个滤镜）。
    • 设定 M: 操作的强度是多少？（比如 M=10，表示强度拉满）。
  2. 随机选择 (get_random_ops):
    • 从菜单里随机抽取 N 个操作的名字。
  3. 执行 (__call__):
    • 拿到图片。
    • 遍历刚才抽到的操作。
    • 关键步骤：
      • 用 arg_dict 算出参数（比如算出旋转 15度）。
      • 用 func_dict 执行操作（真的去旋转图片）。
    • 返回处理好的图片。

一句话总结：每张图片进来，随机抽两张卡牌（比如“旋转”和“变亮”），按设定好的强度打出去，把图片变样。

✅ Task 05: 视频处理 (VideoRandomAugment Class)

第 362 行 class VideoRandomAugment。

视频其实就是一堆图片（Frames）叠在一起。 * 它的输入是一个 Tensor，形状通常是 (帧数, 高, 宽, 通道)。 * 它的逻辑和上面一样，区别在于它需要用 for 循环或者 map 函数，把刚才那套随机增强的逻辑应用到视频的每一帧上。 * 代码里 torch.stack 和 map 就是在做这件事：把每一帧都拿去“捣乱”一下，然后再拼回成一个视频。

总结

这篇代码讲的是：

我是一个全自动的图片/视频处理机器。给我一张图，我会根据你设定的强度（M），随机挑几个滤镜（N）加上去，吐出一张增强后的图，用来帮你的 AI 模型做训练。

你如果不做底层图像算法开发，只需要知道怎么调用 RandomAugment(N=2, M=9) 就可以了，内部的 OpenCV数学计算不需要完全看懂。
