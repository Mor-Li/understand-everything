easyeditor/models/rome/compute_v.py

这份代码 compute_v.py 是 ROME (Rank-One Model Editing) 算法的核心部分之一。

简单来说，ROME 试图把大模型看作一个键值对存储器（Key-Value Store）。 * Key (键)：代表输入的信息（例如：“埃菲尔铁塔在哪里？”）。 * Value (值)：代表输出的信息（例如：“在巴黎”）。

如果你想把知识改成“埃菲尔铁塔在罗马”，你需要计算出一个新的 Value 向量（v），使得当模型看到 Key 时，输出新的 Value。

这个文件的任务就是：计算出这个新的、能代表“在罗马”的 Value 向量。

📝 任务清单 (To-Do List)

为了计算出这个向量，代码执行了以下步骤。你可以把它想象成一个“寻找最佳修改方案”的过程：

  1. 准备数据 (Pre-processing)：

    • 把目标单词（比如 "Rome"）转换成机器能懂的编号 (Token IDs)。
    • 准备一堆句子，有的用来教模型新知识（Rewrite Prompts），有的用来防止模型变傻（KL Prompts）。

  2. 定位手术位置 (Find Lookup Index)：

    • 找到在句子中的哪个位置（哪个 Token）进行修改最合适（通常是主语的最后一个词，比如 "Tower"）。

  3. 定义优化目标 (Setup Optimization)：

    • 创建一个可以训练的变量 $\delta$ (delta)。
    • 我们的目标是找到一个完美的 $\delta$，把它加到模型某一层的输出上，就能让模型最终吐出 "Rome"。

  4. 开始寻宝 (Optimization Loop)：

    • 前向传播：让模型读句子。
    • 干预：在指定层强行加上 $\delta$。
    • 计算损失 (Loss)：
      • 让模型说 "Rome" (NLL Loss)。
      • 让模型别忘了 "香蕉是水果" (KL Loss)。
      • 让 $\delta$ 别太大 (Weight Decay)。
    • 反向传播：根据 Loss 调整 $\delta$。
    • 重复以上步骤直到 $\delta$ 完美。

  5. 计算最终向量 (Compute Right Vector)：

    • 利用刚刚算出的完美 $\delta$，通过数学公式反推出最终需要更新到模型参数里的向量 $v$。

    return cur_out

解释：这里我们不直接修改模型参数。我们假设：如果在第 layer 层，原本的输出加上一个神奇的向量 delta，模型最后就能输出 "Rome"。现在的任务就是算出这个 delta 是多少。

4. 开始寻宝 (优化循环)

for it in range(hparams.v_num_grad_steps): # 循环训练几十次
    # ...
    # 带着钩子(TraceDict) 运行模型
    with nethook.TraceDict(..., edit_output=edit_output_fn) as tr:
        logits = model(**input_tok).logits

    # 计算三个 Loss：
    # 1. nll_loss: 预测结果是不是 "Rome"？
    # 2. kl_loss: 其他句子的预测分布变了吗？(最好别变)
    # 3. weight_decay: delta 向量别太长，太长容易过拟合
    loss = nll_loss + kl_loss + weight_decay

    # 反向传播，更新 delta
    loss.backward()
    opt.step()

解释：这是一个标准的 PyTorch 训练循环。但我们训练的不是模型权重，而是那个临时变量 delta。等到循环结束，delta 就是那个“神奇向量”。

5. 计算最终向量 (解方程)

# target = 原本的输出 + 训练好的 delta
# 这就是我们希望这一层输出的“理想状态” (v_star)
target = target_init + delta.to(target_init.dtype)

# 获取原本这一层的输入(cur_input) 和 输出(cur_output)
cur_input, cur_output = get_module_input_output_at_word(...)

# 解线性方程算出 right_vector (也就是 v)
# 公式原理：我们要让 weights * input = target
# ROME 的更新公式推导后，得出 v 的计算方式如下：
right_vector = (target - cur_output) / torch.dot(cur_input, left_vector)

解释： * 我们通过优化找到了 target (理想的输出)。 * 但是我们不能直接把 target 塞进模型，我们需要修改模型的权重矩阵 $W$。 * ROME 的修改方式是 $W_{new} = W_{old} + v \cdot k^T$。 * 这里就是在根据 target 反推这个 $v$ (代码里叫 right_vector) 应该是多少。

总结

这个脚本 compute_v.py 的逻辑是：

  1. 我想让模型输出 "Rome"。
  2. 我通过梯度下降 (Optimization) 试出来：如果我在第 5 层的 "Tower" 这个词后面加上一个向量 $\delta$，模型就会输出 "Rome"。
  3. 利用这个试出来的 $\delta$，结合数学公式，算出我应该怎么修改模型的权重 (计算出向量 $v$)。
  4. 返回这个 $v$，交给后续步骤去真正修改模型参数。
