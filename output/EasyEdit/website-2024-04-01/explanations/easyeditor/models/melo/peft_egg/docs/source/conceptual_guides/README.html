这里是“理论补习班” / “概念说明书”。

2. 这个文件夹下的各个直接文件分别是干什么的？

这里有两个核心的“理论课”：

  • 📄 lora.mdx（LoRA 技术指南）

    • 作用： 它是“外挂说明书”。
    • 通俗理解： 它解释了如何通过给大模型“贴外挂”（旁路矩阵）来让模型学会新技能，而不需要动模型原本的大脑。它告诉你为什么这种方法既省显存又跑得快，以及代码配置里那些 r（秩）、target_modules 都是在调外挂的什么属性。

  • 📄 prompting.mdx（提示工程指南）

    • 作用： 它是“暗号说明书”。
    • 通俗理解： 它解释了如何通过给大模型发送“特制的暗号”（虚拟 Token / 软提示）来引导模型干活。它对比了三种发暗号的高级姿势（Prompt Tuning, Prefix Tuning, P-tuning），教你如何不动模型参数，只靠在输入里加一点“魔法咒语”就搞定任务。
