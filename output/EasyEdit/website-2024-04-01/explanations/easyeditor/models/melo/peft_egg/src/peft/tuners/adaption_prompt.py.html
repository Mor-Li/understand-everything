easyeditor/models/melo/peft_egg/src/peft/tuners/adaption_prompt.py

这份代码实现了一种叫做 Adaption Prompt (通常指 LLaMA-Adapter) 的微调技术。

简单来说，它的核心思想是：不要重新训练整个大模型，而是在模型的高层（靠近输出的层）的注意力机制（Attention）中，强行插入一些“可学习的提示词向量”，让模型学会新的任务。

为了让你看懂，我把这份代码的逻辑拆解成一个 “开发任务清单 (Todo List)”，我们模拟一下作者是如何一步步实现这个功能的。

任务清单：实现 LLaMA-Adapter 微调器

Phase 1: 准备工作 (搞定 LLaMA 的特殊数学计算)

LLaMA 模型有一种特殊的“旋转位置编码 (RoPE)”。为了计算 Attention，我们需要获取中间变量 Query (查询向量)。但 HuggingFace 的原始代码不直接返回这个，所以我们需要手动算一遍。

  • Task 1.1: 抄写 LLaMA 的旋转编码逻辑
    • llama_rotate_half: 把向量切两半翻转一下（RoPE 的数学操作）。
    • llama_apply_rotary_pos_emb: 给 Query 加上位置信息。
  • Task 1.2: 重新计算 Query 状态
    • llama_compute_query_states: 这是个关键辅助函数。因为我们需要拿原本的输入 hidden_states，重新过一遍 q_proj 层，再手动加上位置编码，算出当前的 Query。
    • 目的：后面我们要用这个 Query 去查询我们需要插入的“提示词”。

Phase 2: 定义配置 (我们要插入什么样的补丁？)

我们需要一个配置文件来告诉程序，我们要把提示词插在哪里，插多长。

  • Task 2.1: 定义配置类
    • AdaptionPromptConfig:
      • adapter_len: 插入的提示词长度是多少（比如 10 个 token）。
      • adapter_layers: 插在模型的哪几层（通常是最后几层，比如最后 30 层）。
      • target_modules: 目标模块的名字（LLaMA 里通常叫 self_attn）。

Phase 3: 核心逻辑 (制造“特洛伊木马”)

这是代码里最难懂、但最核心的部分：AdaptedAttention 类。 我们要写一个新的 Attention 层，把原始的 Attention 层包裹在里面，然后偷偷加上我们的私货。

  • Task 3.1: 初始化“私货” (Parameters)

    • self.adaption_prompt: 这是一个随机初始化的向量，形状是 [1, adapter_len, hidden_size]。这就是我们要训练的“知识”。
    • self.adaption_gate: 门控机制。初始化为 0。这很重要！
      • 为什么是0？ 刚开始训练时，门关着，模型表现和原始模型一模一样（Zero-init），保证训练稳定，然后慢慢打开门让新知识进来。

  • Task 3.2: 劫持 Forward 传播

    • Step A: 跑原始模型。先调用 self.model(**kwargs)，让原始的 Attention 算出结果 output。
    • Step B: 处理提示词。把我们的 adaption_prompt 扔进模型的 K (Key) 和 V (Value) 投影层，变成 adapter_k 和 adapter_v。
    • Step C: 计算新注意力。
      • 拿 Task 1.2 算出来的 Query，去和 adapter_k 做矩阵乘法。
      • 这步的意思是：“看看当前输入的 Query，和我们插入的提示词有多大的关联？”
    • Step D: 加权求和。
      • 算出分数后，乘以 adaption_gate (那个门)。
      • 再乘以 adapter_v。
      • 最后经过 o_proj (输出层)。
    • Step E: 融合。
      • output = output + adapter_output。
      • 把原始结果加上我们算出来的“补丁结果”，作为最终输出。

Phase 4: 管理员 (把补丁打进大模型)

最后，我们需要一个总管类 AdaptionPromptModel 来负责把上面做好的 AdaptedAttention 塞进原本的 LLM 里。

  • Task 4.1: 找到目标层
    • 遍历模型的所有层，找到最后 adapter_layers 层（比如最后 30 层的 Attention 模块）。
  • Task 4.2: 偷梁换柱 (Swapping)
    • _create_adapted_attentions:
      1. 把原始模型的 Attention 层取出来。
      2. 用 AdaptedAttention 把它包起来。
      3. 把这个包好的新层，塞回模型里去。
  • Task 4.3: 冻结参数 (Freezing)
    • _mark_only_adaption_prompts_as_trainable:
      • 把大模型原本几百亿个参数全部锁死 (requires_grad = False)。
      • 只允许我们要插入的 adaption_prompt 和 adaption_gate 进行更新。

总结：这段代码到底在干嘛？

  1. 它不改动模型原本的权重，而是像“寄生虫”一样，寄生在模型的 Attention 层上。
  2. 它在每次做 Attention 计算时，除了看原本的上下文，还会多看一眼我们训练好的 adaption_prompt。
  3. 通过一个初始化为 0 的门，控制这个 prompt 对结果的影响，让微调过程非常丝滑。

你看代码的时候，重点看 AdaptedAttention 类的 forward 函数，那里就是整个算法的灵魂。其他的代码大多是在做原来 LLaMA 架构的兼容和模块替换工作。
