easyeditor/models/pmet/compute_zs.py

这份代码文件 compute_zs.py 是 PMET (Probabilistic Model Editing with Transformer) 算法的核心部分之一。它的主要目的是计算出一个（或两个）“目标向量”。

简单来说，模型编辑通过修改模型某一层的参数（矩阵），让模型记住新的知识。为了修改这个矩阵，我们需要知道：在这个位置，模型的输出向量应该变成什么样，才能让最后输出的结果变成我们想要的那个词？

这个文件就是在通过“优化（Optimization）”的过程，反推算出这个理想的“目标向量”。

为了让你看懂，我把它拆解成一个 Task List (任务清单)，然后一步步解释。

核心任务清单 (Task List)

  1. 准备阶段 (Preparation)：
    • 提取模型参数（LM Head 权重）。
    • 把目标单词（Target Word，比如要把“巴黎”改成“罗马”）转换成 Token ID。
    • 构建输入句子（Prompts），包括用来训练的句子和用来保持稳定性的句子（KL Prompts）。
  2. 定位阶段 (Localization)：
    • 找到句子中“主语”（Subject，比如“埃菲尔铁塔”）所在的 Token 位置。我们只修改这里的隐藏状态。
  3. 初始化变量 (Initialization)：
    • 创建可以学习的变量 delta（增量）。这是我们需要通过梯度下降算出来的“修改量”。
    • PMET 算法比较特殊，它同时计算 Attention 层的增量 (delta_attn) 和 MLP 层的增量 (delta_mlp)。
  4. 定义干预函数 (Define Intervention Hook)：
    • 定义一个函数，告诉模型：“当你运行到这一层时，把刚才定义的 delta 强行加到主语的隐藏状态上”。
  5. 执行优化循环 (Optimization Loop)：
    • 前向传播：带着干预函数运行模型。
    • 计算 Loss：
      • 让模型预测出新目标（NLL Loss）。
      • 让模型在无关内容上保持不变（KL Loss）。
      • 让修改量不要太大（Weight Decay）。
    • 反向传播：更新 delta。
  6. 输出结果 (Output)：
    • 计算最终的目标向量 v* = 原始向量 + delta。

Step 3 & 4: 初始化变量与干预函数

这是最核心的部分：

# 初始化两个全零的可学习向量，requires_grad=True 表示我们要训练它们
delta_attn = torch.zeros(..., requires_grad=True)
delta_mlp = torch.zeros(..., requires_grad=True)

# 定义 Hook 函数
def edit_output_fn(cur_out, cur_layer):
    # ... 省略记录初始值代码 ...

    # 如果当前层是 MLP 层，加上 delta_mlp
    if cur_layer == hparams.mlp_module_tmp.format(layer):
        cur_out[i, idx, :] += delta_mlp

    # 如果当前层是 Attention 层，加上 delta_attn
    if cur_layer == hparams.attn_module_tmp.format(layer):
        cur_out[i, idx, :] += delta_attn
    return cur_out

观点：这里体现了 PMET 和 ROME 的区别。ROME 假设知识主要在 MLP 层，只求一个 delta。PMET 认为知识分布在 Attention 和 MLP 的输出中，所以它试图同时寻找两个最优的修正向量。

观点：函数最终返回的是 修改后的理想向量。 后续的代码（不在这个文件里）会利用这个 target_attn 和 target_mlp，通过最小二乘法（Least Squares）去反解出模型权重的更新量 $\Delta W$，从而永久修改模型。

总结

这个脚本就像是在做一个微创手术前的模拟： 1. 病人：大语言模型。 2. 手术目标：让它把“埃菲尔铁塔”和“罗马”关联起来。 3. 手术手段：在第 layer 层的 Attention 和 MLP 输出处注入电流（delta）。 4. 模拟过程 (compute_zs)：不断调整电流的大小和方向，直到病人的大脑最后能输出“罗马”，同时不影响它识别“苹果”。 5. 输出：记下这股理想的电流及其产生的状态（Target Vectors），交给下一步去修改物理线路（权重）。
