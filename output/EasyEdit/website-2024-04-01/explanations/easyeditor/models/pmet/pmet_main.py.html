easyeditor/models/pmet/pmet_main.py

这份代码实现了一个叫做 PMET (Parallel Model Editing with Transformer) 的算法。

简单来说，这个算法的目的是：给大模型做“微创手术”。 比如，模型原本认为“埃菲尔铁塔在巴黎”，你想强行修改它的参数，让它认为“埃菲尔铁塔在罗马”，但同时不能破坏模型原本的其他知识（比如不能忘了“香蕉是黄色的”）。

为了让你看懂，我把它拆解成一个 Task Todo List（任务清单），然后对照代码一步步讲。

📋 PMET 算法执行清单 (Task Todo List)

  1. 准备阶段：整理用户的修改请求（比如把“巴黎”改成“罗马”），备份模型原始参数（防止改坏了）。
  2. 计算目标 (Compute $Z$)：计算为了输出“罗马”，模型最后一层应该输出什么样的向量？（这是我们的终点）。
  3. 逐层计算输入 (Compute $K$)：在我们要修改的那些层，当前的输入信号长什么样？（这是我们的起点）。
  4. 计算更新量 (Compute Delta)：结合“起点”和“终点”，利用数学公式算出权重矩阵 $W$ 应该加多少数值（$\Delta W$）。
    • 关键点：这里引入了“协方差矩阵”，目的是确保修改只影响特定知识，不破坏其他知识。
  5. 应用修改：把算出来的 $\Delta W$ 真正加到模型的参数里。

🔍 详细代码导读 (Step-by-Step)

现在我们按照上面的清单，深入代码的细节。

第一步：入口与准备 (Function: apply_pmet_to_model)

这是整个流程的总指挥。

  • 代码位置：apply_pmet_to_model 函数开头。
  • 逻辑：
    1. if copy: model = deepcopy(model): 如果需要，先复制一个模型，别把原版搞坏了。
    2. deltas = execute_pmet(...): 核心步骤。调用执行函数，计算出权重需要变化的数值（Delta）。
    3. w[...] += upd_matrix.float(): 应用修改。把算出来的变化量加到模型原本的权重上。

第二步：核心计算流程 (Function: execute_pmet)

这是干脏活累活的地方。

2.1 整理 Prompt * 代码： python if '{}' not in request['prompt']: ... * 解释：把用户的输入格式化。比如把 "Eiffel Tower is in Paris" 变成 "{} is in Paris"，方便后续把 "Eiffel Tower" 填进去作为主语。

2.2 备份权重 * 代码： python weights = { ... nethook.get_parameter(...) } weights_copy = { ... .clone() } * 解释：把我们要修改的层（Attention层或MLP层）的权重先拿出来，并备份一份。

2.3 计算目标向量 $Z$ (Task List 第2项) * 代码： python # Compute z for final layer ... cur_z_attn, cur_z_mlp = compute_zs(...) * 解释： * 我们需要知道，如果想让模型输出“罗马”，在模型的最后一层（Z层），它的隐藏状态向量（Hidden State）应该长什么样。 * 代码里有缓存机制（cache_fname），如果以前算过就直接读取，没算过就调用 compute_zs 算。 * PMET 的特点是它可能同时修改 Attention 和 MLP 模块，所以你看到它分别处理了 cur_z_attn 和 cur_z_mlp。

第三步：逐层计算与更新 (Loop: for i, layer in enumerate(hparams.layers))

这是最复杂的循环，它一层一层地去修改模型。

3.1 计算输入向量 $K$ (Task List 第3项) * 代码： python layers_ks = compute_ks(...) * 解释： * 对于我们要修改的第 layer 层，当输入 "Eiffel Tower" 时，这一层接收到的输入信号是什么？记为 $k$。 * 我们希望：输入 $k$ $\times$ 新权重 $\approx$ 目标输出 $z$。

3.2 计算残差 (Targets) * 代码： python cur_zs = get_module_input_output_at_words(...) targets = z_list[rewrite_module_name] - cur_zs * 解释： * cur_zs 是当前这一层实际输出的值。 * targets 是我们希望它输出的值与实际输出值的差（即：我们需要填补的差距）。

3.3 获取协方差矩阵 (Covariance) * 代码： python cov = get_cov(...) * 解释： * 这是为了保护模型原有知识。 * cov 统计了模型在读大量普通文本（Wikipedia等）时，这一层的激活模式。 * 在更新公式里除以这个 cov，意思就是：“在大家通常不怎么激活的方向上多改点，在大家经常激活的重要方向上少改点，以免改坏了通用能力”。

3.4 计算更新矩阵 (The Equation) * 代码： python upd_matrix = (targets / np.sqrt(...)) @ layer_ks.T @ torch.inverse(layer_ks @ layer_ks.T + hparams.mom2_update_weight * cov.double()) * 解释： * 这就是传说中的 最小二乘法解 (Least Squares Solution)。 * 它试图找到一个矩阵 upd_matrix，使得加上它之后，输入 $k$ 能映射到目标 $z$，同时最小化对其他知识的干扰（由 cov 控制）。 * 公式逻辑：$\Delta W = \text{Error} \times k^T \times (C + \lambda I)^{-1}$。

3.5 临时应用更新 * 代码： python weights[weight_name][...] = weights_copy[weight_name] + upd_matrix.float() deltas[weight_name] = upd_matrix * 解释： * 算出这一层的更新量后，立刻把它加到模型里。 * 为什么？ 因为下一层的计算依赖于上一层的输出。如果上一层改了，传给下一层的信号也会变，所以必须边改边算。

第四步：收尾

  • 代码： python # Restore state of original model nethook.get_parameter(model, k)[...] = weights_copy[k] return deltas
  • 解释：
    • execute_pmet 函数承诺不直接永久修改传入的 model 对象（它只负责计算），所以它最后把模型恢复原状。
    • 它返回 deltas（所有层的修改量）。
    • 真正的永久修改是在最外层的 apply_pmet_to_model 里完成的。

💡 总结：这个文件到底在干嘛？

这个文件就是 PMET 算法的施工队。

  1. 它不训练模型（没有反向传播 Backpropagation）。
  2. 它用解析解（数学公式直接算）来得出权重应该改多少。
  3. 它利用了 compute_ks (算输入特征) 和 compute_zs (算目标特征)，结合 get_cov (统计特征分布)，算出最优的权重修改方案。

一句话人话总结： 它计算出了一组新的参数，强行插入到模型的 Attention 和 MLP 层中，让模型在看到特定主语（如“埃菲尔铁塔”）时，不仅能联想到新的宾语（如“罗马”），还能尽量不把脑子里的其他知识搞乱。
