tutorial-notebooks

这里是 EasyEdit 项目的“实战演练场” 或 “医学院解剖课”。

如果你想知道怎么用代码给大模型“做手术”，这一层就是你最该呆的地方。这里存放的全是 Jupyter Notebook (.ipynb) 格式的教程，你可以直接运行它们，亲手体验如何修改模型的记忆。

1. 这个文件夹（tutorial-notebooks）主要负责什么？

简单来说：这里是“大模型脑科手术”的操作指南大全。

通常我们训练好一个 AI，它的脑子就固定了。如果它记错了知识（比如以为美国总统还是奥巴马），或者你想给它植入新知识，通常很麻烦。 这个文件夹里的每一个文件，都是一个具体的实验案例，手把手教你如何使用 EasyEdit 这个工具箱，配合不同的“手术刀法”（算法），去修改不同的“病人”（模型）的记忆。

2. 这个文件夹下的各个直接文件是干什么的？

这些文件看起来多，其实命名很有规律。它们遵循 EasyEdit_Example_[手术刀法]_[病人名字].ipynb 的格式。

我们可以把它们分成几大类流派：

🔪 流派一：ROME 系列 (精准微创手术)

  • 代表文件：EasyEdit_Example_ROME.ipynb, ..._ROME_llama.ipynb, ..._ROME_qwen.ipynb 等。
  • 作用：演示使用 ROME 算法。
  • 比喻：这是一把精准的手术刀。它假设知识存在于某个特定的神经元区域。这些教程教你如何精准定位并修改某一个具体的知识点（比如把“埃菲尔铁塔在巴黎”改成“在罗马”），同时不破坏其他记忆。不同的后缀（llama, qwen, InternLM）只是换了不同的“病人”来演示。

🔦 流派二：MEMIT 系列 (批量手术)

  • 代表文件：EasyEdit_Example_MEMIT.ipynb, ..._MEMIT_llama.ipynb, ..._Qwen-7b.ipynb。
  • 作用：演示使用 MEMIT 算法。
  • 比喻：这是 ROME 的升级版，相当于激光阵列。如果你需要一次性修改成千上万条知识，用 ROME 会累死，MEMIT 可以批量处理。这些教程教你如何给模型进行大规模的知识更新。

📝 流派三：IKE 系列 (催眠/小抄流)

  • 代表文件：EasyEdit_Example_IKE.ipynb, ..._IKE_Baichuan.ipynb 等。
  • 作用：演示使用 IKE (In-Context Knowledge Editing) 方法。
  • 比喻：这其实不动刀子。它不修改模型的任何参数，而是通过给模型看一些“小抄”或“示范”（Prompt Engineering），让模型在回答时“假装”自己变了。这是一种非侵入式的疗法。

👁️ 流派四：Multimodal (给眼睛做手术)

  • 代表文件：EasyEdit_Example_Multimodal_IKE.ipynb。
  • 作用：针对多模态模型（能看图说话的 AI，如 MiniGPT-4）。
  • 比喻：教你如何修正模型对图片的理解（比如把图里的“狗”强行认成“猫”）。

🔍 流派五：KN (侦探流)

  • 代表文件：EasyEdit_Example_KN_T5.ipynb。
  • 作用：Knowledge Neurons (知识神经元)。
  • 比喻：这是做 CT 扫描。在做手术前，先教你如何找到某条知识到底藏在模型大脑的哪个位置。

3. 子文件夹的作用是什么？

  • 📁 .ipynb_checkpoints/
    • 作用：忽略它。
    • 这是 Jupyter Notebook 自动生成的“临时存档”和“垃圾桶”，里面存的是你运行代码时的自动保存版本，跟项目逻辑无关。

4. 高层认知：我该怎么理解这部分代码？

要把这部分代码看作是一个 “排列组合的菜单”：

  • 横轴是“算法（手术方案）”：你想用 ROME（改单个）、MEMIT（改批量）、还是 IKE（不动参数）？
  • 纵轴是“模型（病人）”：你想改 LLaMA、Qwen、GPT-2 还是 Baichuan？

你只需要根据你的需求，找到对应的那个 .ipynb 文件，点开它，照着里面的步骤： 1. 加载模型（把病人推上台）。 2. 设定目标（要把“A是B”改成“A是C”）。 3. 点击运行（开始动手术）。 4. 查看结果（手术成功了吗？有没有副作用？）。

这就是 tutorial-notebooks 存在的意义——让你不用懂复杂的数学公式，也能直接上手修改大模型。
