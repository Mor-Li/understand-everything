hparams/MEMIT/qwen-7b.yaml

这份文件其实是一份“手术方案”。

简单来说，它的目的是：给一个叫 Qwen-7B 的人工智能模型做“脑部手术”，修改它记忆中的某些知识。 使用的手术方法叫做 MEMIT。

为了让你能够看懂，我为你列了一个由浅入深的 学习任务清单 (Todo List)。我们把这一大堆参数拆解成几个具体的步骤来理解。

任务清单 (Task List)

✅ Task 1: 搞清楚“病人”和“手术方法”

目标：理解基本背景。 * alg_name: "MEMIT": 这是算法的名字（Mass-Editing Memory in a Transformer）。它的特长是能批量修改知识，而且不仅改得准，还能尽量不破坏模型原有的其他能力。 * model_name: "./hugging_cache/qwen-7b": 这是“病人”。我们要修改的是 Qwen-7B 这个大模型。 * device: 0: 这是手术台。指使用第 0 号 GPU 显卡来运行。

✅ Task 2: 确定“手术部位” (定位)

目标：理解我们要修改模型的哪一部分。大模型像千层饼，我们不能乱改。 * layers: [4, 5, 6, 7, 8]: 这是 MEMIT 的核心特点。它不只改一层，而是把知识分散修改在第 4 到 第 8 层。这比只改一层更稳定。 * rewrite_module_tmp: "transformer.h.{}.mlp.c_proj": 这是具体的“神经元”。 * LLM 里面主要分“注意力机制(Attention)”和“前馈网络(MLP)”。 * 研究认为 MLP 存储了事实性知识（比如“巴黎在法国”）。 * 这行代码指定了我们要修改 MLP 层的输出投影部分 (c_proj)。 * fact_token: "subject_last": 这是定位点。比如我们要改“埃隆·马斯克是推特的老板”，算法会在读到“马斯克”这个词的最后一个字（token）时进行操作。

✅ Task 3: 准备“止痛药”和“监测仪” (统计数据)

目标：理解如何防止把模型改傻了。 * 背景：如果你强行修改一个神经元，模型可能会忘记怎么说话。我们需要知道模型平时正常说话时神经元是怎么反应的。 * mom2_dataset: "wikipedia" & mom2_n_samples: 100000: 我们先让模型读 10 万条维基百科，观察它的正常反应。 * mom2_adjustment: true: 开启“协方差统计”调整。简单说，就是利用上面观察到的正常数据，来约束我们的修改，确保修改后的参数在数学上是“顺滑”的，不会突兀地破坏原有结构。 * stats_dir: 这些统计数据存放在哪。

✅ Task 4: 设定“手术精度” (优化参数)

目标：理解算法是如何计算出新参数的。这是一个数学优化过程。 * v_num_grad_steps: 25: 就像调焦距一样，为了找到最佳的修改值，算法会反复微调计算 25 次。 * v_lr: 5e-1: 学习率。调整的步子迈多大。 * kl_factor: 0.0625: 这是一个安全阀。KL 散度是衡量两个分布差异的指标。这里用来限制模型修改前后的输出差异不能太大，防止改得面目全非。 * clamp_norm_factor: 0.75: 限制修改向量的长度（Norm），也是为了防止修改力度过猛。

✅ Task 5: 识别模型的解剖结构 (模板配置)

目标：告诉程序 Qwen 模型的代码变量名叫什么。不同的模型（如 LLaMA, GPT-J）变量名不一样。 * 这些都是 Qwen 模型的内部变量命名规则，程序需要通过这些名字找到对应的代码模块： * layer_module_tmp: 层的名字模板。 * mlp_module_tmp: MLP 模块的名字。 * attn_module_tmp: 注意力模块的名字。 * ln_f_module: 最终归一化层。 * lm_head_module: 最后的输出层（决定下一个词是谁）。

总结：这份文件讲了个什么故事？

如果把这个 YAML 文件翻译成人类语言，它在说：

“嘿，程序！我们要给 Qwen-7B 做个手术。

  1. 我们要用 MEMIT 算法。
  2. 手术范围是第 4 到 8 层 的 MLP 模块。
  3. 在动手前，先去读 10万条维基百科 (mom2)，搞清楚这个脑子平时是怎么运作的，别把它搞坏了。
  4. 计算修改方案时，迭代 25次，步子大一点 (5e-1)，但要盯着 KL散度，别让它胡言乱语。
  5. 对了，Qwen 的内部器官名字叫 transformer.h...，别找错地方了。”
