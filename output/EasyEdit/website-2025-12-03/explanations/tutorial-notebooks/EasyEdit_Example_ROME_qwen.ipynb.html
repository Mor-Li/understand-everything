tutorial-notebooks/EasyEdit_Example_ROME_qwen.ipynb

这份 Notebook 是关于大模型知识编辑（Knowledge Editing）的一个实战教程。

简单来说，它的目的是：不动用大规模的重新训练，就像做“脑科手术”一样，精准地修改大模型（这里是 Qwen-7b）脑子里的某一条特定的知识。

比如：模型原本知道“埃菲尔铁塔的设计师是埃菲尔”，我们要强制把它改成“设计师是张三”，同时不影响模型回答其他问题（比如“美国首都是哪”）。

下面我为你列一个 Task Todo List，并按照这个流程一步步拆解文中的观点和代码逻辑。

📋 任务清单 (Task Todo List)

  1. [准备] 环境搭建与模型加载
    • 下载代码库，加载 Qwen-7b 模型。
  2. [配置] 设定手术参数 (Hparams)
    • 告诉程序用什么方法（ROME）、改哪一层神经元。
  3. [目标] 定义要篡改的知识
    • 设定：问题是什么？原本的真理是什么？我们要注入的“新知识”是什么？
  4. [执行] 进行模型编辑
    • 运行算法，寻找并修改模型参数。
  5. [质检] 术后效果评估 (三维测试)
    • 可靠性 (Reliability): 问它刚才改的问题，它答对了吗？
    • 泛化性 (Generalization): 换个说法问同一个知识，它能反应过来吗？
    • 局部性 (Locality): 问它不相关的问题，它变傻了吗？（有没有破坏原有知识）

💡 逐步观点解析

第一步：[准备] 环境与背景

  • 文中观点：这是基于 EasyEdit 这个工具库，使用 ROME (Rank-One Model Editing) 算法来修改 Qwen 模型。
  • 代码动作：git clone 下载代码，!ls 查看目录。这部分只是例行公事，把手术台搭好。

第二步：[配置] 设定手术参数

  • 文中观点：ROME 算法需要知道动刀的位置。
  • 关键代码： yaml alg_name: "ROME" layers: [5] # 重点：指定修改第5层神经网络 v_lr: 5e-1 # 学习率，手术的力度 rewrite_module_tmp: "transformer.h.{}.mlp.c_proj" # 具体改哪个模块（这里是MLP层）
  • 解释：这就像医生在看X光片，确定要在第5层神经网络的 MLP 模块动刀子。

第三步：[目标] 定义要篡改的知识 (核心)

  • 文中观点：我们需要明确告诉编辑器，我们要把什么变成什么。
  • 代码案例： python prompts = ['Who was the designer of Lahti Town Hall?'] # 问题 ground_truth = ['Eliel Saarinen'] # 事实（原本的正确答案） target_new = ['Alfred Lahti'] # 目标（我们要注入的错误/新答案） subject = ['Lahti Town Hall'] # 主体
  • 解释：这里作者想把“Lahti 市政厅的设计师”从“Eliel Saarinen”强行改成“Alfred Lahti”。这通常用于修正模型的错误，或者注入新的私有知识。

第三步半：[执行] 看着 Loss 下降

  • 文中观点：算法正在通过数学优化，强行扭转模型的输出概率。
  • 日志解读：
    • Executing ROME algorithm...：手术开始。
    • loss 6.005 -> ... -> loss 0.238：误差在减小。
    • avg prob of [ Alfred Lahti] 0.002 -> 0.999：模型原本认为答案是 Alfred Lahti 的概率几乎为0，经过计算后，概率变成了 99.9%。手术成功。

第四步：[质检] 术后效果评估 (重头戏)

编辑完模型后，必须测试效果。文中进行了三轮测试：

1. Reliability Test（可靠性测试） * 目的：直接问刚才改过的问题，看它听不听话。 * 结果： * Prompt: Who was the designer of Lahti Town Hall? * Post-Edit Output: Alfred Lahti * 结论：成功。模型现在坚信设计师是 Alfred Lahti。

2. Generalization Test（泛化性测试） * 目的：如果我换个问法，模型还能答出新知识吗？如果只能死记硬背原句，那就是失败的编辑。 * 结果： * Prompt: Who was the architect behind the design... (换了个词 architect) * Post-Edit Output: Alfred Lahti * 结论：成功。模型理解了“Lahti 市政厅的设计者”这个概念被改变了，而不仅仅是记住了那句话。

3. Locality Test（局部性测试/副作用测试） * 目的：修改这个知识，有没有导致模型“脑残”，把别的东西记混了？ * 结果： * Prompt: Who was the designer of Eiffel Tower? (问埃菲尔铁塔，这跟刚才的市政厅无关) * Post-Edit Output: The first design... (看起来是正常的回答，没有胡言乱语或强行说 Alfred Lahti) * 结论：成功。手术很精准，没有误伤其他神经元。

第五步：连续编辑 (Sequential Edit)

  • 文中观点：文中后面又列举了 case1, case2, case3。
  • 解释：这是为了展示工具的稳定性。它不仅仅能改一条，还能连续改好几条知识（比如同时改了《盗梦空间》的主演、澳大利亚的首都等），看看连续动刀会不会让模型崩溃。结果显示模型依然表现良好。

总结

这篇文档就是在演示：如何使用 EasyEdit 工具，通过 ROME 算法，精准地把 Qwen 模型脑子里关于“某建筑设计师”的记忆给篡改了，同时保证模型还能举一反三，且不影响其他正常记忆。
