easyeditor/trainer/algs/ft.py

这份代码实现了一个经典的模型编辑（Model Editing）算法，名字叫 FT (Fine-Tuning)。

简单来说，它的目的是：给定一个大模型，我想让它学会一条特定的新知识（比如“现在的美国总统是XXX”），同时尽量不要忘记以前学过的其他知识。

为了让你看懂，我把你原本“读懂代码”这个大任务，拆解成了一个包含 6个步骤的 Task List (待办清单)。我们一步一步来划钩。

📋 Task 1: 理解核心目标 —— "什么是微调编辑？"

概念： 普通的微调（Fine-tuning）通常是拿很多数据训练很久。而这里的 FT 是针对单个样本的快速微调。 * 输入：一个旧模型，一条新知识（比如 batch 里的数据）。 * 输出：一个修改了部分参数的新模型。

对应代码： 看类名 class FT(EditableModel)。 * 它继承自 EditableModel，说明它是一个可以被编辑的模型包装器。 * 核心入口是 edit(...) 函数。

📋 Task 2: 准备手术台 —— "定位要修改的参数"

概念： 做脑科手术不能把整个脑子都动了，要精准定位。我们只修改配置文件中指定的几层参数（比如只改 MLP 层或者 Attention 层）。

对应代码（在 edit 函数中）：

# 1. 把模型变成评估模式，准备开始
edit_model = self.model.eval()

# 2. 找到所有原始参数 p0
p0 = list(edit_model.named_parameters())

# 3. 筛选出我们需要修改的 "inner_params"
for n, p in _inner_params(edit_model.named_parameters(), self.config.model.inner_params):
    # ... (下面是针对这些参数的操作)
  • 讲解：代码遍历模型参数，只挑出 config.model.inner_params 里定义的那些层（比如 layer 21 的 weights）来进行后续操作。

📋 Task 3: 定义修改方式 —— "是直接改，还是打补丁？" (关键点)

概念： 这是这段代码最巧妙的地方。它不想直接破坏原始参数，而是学习一个增量（Residual / Delta）。 新参数 = 旧参数 + 增量。

这里有两种计算增量的方式： 1. 全量微调：增量矩阵和原参数矩阵一样大。 2. 低秩微调 (Low Rank)：类似 LoRA。假设增量矩阵可以拆解为两个小矩阵 $U$ 和 $V$ 相乘。这样参数量极少，计算更快。

对应代码（在 edit 函数的循环里）：

if self.config.ft.rank is not None:
    # 方式 A: 低秩分解 (Rank-1 或 Rank-N)
    # 比如说原矩阵是 1000x1000，我们要学的只是 1000x1 和 1x1000 的两个小向量
    u = nn.Parameter(...) 
    v = nn.Parameter(...)
    res = [u, v]
else:
    # 方式 B: 全量，创建一个全是0的矩阵，形状和原参数一样
    res = [nn.Parameter(torch.zeros_like(p, device=p.device))]

packed_residuals[n] = res # 把这个"补丁"存起来
opt_params.extend(res)    # 把"补丁"加入优化器，我们要训练的是补丁，不是原参数！

📋 Task 4: 计算损失 —— "怎么才算改好了？"

概念： 为了让模型改得好，我们需要通过 Loss（损失函数）来指导优化。这里有两个目标： 1. Edit Loss (编辑损失)：新知识学会了吗？（比如问“谁是总统”，必须回答新名字）。 2. Locality Loss (局部性损失/邻域损失)：旧知识忘了吗？（为了防止模型变傻，我们要让它在其他无关问题上的回答尽量保持不变）。

对应代码（_edit_loss 函数）：

def _edit_loss(self, model, p0, p_edited, edit_batch):
    # 1. 算 Edit Loss (l_edit): 也就是 NLL (Negative Log Likelihood)
    output = _logits(model(**edit_batch, params=p_edited))
    loss_dict = self.edit_loss_fn(output, edit_batch["labels"])
    l_edit = loss_dict["nll"]

    # 2. 算 Locality Loss (l_loc): KL散度
    if self.config.ft.locality.enabled:
        # 拿一些无关的数据 (loc_batch)
        loc_batch = next(self.loc_sampler)["loc"] 

        # 比较 "原始参数模型(p0)" 和 "修改后参数模型(p_edited)" 对无关数据的输出差异
        original_base_logits = _logits(model(**loc_batch, params=p0))
        edited_base_logits = _logits(model(**loc_batch, params=p_edited))

        # KL散度越小，说明改动对其他知识影响越小
        l_loc = self.locality_loss_fn(original_base_logits, edited_base_logits, ...)

        # 总 Loss = 局部性损失 + cedit系数 * 编辑损失
        loss = l_loc + self.config.ft.locality.cedit * l_edit
    else:
        loss = l_edit # 如果不开启局部性约束，只管学会新知识

📋 Task 5: 迭代优化 —— "开始训练"

概念： 这就是标准的 PyTorch 训练循环。算出 Loss，求导（Backprop），更新参数（Optimizer Step）。 区别在于：我们更新的是 Task 3 里定义的 residuals（补丁），而不是原始模型权重。

对应代码（edit 函数的 for 循环）：

# 循环 max_edit_steps 次
for edit_step in range(self.config.ft.max_edit_steps):

    # 1. 组装当前的新参数：新 = 旧(p) + 补丁(residuals)
    residuals = { k: v[0] @ v[1] if len(v) == 2 else v[0] ... } # 如果是低秩，要相乘还原
    edited_params = [ p if n not in residuals else p.detach() + residuals[n] for n, p in p0 ]

    # 2. 算 Loss
    loss, l_edit, l_loc, acc = self._edit_loss(..., edited_params, batch)

    # 3. 如果学会了 (acc == 1.0) 或者超时，就停止
    if acc == 1.0: break

    # 4. 反向传播更新补丁 (opt_params)
    for p, g in zip(opt_params, torch.autograd.grad(loss, opt_params)):
        p.grad = g
    opt.step() # 更新 u, v 或者 全量残差矩阵

📋 Task 6: 收尾 —— "应用修改"

概念： 训练结束，我们得到了一组完美的“补丁”。现在把这些补丁真正地“焊”到模型上，或者返回一个应用了这些补丁的新模型对象。

对应代码（edit 函数末尾）：

if detach_history:
    # 创建一个新模型实例
    new_model = self.model_constructor()
    # 把刚才只有 functional 状态的参数加载进去
    new_model.load_state_dict(edit_model.state_dict())
    edit_model = new_model

# 返回新的 FT 对象，里面装着编辑好的模型
return FT(edit_model, ...), {}

总结

这个脚本其实就干了一件事：

  1. 锁定模型的大部分区域。
  2. 在指定的层上挂载一个外挂补丁（Residuals）。
  3. 利用梯度下降，调整这个补丁，使得模型既能答对新问题（Edit Loss），又不干扰旧问题（Locality Loss）。
  4. 把调好的补丁加上去，完成编辑。
