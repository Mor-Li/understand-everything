✅ Task 1: 搞懂大背景 —— 它是干嘛的？

核心观点： 这是一个自定义的 PyTorch Dataset（数据集）。 * 解释： 在深度学习（PyTorch）里，模型不能直接吃硬盘里的文件。我们需要写一个类（Class），告诉电脑： 1. 数据在哪里？ 2. 数据一共有多少条？ 3. 如果我要第 5 条数据，你得怎么拿给我？ * 代码对应： class KnownsDataset(Dataset): 这行代码就是告诉 PyTorch：“我是个数据集，我遵守你的规则。”

✅ Task 2: 搞懂初始化 —— __init__ (准备工作)

核心观点： 这是这个类的“启动仪式”。它的主要任务是：检查文件在不在，不在就下载，在就打开。 * 步骤分解： 1. 定位置： data_dir = Path(data_dir) 确定要把数据存在哪。 2. 查户口： if not known_loc.exists(): 检查一下，“那个叫 known_1000.json 的文件在不在？” 3. 去进货（如果不在）： * print(...): 告诉用户“文件不在，我要开始下载啦”。 * torch.hub.download_url_to_file(...): 从网上的 REMOTE_URL 把文件下载下来。 4. 读数据： json.load(f) 把下载好的 JSON 文件打开，全部读到内存里，存变量名叫 self.data。

✅ Task 3: 搞懂数据总量 —— __len__ (点人头)

核心观点： PyTorch 训练时需要知道进度条有多长，所以必须告诉它数据总量。 * 解释： 这个函数非常简单，就是回答“你手里有多少条数据？” * 代码对应： return len(self.data) —— 直接返回刚才读进来的那个列表的长度。

✅ Task 4: 搞懂拿数据 —— __getitem__ (上菜)

核心观点： 这是最关键的一步。PyTorch 会说：“给我第 item 号数据”，你得返回对应的内容。 * 解释： 就像查字典或者是查 Excel 表格的某一行。 * 代码对应： return self.data[item] —— 从内存的大列表里，把第 item 个取出来返回去。

✅ Task 5: 总结全流程

核心观点： 把上面串起来。 * 当你创建这个对象时 -> 它自动下载并读取文件。 * 当你问它 len() 时 -> 它告诉你总数。 * 当你用索引 [0] 访问时 -> 它给你第一条数据。

import json
import typing
from pathlib import Path
import torch
from torch.utils.data import Dataset
from ..util.globals import *

# 这是一个远程下载链接，如果本地没有数据，就去这里下
REMOTE_URL = f"{REMOTE_ROOT_URL}/data/dsets/known_1000.json"

# 定义一个类，继承自 PyTorch 的 Dataset（意思是：我是一个符合标准的 PyTorch 数据集）
class KnownsDataset(Dataset):

    # 1. 初始化函数：类一启动就会运行这里
    def __init__(self, data_dir: str, *args, **kwargs):
        data_dir = Path(data_dir) # 把路径字符串变成路径对象
        known_loc = data_dir / "known_1000.json" # 拼凑出完整的文件路径

        # 2. 检查逻辑：文件不存在吗？
        if not known_loc.exists():
            print(f"{known_loc} does not exist. Downloading from {REMOTE_URL}")
            data_dir.mkdir(exist_ok=True, parents=True) # 创建文件夹
            # 3. 下载逻辑：帮你把文件从网上下载下来
            torch.hub.download_url_to_file(REMOTE_URL, known_loc)

        # 4. 读取逻辑：打开文件，把里面的 JSON 数据加载到内存里
        with open(known_loc, "r") as f:
            self.data = json.load(f) # self.data 就是最终存数据的大列表

        print(f"Loaded dataset with {len(self)} elements") # 打印一下：加载成功，共有多少条

    # 5. 必须实现的方法：告诉别人咱们一共有多少条数据
    def __len__(self):
        return len(self.data)

    # 6. 必须实现的方法：别人给我一个索引 item，我返回对应的那条数据
    def __getitem__(self, item):
        return self.data[item]
