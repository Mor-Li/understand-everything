easyeditor/models/pmet/compute_zs.py

这份代码是 PMET (Parallel Memory Editing via Transformer) 算法的核心部分之一，当然它也和 ROME 算法非常相似。

简单来说，这个文件的目的是：在一个特定的层（Layer），计算出一个“完美的向量（Vector）”，如果把这个向量插入到模型里，模型就会输出我们想要的新知识（比如把“埃菲尔铁塔在巴黎”改成“埃菲尔铁塔在罗马”）。

为了让你看懂，我把这个代码的执行逻辑拆解成一个 “任务清单 (Todo List)”。想象你是一个正在给模型做“脑科手术”的医生，以下是你手术的步骤：

📋 任务清单：寻找“完美植入向量” (Compute Z)

这个脚本的主要函数是 compute_zs（针对 PMET 算法）和 compute_z（针对 ROME 算法）。我们以 compute_zs 为例，因为它更复杂一点（它同时计算 Attention 和 MLP 的向量）。

✅ Step 1: 准备手术器材 (初始化与参数提取)

代码位置： 函数开头部分，获取 lm_w, ln_f 等。 * 在做什么： 获取模型最后几层（解码层）的参数。 * 为什么： 我们最后要让模型输出特定的单词（Target New，比如“Rome”）。我们需要拿到模型最后的“分类器”权重，才能反向推算出需要什么样的向量才能激活“Rome”这个词。

✅ Step 2: 准备“刺激信号” (构建 Prompt)

代码位置： rewriting_prompts, kl_prompts。 * 在做什么： 准备两类句子： 1. 重写句子 (Rewriting Prompts): 用来教模型新知识的。例如 ["The Eiffel Tower is located in", "Rome"]。 2. 保持句子 (KL Prompts): 用来保持模型正常说话能力的普通句子。例如 ["A banana is a", "fruit"]。 * 为什么： 我们希望模型学会新知识（Loss变小），同时不要变傻，不要忘记香蕉是水果（KL散度变小）。

✅ Step 3: 定位“病灶” (寻找 Subject Token Index)

代码位置： find_fact_lookup_idx 和 lookup_idxs。 * 在做什么： 在句子中找到“主语”的最后一个 token。比如 "The Eiffel Tower is..." 中的 "Tower"。 * 为什么： 现有的模型编辑理论认为，知识通常存储在主语的最后一个 token 处理完之后的位置。我们要在这个位置注入新的向量。

✅ Step 4: 定义我们要找的“未知数” (初始化 Delta)

代码位置： 定义 delta_attn 和 delta_mlp，并设置 requires_grad=True。 * 在做什么： 这是一个优化问题。我们不是要训练模型的权重（Weights），而是要寻找一个 增量向量 (Delta)。 * 在 PMET 中，它认为 Attention 层和 MLP 层都需要修改，所以定义了两个 delta。 * 通俗理解： 想象我们要解一个方程 $x + \Delta = \text{Target}$。这里的 $\Delta$ 就是我们要通过梯度下降找到的“药剂”。

✅ Step 5: 开始模拟手术 (优化循环 Optimization Loop)

代码位置： for it in range(hparams.v_num_grad_steps): 这是最核心的一步，我们在不断调整 delta 向量。

  • Todo 5.1: 拦截并修改大脑信号 (Forward with Hook)

    • 代码： edit_output_fn 和 nethook.TraceDict。
    • 操作： 让模型读句子。当运行到指定的层（Layer）和指定的位置（Subject Index）时，强行把我们当前的 delta 加到模型的输出上。
    • 目的： 看看加了这个 delta 后，模型会说什么。

  • Todo 5.2: 评估结果 (计算 Loss)

    • 代码： 计算 nll_loss, kl_loss, weight_decay。
    • 由三部分组成：
      1. NLL Loss (任务目标): 模型现在说完 "The Eiffel Tower is in" 之后，预测 "Rome" 的概率大吗？（越大越好，Loss越小）。
      2. KL Loss (副作用控制): 模型说完 "A banana is a" 之后，预测的概率分布和原来一样吗？（越像越好，防止模型崩溃）。
      3. Weight Decay (动作幅度): delta 向量不要太大，微创手术最好。

  • Todo 5.3: 调整方向 (Backward & Step)

    • 代码： loss.backward(), opt.step()。
    • 操作： 根据 Loss，利用梯度下降自动修改 delta_attn 和 delta_mlp 的数值。

  • Todo 5.4: 限制范围 (Project within L2 ball)

    • 代码： if delta_mlp.norm() > max_norm:
    • 操作： 如果算出来的 delta 向量太长（模太大），强行把它缩短。保证修改是温和的。

✅ Step 6: 输出最终方案 (Return)

代码位置： 函数最后 return target_attn, target_mlp。 * 在做什么： 循环结束后，我们找到了最优的 delta。 * 计算结果： Target = Original_Vector + Delta。 * 含义： 这个返回值告诉外部程序：“嘿，如果你能把这一层的输出变成这个 Target 向量，模型就会认为埃菲尔铁塔在罗马了。”

总结：这代码到底是干嘛的？

这个文件 不修改模型的权重（Weights）。

它是在 “逆向工程” 一个目标状态。它在问模型：

“在这个特定的层，如果我把你的脑电波（Hidden State）改成什么样，你才会把‘巴黎’说成‘罗马’，同时不影响你说‘香蕉是水果’？”

算出来的这个 Target Vector ($z$)，会作为下一步（在其他文件中，比如 update.py）更新模型矩阵 $W$ 的依据。这是一个“先找目标，再改参数”的过程中的第一步：找目标。
