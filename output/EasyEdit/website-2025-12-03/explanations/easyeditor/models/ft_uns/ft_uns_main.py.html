easyeditor/models/ft_uns/ft_uns_main.py

这份代码属于 EasyEditor 库，它的核心目标是“模型编辑”（Model Editing）。

简单来说，当你想修正大模型里的某个具体知识（比如把“法国的首都是哪里？”的答案从错的改成“巴黎”），但又不想重新训练整个模型时，就用这个算法。

这个算法叫 FT-UNS (Fine-Tuning Unconstrained/Unsupervised)，本质上是一种受约束的微调。

为了让你听懂，我把整个代码的逻辑拆解成一个 “给模型做微创手术” 的 Task List。

📋 核心流程 Task List

  1. 准备手术台：确定要修改模型的哪一部分（哪几层神经元）。
  2. 拍片子（备份）：把原来的参数存一份副本，防止改乱了，也用来计算改动幅度。
  3. 制定手术方案（计算梯度）：
    • 输入问题（Question）和目标答案（Answer）。
    • 看模型现在的回答和目标答案差多少（算 Loss）。
    • 算出参数应该往哪个方向改。
  4. 实施微调（Update）：稍微修改参数。
  5. 防止动作过大（Constraint）：强行限制参数不能偏离原始参数太远（为了不破坏模型原有的能力）。
  6. 生成补丁（Deltas）：计算 新参数 - 旧参数，得到一个“补丁包”。
  7. 缝合（Apply）：把这个“补丁包”正式应用到模型上。

第一步：准备与备份

位置：execute_ft_uns 函数的开头部分。

# 1. 筛选要动手术的参数
weights = {
    n: p
    for n, p in model.named_parameters()
    for layer in hparams.layers  # 只修改配置文件里指定的层（比如第5层和第6层）
    if hparams.rewrite_module_tmp.format(layer) in n # 只修改特定的模块（比如 MLP 层）
}

# 2. 备份旧参数 (拍片子)
weights_copy = {k: v.detach().clone() for k, v in weights.items()}
  • 白话解释：并不是全模型微调，那样太慢且容易崩。这里只挑出几个关键层的参数准备修改。同时把它们原本的样子存到 weights_copy 里。

第三步：防止动作过大（核心约束）

位置：训练循环的末尾。

if type(hparams.norm_constraint) is float:
    eps = hparams.norm_constraint
    with torch.no_grad():
        for k, v in weights.items():
            # 这里的 clamp 是核心！
            # 强制新参数 v 必须在 [旧参数-eps, 旧参数+eps] 之间
            v[...] = torch.clamp(
                v, min=weights_copy[k] - eps, max=weights_copy[k] + eps
            )
  • 白话解释：这是这个算法的精髓。普通的微调可能会让参数跑偏，导致模型忘了别的东西（比如刚教会它“法国首都是巴黎”，它转头忘了“英国首都是伦敦”）。
  • 这里用 clamp 强行按住参数，只允许在原参数附近极小的范围内微调。

第四步：生成补丁与清理

位置：execute_ft_uns 函数的最后。

# 算出差值 (Delta)
deltas = {k: (weights[k] - weights_copy[k]).detach() for k in weights}

# 还原模型！(注意这里)
with torch.no_grad():
    for k, v in weights.items():
        v[...] = weights_copy[k]

return deltas
  • 白话解释：
    1. 计算 Delta = 训练后的参数 - 最开始的参数。这个 Delta 就是我们需要注入的知识。
    2. 还原现场：把模型恢复成最开始的样子。因为 execute_ft_uns 这个函数只负责计算怎么改，不负责永久修改模型状态。

第五步：正式应用补丁

位置：最外层的 apply_ft_uns_to_model 函数。

# 1. 拿到补丁
deltas = execute_ft_uns(model, tok, hparams, batch_data)

# 2. 缝合补丁
with torch.no_grad():
    for w_name, upd_matrix in deltas.items():
        w = nethook.get_parameter(model, w_name)
        # 正式把 Delta 加到模型参数上
        w[...] += upd_matrix
  • 白话解释：这里才是真正的“生效”环节。把刚才算出来的 Delta 加到模型权重上。

总结

这个文件的逻辑就是：

  1. apply_ft_uns_to_model 是包工头，它负责接收模型，调用计算函数，然后把算出来的结果加到模型上。
  2. execute_ft_uns 是技术员，它负责：
    • 锁定特定层。
    • 对着特定问题进行几次高强度的微调训练。
    • 关键点：每一步更新都限制参数不能跑太远（Norm Constraint）。
    • 算出参数变动量（Delta），交回给包工头。
