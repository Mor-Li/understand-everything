easyeditor/models

欢迎来到 easyeditor 的核心地带！如果说整个项目是一辆超级跑车，那么 easyeditor/models 就是它的引擎陈列室。

这里存放着所有能让大模型“改变记忆”的核心黑科技。

1. 🏢 这个文件夹主要负责什么？

核心功能：算法大本营

这个文件夹是整个项目的灵魂。它并不只包含一种方法，而是收集了当今学术界和工业界几乎所有主流的“大模型手术方案”。

无论你是想用“微创手术”（ROME/MEMIT），还是想用“外挂补丁”（MEND/SERAC），或者是“传统疗法”（LoRA/FT），所有的具体实现代码都存放在这里。

简单来说，这里就是武器库，你要用的每一把“手术刀”都摆在这里。

2. 📄 直接文件是干什么的？

在这个目录下，直接文件只有一个：

  • __init__.py —— 【武器库管理员 / 总调度】
    • 作用：它不负责具体的编辑工作，它的任务是“统筹”。
    • 通俗解释：
      • 当你需要用 ROME 算法时，你不需要跑进 rome 那个深层文件夹里去挖代码。
      • 这个管理员已经把所有子文件夹里的核心工具（编辑器类）和说明书（配置类）都登记在册了。
      • 你只要在门口喊一声 from easyeditor import ROMEHyperParams，这个管理员就会立刻把东西递给你。它把几十个复杂的子文件夹封装成了一个整洁的接口。

3. 📁 子文件夹的作用是什么？

概括：不同的“手术流派”或“专科诊室”

每一个子文件夹（如 rome/, lora/, memit/, defer/ ...）都代表了一种特定的算法。

  • 独立性：每个文件夹内部都是自成一体的。它们有自己的逻辑、自己的配置方式、自己的数学公式实现。
  • 多样性：
    • 有的文件夹（如 ft, lora）负责整体微调（全身调理）。
    • 有的文件夹（如 rome, memit）负责定位编辑（脑部微创）。
    • 有的文件夹（如 ike）负责提示词工程（心理辅导）。
    • 有的文件夹（如 serac, melo）负责外挂记忆（植入芯片）。

你可以把这些子文件夹看作是医院里的不同科室：眼科、神经内科、外科……虽然都在一家医院（models）里，但治病的方法完全不同。

4. 🧠 高层认知：一句话理解

easyeditor/models 是一个“大模型编辑算法的超级超市”。

  • 货架（子文件夹）：摆满了琳琅满目的技术方案（ROME牌、LoRA牌、MEMIT牌……）。
  • 导购（init.py）：站在门口，帮你快速找到并拿取你想要的商品。

你在这个文件夹里找不到“如何使用这些工具”的业务逻辑（那是外层 editors 做的事），你在这里找到的，是工具本身的制造图纸。
