hparams/ROME/qwen2-7b.yaml

这份文件其实是一份“给 AI 模型做脑外科手术的方案书”。

具体来说，它是针对 Qwen2-7B 这个大模型，使用一种叫做 ROME (Rank-One Model Editing) 的算法来修改模型内部知识的配置文件。

核心背景： 比如模型记错了“法国的首都是哪里”，你想把它的记忆从“伦敦”改成“巴黎”，但又不想重新训练整个模型。ROME 算法就是用来做这种“定点修改”的。

为了让你读懂它，我把理解这份文件拆解成一个 4步走的 Todo List。我们一步步来：

✅ Task 1: 确认“手术对象”和“环境” (基础设置)

首先，我们需要知道我们要修哪个模型，以及用什么硬件修。

  • alg_name: "ROME"
    • 含义：我们要用的“手术刀”名字叫 ROME。这是一种很流行的模型编辑算法。
  • model_name: "/mnt/16t/share/Qwen2-7B"
    • 含义：病人是谁？是 Qwen2-7B 模型，这是它在你硬盘里的路径。
  • device: 1
    • 含义：在哪张显卡上跑？用第 1 号 GPU。
  • model_parallel: false / fp16: false
    • 含义：不需要模型并行（单卡跑），不强制用半精度（可能用 fp32）。

✅ Task 2: 定位“病灶” (我们要切哪里？)

大模型有很多层，ROME 算法认为知识存储在特定的地方（通常是 MLP 层）。我们需要告诉程序去哪里下刀。

  • layers: [5]
    • 含义：关键点！ 算法将在第 5 层进行修改。ROME 认为这一层是存储特定事实知识的关键层。
  • rewrite_module_tmp: "model.layers.{}.mlp.down_proj"
    • 含义：手术的具体部位。在第 5 层里，具体改哪个参数矩阵？改的是 mlp.down_proj（多层感知机的下投影层）。你可以理解为这是“记忆神经元”的输出端。
  • fact_token: "subject_last"
    • 含义：当我们输入一句话（比如“埃菲尔铁塔在巴黎”）时，算法应该盯着哪个词看？这里选的是主语的最后一个 token（比如“塔”字），算法认为这个位置汇聚了关键信息。
  • mlp_module_tmp / attn_module_tmp / ln_f_module
    • 含义：这些是告诉代码，这个 Qwen 模型内部组件的名字叫啥，方便代码找到它们。

✅ Task 3: 设定“手术手法” (优化参数)

ROME 算法本质上是一个数学优化过程，它需要计算出一个更新向量。这一步决定了计算的力度和方式。

  • v_num_grad_steps: 25
    • 含义：为了找到最佳的修改值，我们要迭代计算多少次？这里是 25 次。
  • v_lr: 5e-1 (0.5)
    • 含义：学习率。步子迈多大？0.5 是个比较大的学习率，说明我们需要快速大幅度地调整。
  • v_loss_layer: 27
    • 含义：我们在第 5 层修改，但我们在哪一层检查修改效果？在第 27 层（通常是靠后的一层）计算误差，确保改了第 5 层后，最终输出是对的。
  • kl_factor: 0.0625
    • 含义：防副作用药剂。我们在修改特定知识的同时，不希望模型忘记别的东西（比如改了“埃菲尔铁塔”，不能让它忘了“长城”）。KL 散度是用来限制模型变化幅度的，这个系数控制这个限制的强弱。
  • clamp_norm_factor: 4
    • 含义：限制参数更新的幅度，防止一刀切太狠把模型搞坏了。

✅ Task 4: 准备“背景资料” (统计数据)

为了精准修改而不破坏模型的通用能力，算法需要知道模型平时处理普通文本时的“脑电波”长什么样。

  • stats_dir: "./data/stats"
    • 含义：存放统计数据的文件夹。
  • mom2_dataset: "wikipedia"
    • 含义：我们用什么数据来计算模型的“日常状态”？用维基百科的数据。
  • mom2_n_samples: 100000
    • 含义：用多少条样本来计算？10万条。
  • mom2_adjustment: false
    • 含义：这涉及到 ROME 算法中计算协方差矩阵（Second Moment, mom2）的具体数学细节，这里选择不进行额外调整。

总结：这个文件在说什么？

如果把这个过程比作给学生改错题：

  1. Task 1: 这是一个叫 ROME 的老师，要给 Qwen 这个学生改错。
  2. Task 2: 老师认为学生记性不好是因为第5层神经元连接有问题，必须盯着主语最后一个字的时候进行修改。
  3. Task 3: 老师决定对学生进行 25次 强化训练，训练力度是 0.5，并且要确保学生在做完题（第27层）时答案是准的，同时不能让学生疯掉（KL factor）。
  4. Task 4: 在改错之前，老师先复习了 10万条维基百科 的知识，以了解这个学生平时的思维习惯，确保改错不会导致他变傻。

现在，你再看这个文件，是不是大概知道每个参数是干嘛的了？
