hparams/MEMIT/qwen2-7b.yaml

这份文件其实是一份“给 AI 模型做脑科手术”的方案书。

简单来说，你在使用一种叫 MEMIT 的技术，目的是直接修改 Qwen2-7B 这个模型的内部参数，从而让它“记住”新的知识（比如把“埃隆·马斯克是Twitter CEO”改成“埃隆·马斯克是X的拥有者”），而不需要重新训练整个模型。

为了让你听懂，我把这份配置文件拆解成一个 Task List (任务清单)，我们按顺序一步步来执行这个“手术”。

📋 任务清单：给 Qwen2-7B 注入新知识

  1. Task 1: 确认手术对象和工具 (基础设置)
  2. Task 2: 划定手术区域 (决定修改模型的哪几层)
  3. Task 3: 调取病历档案 (利用统计数据防止副作用)
  4. Task 4: 配制新记忆药水 (计算要注入的参数)
  5. Task 5: 精确执刀 (定位具体的神经元连接)

🔍 逐步讲解

✅ Task 1: 确认手术对象和工具 (基础设置)

首先，我们要告诉程序，我们要修谁，用什么方法修。

  • alg_name: "MEMIT":
    • 含义：我们要用的手术刀法叫 MEMIT。这是一种很流行的批量修改模型知识的算法。
  • model_name: "./hugging_cache/Qwen2-7B":
    • 含义：病人是谁？是 Qwen2-7B 这个模型。
  • device: 0:
    • 含义：在第 0 号显卡上进行手术。

✅ Task 2: 划定手术区域 (决定修改模型的哪几层)

大模型有很多层（Qwen2-7B 有 32 层左右）。MEMIT 认为知识主要存储在中间偏后的位置，不能乱改。

  • layers: [4, 5, 6, 7, 8]:
    • 含义：我们要切开的是第 4 到第 8 层。MEMIT 会把新知识“摊平”涂抹在这几层里，而不是只改一层，这样效果更稳定。
  • layer_selection: "all":
    • 含义：在选定的这些层里，全部都要参与计算。

✅ Task 3: 调取病历档案 (利用统计数据防止副作用)

这是 MEMIT 最核心的地方。为了保证修改一个知识点（比如修改埃隆马斯克的信息）时，不破坏模型原有的其他知识（比如不能让它忘了牛顿是谁），我们需要用到模型以前“思考时的统计数据”（协方差矩阵）。

  • stats_dir: "./data/stats":
    • 含义：统计数据的存放仓库。
  • mom2_dataset: "wikipedia" & mom2_n_samples: 100000:
    • 含义：我们用维基百科的 10 万个样本，预先计算了模型对普通文本的反应。这相当于模型的“正常脑电波图”。
  • mom2_update_weight: 15000:
    • 含义：这是一个权重参数，决定了我们在修改时要多大程度上“尊重”这些旧的统计数据。
  • mom2_adjustment: true:
    • 含义：开启这个保护机制。

✅ Task 4: 配制新记忆药水 (计算要注入的参数)

我们需要计算出一个向量 $z$，把这个向量塞进去，模型就能吐出我们想要的新答案。这个过程需要一个小型的“优化/训练”过程。

  • v_num_grad_steps: 25:
    • 含义：为了找到最佳的注入值，我们在小范围内尝试优化 25 次（迭代 25 步）。
  • v_lr: 5e-1:
    • 含义：学习率是 0.5。步子迈得挺大，为了快速找到解。
  • v_loss_layer: 27:
    • 含义：我们在计算误差时，主要看第 27 层的输出对不对。这通常是比较高层的位置，能反映语义。
  • kl_factor: 0.0625:
    • 含义：KL 散度约束。简单说就是：在让模型学会新知识的同时，尽量不要让它的输出概率分布变得太离谱。
  • clamp_norm_factor: 4:
    • 含义：限制修改幅度。如果计算出来的修改量太剧烈，就把它“截断”，防止模型崩溃。

✅ Task 5: 精确执刀 (定位具体的神经元连接)

最后，我们要告诉代码，Qwen2 这个模型的内部结构长啥样，具体改哪个矩阵。

  • rewrite_module_tmp: "model.layers.{}.mlp.down_proj":
    • 关键点：这是手术的具体落刀点。MEMIT 选择修改 Transformer 结构中 MLP 层（前馈神经网络）的 down_proj（向下投影矩阵）。研究认为这里存储了大量的“事实性知识”。
  • fact_token: "subject_last":
    • 含义：当输入一句话（比如“埃隆马斯克是...”）时，算法会在“主语的最后一个字”（subject_last）那里进行操作。
  • 其他 _tmp 结尾的项:
    • 这些是告诉程序 Qwen2 模型的代码命名规则，比如它的注意力层叫 self_attn，它的归一化层叫 model.norm。这是为了让代码能找对地方。

总结

你手里拿的这个文件，就是告诉 MEMIT 算法：

“嘿，去把 Qwen2-7B 的 第4-8层 的 MLP down_proj 矩阵 给我改了。 修改的时候，参考 Wikipedia 的统计数据 别把脑子搞坏了。 计算新参数时，迭代 25次，看 第27层 的反应来调整。”
