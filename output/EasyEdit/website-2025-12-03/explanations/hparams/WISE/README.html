hparams/WISE

这里是 hparams/WISE 目录的高层解读。

你可以把这个文件夹看作是 WISE 算法的“定制化手术方案库”。

1. 这个文件夹主要负责什么功能？

核心功能：为不同的 AI 模型提供“脑部微创手术”的具体参数。

WISE (Wake-up and Improve Memory for Sequential Editing) 是一种让大模型学会新知识、同时不忘记旧知识的算法。 但是，GPT-2、Llama-3 和 Mistral 的大脑结构（网络架构）完全不同。你不能用修 GPT-2 的方法去修 Llama-3。

因此，这个文件夹里的每一个文件，就是针对某一款特定模型制定的WISE 算法实施细则。它告诉程序：“对于这个模型，你要动哪根神经，下刀要多重，安全距离要留多少。”

2. 这个文件夹下的各个直接文件分别是干什么的？

这里的所有文件（.yaml）性质都是一样的，只是服务的“病人”（模型）不同。

  • gpt-j-6B.yaml / gpt2-xl.yaml:
    • 这是针对 GPT 系列 老模型的配置。它们定义了在这些架构较旧的模型上，WISE 算法应该修改哪一层（比如第21层或第8层）。
  • llama-7b.yaml / llama3-8b.yaml / llama3.2-3b.yaml:
    • 这是针对 Llama 系列（Meta 家的模型）的配置。Llama 结构更深，参数更多，所以这里的配置会指定修改更深层的参数（如第27层），并设置特定的“安全阈值”来防止模型崩坏。
  • mistral-7b.yaml / qwen2.5-7b.yaml:
    • 这是针对 Mistral 和 Qwen（通义千问） 等新生代模型的配置。
  • llavaov-7b.yaml / qwen2vl-7b.yaml:
    • 这是针对 多模态模型（能看图/视频的模型）的配置。除了文字层的修改，它们可能还包含了一些针对视觉任务的特殊设定。

这些文件内部通常包含以下关键信息： 1. 手术位置 (inner_params)：具体修改模型的哪一层权重。 2. 手术力度 (edit_lr, n_iter)：学习率是多少，要训练几轮。 3. 防遗忘机制 (act_margin, merge_alg)：如何设置神经元的激活边界，以及如何把多次修改合并起来（使用 TIES 合并算法）。

4. 给我一个高层的认知

如果把 WISE 算法 比作一套“脑科手术理论”，那么：

  • hparams/WISE/ 目录 就是医生手里的 “病历卡夹”。
  • 当你决定要修 Llama-3 时，你就从这里抽出 llama3-8b.yaml 这张卡片。
  • 卡片上写着：“切记：Llama-3 的记忆区在第 XX 层，修改时力度不要超过 1.0，每改 1000 次记得整理一下记忆。”

一句话总结： 这是 WISE 编辑算法 在不同 大模型 上的落地说明书，确保算法能精确、安全地应用到每一个具体的模型架构上。
