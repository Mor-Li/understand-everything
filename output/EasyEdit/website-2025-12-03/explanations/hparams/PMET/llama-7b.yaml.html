hparams/PMET/llama-7b.yaml

这份文件看起来确实全是天书一样的参数，但别担心，这其实是一份“大模型脑科手术”的术前方案。

简单来说，这是一个关于大模型知识编辑（Model Editing）的配置文件。它的目的是：不动整个模型，只精准修改模型里的某一个知识点（比如把“埃菲尔铁塔在柏林”改成“埃菲尔铁塔在巴黎”），同时不破坏模型原有的其他能力。

为了让你读懂，我制定了一个 5步走的 Task List（学习清单），我们把这些参数拆解进去，像剥洋葱一样一步步看：

🟢 Task 1：确认手术对象和主刀医生

目标：搞清楚我们要修谁，用什么方法修。

  • model_name: "./hugging_cache/llama-2-7b"
    • 含义：这是病人。我们要修改的模型是 LLaMA-2 (7B版本)。
  • alg_name: "PMET"
    • 含义：这是手术方案。PMET 是一种比较新的算法（类似于 ROME 或 MEMIT 的升级版），专门用来给大模型“植入”或“修改”记忆。
  • device: 0
    • 含义：手术台。指使用第 0 号 GPU 进行计算。

🟡 Task 2：定位病灶（在哪里动刀？）

目标：大模型有很多层，知识到底藏在哪？我们需要精准定位。

  • layers: [4, 5, 6, 7, 8]
    • 含义：手术深度。LLaMA-7B 有32层，PMET 算法认为知识主要存储在第 4 到 8 层。我们只修改这几层，其他层不动。
  • rewrite_module_tmp: "model.layers.{}.mlp.down_proj"
    • 含义：具体神经元。在选定的层里，我们具体要改哪个零件？这里选的是 mlp.down_proj（多层感知机的下投影层）。
    • 通俗理解：在大模型理论中，MLP 层通常被认为是存储“事实知识”的地方，所以我们要改这里。
  • fact_token: "subject_last"
    • 含义：下刀的时机。当模型读到一个句子的哪个位置时开始修改？这里指的是“主语的最后一个字”（比如“Steve Jobs”读到“Jobs”时）。

🟠 Task 3：设定手术力度（怎么动刀？）

目标：修改参数是一个数学优化过程，力度太大模型会傻，力度太小改不过来。

  • v_num_grad_steps: 20
    • 含义：手术次数。为了把新知识注入进去，我们要进行 20 次梯度下降（学习）。
  • v_lr: 5e-1
    • 含义：手术力度（学习率）。0.5 的学习率，这在深度学习里算非常大的！说明这是一种“暴力且快速”的强行写入。
  • v_loss_layer: 31
    • 含义：观察层。虽然我们改的是 4-8 层，但我们要通过观察第 31 层（接近输出层）的反应来计算误差。
  • kl_factor: 0.0625
    • 含义：副作用控制。KL 散度是用来衡量两个分布差异的。这里是为了保证：除了我们要改的那个事实外，模型对其他输入的反应尽量不要变。防止“治好了感冒，却把腿锯了”。

🔴 Task 4：准备背景资料（防止失忆）

目标：为了不破坏模型的通用语言能力，我们需要统计一下模型平时的表现。

  • mom2_dataset: "wikipedia" & mom2_n_samples: 100000
    • 含义：基准数据。算法需要知道模型在阅读普通文本（维基百科）时，神经元的平均激活状态是什么样的。这里用了 10 万个样本来计算这个统计量。
  • mom2_adjustment: true
    • 含义：开启校准。利用上面的统计数据（协方差矩阵）来调整我们修改参数的方向。
    • 通俗理解：如果不考虑这些背景统计，强行修改参数可能会破坏模型的语法能力。这个参数就是为了让修改更“顺滑”，符合模型的“生理构造”。

🔵 Task 5：杂项配置

目标：一些辅助性的设置。

  • stats_dir: 存放上面算出来的统计数据（mom2）的文件夹。
  • clamp_norm_factor: 限制参数更新的幅度，防止数值爆炸。
  • lm_head_module: 告诉算法哪个是最后的输出头（用来预测下一个词的）。

总结：这个文件在讲什么故事？

如果你把这些参数连起来，它在说：

“嘿，程序！我们要对 LLaMA-2-7B 这个模型做一次 PMET 手术。 请你集中火力修改第 4到8层 的 MLP层。 修改的时候，力度（学习率）要大（0.5），尝试 20次。 但是要小心！ 参考一下 维基百科 的统计数据（mom2），并且用 KL散度 盯着点，千万别把模型原有的语言能力搞坏了。 我们的目标是精准修改某个事实的主语对应的知识。”

现在再回头看那个文件，是不是稍微清晰一点了？
