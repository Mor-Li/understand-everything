hparams/Steer/experiment_hparams/safe/qwen

这是一个关于 Qwen（通义千问）模型安全干预实验 的专属工作台。

为了让你快速理解，我们可以把这个文件夹想象成Qwen 的“思想矫正”手术室。

1. 这个文件夹主要负责什么？

职责：Qwen 专属的安全特训中心。

在这个目录下，所有的配置都是专门为 Qwen（特别是 Qwen2.5-7B） 这个模型量身定制的。它的核心目标只有一个：让 Qwen 变得更安全，不再说脏话或有毒的内容。

它不负责训练模型（那是“上学”），它负责对已经训练好的模型进行微调和干预（这是“心理辅导”或“脑科手术”）。

2. 这里的“直接文件”是干什么的？

这里只有一个核心的直接文件：📄 qwen_config.yaml。

如果把这次实验比作一场手术，那这个文件就是“手术总方案”或“总指挥官”。

它不包含具体的手术刀法（刀法在子文件夹里），但它规定了整场手术的流程： * 指定病人：确认是给 Qwen2.5-7B 做手术。 * 指定病灶：指出我们要去除的是 toxicity（毒性/脏话）。 * 调度资源：告诉程序去哪里找“手术刀”（引用子文件夹里的配置）。 * 规定流程： 1. 先找病灶（生成毒性向量）。 2. 再切病灶（加载向量并干预模型）。 3. 最后体检（用测试题考考它，看还说不说脏话）。

简单说：它是整个文件夹的大脑，它把具体的工具（子文件夹）和实验目标串联了起来。

3. 子文件夹的作用是什么？（概括）

如果 qwen_config.yaml 是指挥官，那这些子文件夹就是不同的“兵种”或“工具箱”。它们提供了不同的干预手段：

  • 📁 caa/ (Contrastive Activation Addition)
    • 这是一个“特定流派的工具箱”。里面装着 CAA 这种算法的具体参数。指挥官会调用这里的配置来提取“毒性特征”。
  • 📁 lm_steer/ (Language Model Steering)
    • 这是“另一个流派的工具箱”。如果不想用 CAA，可以用这种方法来引导模型。
  • 📁 prompt/
    • 这是“话疗工具箱”。里面可能包含一些特殊的提示词策略，用纯文本的方式去测试或引导模型。

总结： 它们是具体的实施细节，而外面的 qwen_config.yaml 负责决定用哪一个工具箱以及怎么组合使用。

4. 高层认知：一句话理解这部分代码

这部分代码在做一个“非侵入式脑机接口”实验：

我们不重新训练 Qwen 的大脑（那样太贵太慢），而是通过这些配置文件，找到 Qwen 大脑里控制“说脏话”的那根神经（Vector），然后用一个外挂装置（Steering）按住这根神经。

这个文件夹就是用来配置“怎么找这根神经”以及“按住它之后怎么测试效果”的地方。
