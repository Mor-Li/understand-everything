hparams/Steer/experiment_hparams/merge/gemma

这是一个关于 hparams/Steer/experiment_hparams/merge/gemma 目录的快速指南。

为了让你一眼看懂，我们将这个目录比作一个 “Gemma 模型的专属改装车间”。

1. 这个文件夹主要负责什么？

核心功能：Gemma 模型的“性格融合”实验总控台。

这个文件夹专门针对 Gemma-2-9b 这个特定模型，定义了如何通过“模型融合（Model Merging）”的技术来提取特征向量，并用这个向量去干预模型的行为。它规定了实验的全流程：从提取向量，到注入模型，再到最后做题测试。

2. 直接文件是干什么的？

这里只有一个核心的直接文件：

  • 📄 gemma_config.yaml
    • 角色：车间主任的“施工图纸” (总指挥)。
    • 作用：这是你运行实验时主要调用的文件。它不包含具体的数学公式，而是负责调度资源和安排流程。
    • 它说了算的事：
      • 选谁：用 Gemma-2-9b 模型。
      • 用啥招：去子文件夹里调用哪一种融合算法（比如 Linear 还是 Ties）。
      • 怎么测：做完手术后，让模型回答哪些问题（毒性测试、情感测试）。
    • 简单说：程序读这个文件，就知道“我们要对 Gemma 做什么，以及怎么做”。

3. 子文件夹的作用是什么？

  • 📁 merge/
    • 角色：具体的“技能包”仓库。
    • 作用：这里面存放着各种具体的“提炼向量的方法论”。
    • 概括：如果 gemma_config.yaml 是决定“我们要炒个菜”，那么这个子文件夹里放的就是具体的“菜谱”（是清蒸、红烧还是油炸）。主配置文件会从这里面挑选一个方法来执行。

4. 高层认知：一句话理解这部分代码

你可以把这个文件夹看作是 Gemma 模型的“性格整容手术方案”：

gemma_config.yaml (手术方案) 决定了我们要给 Gemma 做手术。它会指派 merge/ (手术工具箱) 里的某种具体技术（比如线性融合刀法），切下一个“特征向量”，然后装回 Gemma 脑子里，看看它会不会变聪明或者变老实。
