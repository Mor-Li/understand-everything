1. 📂 当前文件夹 (experiments/py) 主要负责什么？

如果把整个项目比作一家医院，那么 experiments/py 就是“手术操作间”。

  • 功能：这里存放的是可以直接运行的 Python 脚本。
  • 定位：它不是用来存放基础理论（数学公式）或底层工具（手术刀制造图纸）的，而是用来真正执行任务的地方。如果你想亲手试一试给模型“做手术”，或者跑一个实验看看效果，你就要来这里。

2. 📄 这个文件夹下的直接文件是干什么的？

根据你提供的内容，这里目前只有一个核心文件：

📄 demo.py

  • 角色：“标准手术演示”脚本（或者叫“新手引导教程”）。
  • 作用：它把复杂的模型编辑技术封装成了一个一键运行的流程。
  • 它具体做了什么（通俗版）：
    1. 叫号：把病人（大模型）和翻译（Tokenizer）请进房间。
    2. 定方案：决定用什么手术方案（比如 ROME 算法），要把“埃菲尔铁塔在巴黎”改成“在罗马”。
    3. 术前检查：先问模型“塔在哪？”，确认它现在认为是巴黎。
    4. 动刀：调用后台的算法工具，修改模型神经元。
    5. 术后复查：再问模型“塔在哪？”，确认它改口说是罗马了。
    6. 出报告：把修改前后的回答打印出来给你看。

简单说： 它是整个项目的入口点，让你能最快看到模型编辑是真实有效的。
