easyeditor/models/memit/memit_main.py

这份代码实现的是 MEMIT (Mass-Editing Memory in a Transformer) 算法的核心逻辑。

简单来说，它的功能是给大模型做“脑外科手术”。如果你想让模型记住“埃菲尔铁塔在罗马”（即使是错的，或者更新过时的信息），你不需要重新训练模型，而是直接通过数学计算，修改模型内部神经元的权重参数，把这个知识“注射”进去。

为了让你听懂，我把这个复杂的数学过程拆解成一个“任务清单 (To-Do List)”，就像你是一个主刀医生，正在一步步执行手术。

📋 MEMIT 手术任务清单

我们将整个代码逻辑拆分为 6 个步骤：

  1. 【术前准备】清洗输入数据 (标准化 Prompt)
  2. 【设定目标】计算最终想要得到的输出 (计算 Target Z)
  3. 【定位病灶】找到触发记忆的神经元位置 (计算 Input K)
  4. 【计算偏差】算出当前模型和目标的差距 (计算 Residual)
  5. 【保护机制】调取过往病历，防止误伤 (利用 Covariance 协方差矩阵)
  6. 【执行手术】求解方程并修改权重 (Update Weights)

🧐 逐步代码详解

1. 【术前准备】清洗输入数据

代码位置： execute_memit 函数的前半部分。 任务： 确保输入的句子格式正确，模型能读懂。

  • 逻辑： 用户给的请求（比如 {"subject": "iPhone 14", "prompt": "{} is produced by Apple"}）可能格式不统一。代码会把 Prompt 里的 subject 替换成占位符 {}，并处理空格，确保 Tokenizer 切词正确。
  • 代码片段： python if request["target_new"][0] != " ": ... # 加空格 requests[i]['prompt'] = requests[i]['prompt'].replace(...) # 格式化 prompt

2. 【设定目标】计算最终想要得到的输出 (Target Z)

代码位置： execute_memit 中调用 compute_z 的部分。 任务： 我们希望模型看到“埃菲尔铁塔”时，最后一层输出的向量能代表“罗马”。

  • 逻辑：
    • MEMIT 不仅仅修改一层，它涉及多层。
    • 它首先计算：如果模型已经学会了这个新知识，那么在最后一层，针对“埃菲尔铁塔”这个词，它的向量表示（Z向量）应该是什么样子的？
    • 代码里会检查有没有缓存（Cache），没有的话就现场算。
  • 代码片段： python cur_z = compute_z(..., z_layer, ...) # 计算目标向量 Z zs = torch.stack(z_list, dim=1) # 堆叠所有请求的 Z

3. 【定位病灶】找到触发记忆的神经元位置 (Input K)

代码位置： execute_memit 中的 for i, layer in enumerate(hparams.layers): 循环内部。 任务： 在我们要修改的每一层，找出是什么样的输入信号（Key）触发了关于“埃菲尔铁塔”的记忆。

  • 逻辑：
    • 模型是层层传递的。在第 L 层，输入是“埃菲尔铁塔”经过前 L-1 层处理后的结果。
    • 这个输入被称为 $k$ (Key)。我们要修改这一层的权重 $W$，使得 $W \times k$ 能够接近我们的目标。
  • 代码片段： python layer_ks = compute_ks(..., layer, ...).T # 计算当前层的输入 K

4. 【计算偏差】算出当前模型和目标的差距 (Residual)

代码位置： execute_memit 循环内部，计算 targets 的部分。 任务： 看看模型现在的反应和我们期望的反应差多少，把这个差距分摊给剩下的层去修补。

  • 逻辑：
    • cur_zs 是模型目前的输出。
    • targets = zs - cur_zs 是我们还差多少。
    • MEMIT 的精髓在于它不是在一层里改完，而是把这个误差平均分摊到剩下的几层里 (len(hparams.layers) - i)，每层修一点，这样更稳定。
  • 代码片段： python targets = zs - cur_zs # 总差距 resid = targets / (len(hparams.layers) - i) # 分摊给当前层的任务

5. 【保护机制】调取过往病历，防止误伤 (Covariance)

代码位置： get_cov 函数 以及 execute_memit 中计算 adj_k 的部分。 任务： 修改权重时，不能破坏模型已有的通用语言能力（比如语法、其他常识）。

  • 逻辑：
    • 如果我们只为了迎合“埃菲尔铁塔”，可能会导致模型连“你好”都不会说了。
    • 协方差矩阵 (Covariance Matrix) 记录了模型在读取海量普通文本时，神经元的激活统计规律。
    • 在计算更新量时，除以这个协方差矩阵（求逆），相当于告诉算法：“在那些大家通用的方向上不要乱动，只在‘埃菲尔铁塔’特有的方向上动刀”。
  • 代码片段： python cov = get_cov(...) # 获取协方差统计 # 核心公式：利用最小二乘法求解，其中包含了 cov 作为正则项/约束 adj_k = torch.linalg.solve( hparams.mom2_update_weight * cov.double() + layer_ks @ layer_ks.T, layer_ks, )

6. 【执行手术】求解方程并修改权重 (Update Weights)

代码位置： execute_memit 循环的末尾 和 apply_memit_to_model。 任务： 算出具体的参数变化量 $\Delta W$，并加到原模型上。

  • 逻辑：
    • 根据刚才算的输入 $k$、目标残差 $resid$ 和保护机制 $cov$，算出一个更新矩阵 upd_matrix。
    • 在 execute_memit 里，它只是计算出这个变化量（Delta）。
    • 最后在 apply_memit_to_model 里，才真正把这个 Delta 加到模型的 weight 上。
  • 代码片段： python upd_matrix = resid @ adj_k.T # 算出更新矩阵 # ... weights[weight_name][...] = weights_copy[weight_name] + upd_matrix.float() # 执行修改

总结

这个文件的核心思想就是： 不要暴力覆盖，要“顺势而为”。

它先算出目标是什么（Step 2），然后一层一层地（Step 3）看当前缺多少（Step 4），利用统计学数据保护通用能力（Step 5），最后算出最优雅的权重修改方案（Step 6）并注入模型。
