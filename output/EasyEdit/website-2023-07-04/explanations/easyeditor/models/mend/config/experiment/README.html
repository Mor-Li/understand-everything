easyeditor/models/mend/config/experiment

这里是 easyeditor/models/mend/config/experiment 目录的高层解读。

你可以把这个文件夹看作是 MEND 模型的“考试科目表” 或者 “场景模式切换器”。

1. 这个文件夹主要负责什么？

如果说 MEND 算法是一个“AI 脑科医生”，那么这个文件夹里的文件就是告诉医生：“今天我们要给病人做什么类型的体检？”

它不包含复杂的算法代码，只包含配置（Configuration）。它的核心作用是定义实验场景： * 我们要测什么能力？（是测它改错的能力，还是测它写作文的能力？） * 我们要用哪本习题集？（是用维基百科，还是用专门的问答题库？） * 我们要把“手术刀”的力度调到多少？（参数设置）

2. 各个直接文件（📄）分别是干什么的？

这三个文件代表了三种不同的“游戏模式”或“考试科目”：

  • 📄 fc.yaml (Fact Checking - 事实核查模式)

    • 角色：“判官”。
    • 作用：测试模型辨别真假的能力。
    • 场景：给模型一句像“企鹅会飞”的话，看它能不能利用编辑后的知识判断这是错的。它绑定了 FEVER 数据集（专门做真假判断题的题库）。

  • 📄 gen.yaml (Generation - 文本生成模式)

    • 角色：“作家”。
    • 作用：测试模型续写文章的能力。
    • 场景：给模型一个开头，让它往下编故事。这通常用来测试编辑模型后，它的语言组织能力有没有退化。它绑定了 WikiText-103 数据集（海量的文章素材）。

  • 📄 qa.yaml (Question Answering - 问答模式)

    • 角色：“答题选手”。
    • 作用：测试模型精准回答问题的能力。
    • 场景：直接问“埃菲尔铁塔在哪？”，看它能不能答出我们刚教给它的新知识。它绑定了 ZsRE 数据集（专门的关系抽取问答题库）。

4. 高层认知：一句话秒懂

这部分代码的作用就是 “套餐选择按钮”。

当你运行 MEND 代码时，你不需要手动去改几十行代码来切换任务，你只需要指定 config=fc 或 config=qa。程序就会自动读取这里对应的 .yaml 文件，瞬间把任务目标、题库数据和算法力度全部配置好，一键启动对应的实验。
