easyeditor/models/mend/data_classes/wiki.py

这个代码文件 wiki.py 是 MEND（一种大模型编辑算法）用来处理 Wiki（维基百科）数据的“搬运工”。

它的核心任务是：准备好“我要改什么知识（Edit）”和“我要保持什么知识不变（Locality）”的数据，喂给模型去训练。

为了让你听懂，我把这个代码做的事情拆解成一个 “模型编辑手术前的准备清单” (To-Do List)，我们一步步来看：

📋 Task List：模型编辑数据准备清单

  1. 清洗工具准备：把不合格的文本（乱码、太短的）扔掉。
  2. 进货（初始化）：
    • 加载“普通背景知识库”（用来防止模型被改坏）。
    • 加载“手术修改清单”（具体的修改目标）。
  3. 打包发货（生成器）：把数据组合成模型训练需要的 4 个特殊部分（Inner, Outer, Loc, Cond）。
  4. 贴标签（Labeling）：告诉模型哪部分是需要背诵的答案，哪部分是题目。

🧐 详细步骤讲解

第一步：清洗工具准备 (is_ascii, filter_text)

代码位置：文件最上面的两个函数。

  • 观点：大模型训练时，如果数据太脏（比如全是乱码或者只有两三个词），会影响效果。
  • 动作：
    • is_ascii: 检查是不是纯英文字符（过滤掉奇怪符号）。
    • filter_text: 只要那些长度大于 50 个词、且是纯英文的文本。其他的统统扔掉。

第二步：进货 (GenDataset.__init__)

代码位置：class GenDataset 的 __init__ 部分。

  • 观点：模型编辑需要两种数据。一种是Edit Data（比如“把英国首相改成苏纳克”），另一种是Locality Data（无关数据，比如“爵士乐的历史”，用来测试改完首相后，模型会不会忘记爵士乐怎么介绍）。
  • 动作：
    1. 加载背景数据 (base_samples)：默认加载 wikitext-103（维基百科文本）。如果配置里开了 wiki_webtext，就改用 openwebtext。这些数据经过第一步的清洗，用来做“无关数据”测试。
    2. 加载编辑数据 (edit_samples)：读取一个 JSON 文件（edit_path）。这个文件里存的是我们要修改的具体样本（比如：Input="Who is the president?", Target="Biden"）。

第三步：打包发货 (edit_generator) —— 这是最核心的部分

代码位置：edit_generator 函数。

  • 观点：MEND 算法非常特殊，它训练一次需要喂给模型 4 份 数据。

    • Edit Inner: 用来计算梯度的（告诉模型怎么改）。
    • Edit Outer: 用来验证改没改成功的（通常是同义句，看模型能不能举一反三）。
    • Loc: 用来测试稳定性的（无关文本，要求模型改完后，这部分预测不能变）。
    • Cond: 只有 MEND 这种元学习模型才需要，作为条件输入。

  • 动作（循环执行）：

    1. 抽样 (sampler.sample)：从数据库里随机挑出几个“修改样本”和几个“背景样本”。
    2. Tokenize：把文本变成机器能读懂的数字（Input IDs）。
    3. 构建 4 大件：
      • edit_inner: 直接用编辑样本。
      • edit_outer: 复制一份 edit_inner。注意代码里有个 rephrase 逻辑：如果开启重述，它会随机切掉前面的一段话，强迫模型根据残缺的上下文去预测，增加难度。
      • loc: 使用背景样本（无关文本）。
      • cond: 这里直接复制了 edit_toks。
    4. Yield：把打包好的这堆东西（字典格式）发送给 GPU 去训练。

第四步：贴标签 (get_edit_labels, get_labels)

代码位置：类底部的两个函数。

  • 观点：在训练语言模型时，我们不希望模型去学习“问题”是什么，只希望它学习“答案”是什么。
  • 动作：
    • Masking (-100)：在 PyTorch 里，如果 Label 是 -100，计算 Loss（误差）时就会忽略它。
    • get_edit_labels: 这是一个专门为编辑设计的标签函数。它会计算句子的长度，然后把最后几个词（Target/答案） 留着，把前面的所有词（Question/Prompt）都变成 -100。
      • 例子：如果句子是 "The sky is [blue]"。我们只想让模型学 "blue"，不想让它重复学 "The sky is"。
    • get_labels: 这是给普通文本用的，只把 Padding（填充的 0）变成 -100。

总结：这个文件在干嘛？

想象你在教一个学生（模型）改错题：

  1. __init__ 是你的书包，装了错题本（Edit Samples）和语文课本（Base/Locality Samples）。
  2. edit_generator 是你在出考卷。
    • 你挑一道错题放在第一题（Edit Inner），让他重做。
    • 你把这道错题换个问法放在第二题（Edit Outer），看他是不是真懂了。
    • 你从语文课本里随便抄一段话放在第三题（Loc），看他改错题改得脑子乱没乱（能不能正常阅读普通文章）。
  3. get_edit_labels 是你的红笔，你只批改答案部分，题目抄错了你不管（Mask 掉）。

这个 wiki.py 就是负责不停地生成这种“考卷”给 MEND 模型去训练的。
