docs/preparation/install.rst

这份文件其实是 veRL（一个用于大模型强化学习训练的库）的安装说明书。它充满了技术术语，所以看起来很晕。

简单来说，它的核心思想是：先建环境，再下源码，最后装依赖。

我把它拆解成一个 “保姆级” Todo List，你可以按这个顺序一步步理解：

第一阶段：打地基（准备环境）

在安装任何软件之前，你需要先准备好运行它的“房间”（虚拟环境）和“电力系统”（CUDA）。

  • Task 1: 检查你的硬件和驱动

    • 文中要求：你的电脑或服务器必须有 NVIDIA 显卡，且 CUDA 版本要大于等于 12.1。
    • 人话：这是硬指标，版本太低跑不起来。

  • Task 2: 创建一个独立的“房间” (Conda 环境)

    • 文中要求：推荐使用 Conda。
    • 操作：
      1. 创建一个叫 verl 的环境，指定 Python 版本为 3.9：conda create -n verl python==3.9
      2. 进入这个环境：conda activate verl
    • 为什么：防止安装过程中搞乱你电脑里其他的软件环境。

第二阶段：把 veRL 本体搬回家（安装主程序）

这里文中有两种方法，它强烈推荐第一种。

  • Task 3: 下载并安装 veRL 源码 (推荐)

    • 操作：
      1. 用 git 把代码拉下来：git clone https://github.com/volcengine/verl.git
      2. 进入文件夹：cd verl
      3. 以编辑模式安装：pip3 install -e .
    • 为什么：因为这个库可能需要你以后自己改代码（DIY），这种安装方式允许你改了代码立即生效，不用重装。

  • (可选 Task: 如果你不想改代码，只想用，可以直接 pip3 install verl，但不推荐)

第三阶段：安装“发动机”配件（基础依赖）

veRL 只是一个壳子，它底层运行需要依赖其他强大的库（PyTorch, vLLM 等）。这一步是必须做的。

  • Task 4: 安装 PyTorch (核心计算框架)

    • 注意：版本卡得很死。
    • 操作：安装 PyTorch 2.4.0 版本，对应 CUDA 12.1。

  • Task 5: 安装 vLLM 和 Ray (推理和调度框架)

    • 注意：版本也卡得很死，别乱升级。
    • 操作：
      1. 安装 vLLM 版本 0.5.4（用来快速生成文本）。
      2. 安装 Ray 版本 2.10（用来管理多卡并行）。文中特意说了，别的版本有 Bug。

  • Task 6: 安装 Flash Attention 2 (加速插件)

    • 操作：pip3 install flash-attn --no-build-isolation
    • 作用：这是一个让模型训练跑得更快的加速包。

第四阶段：(可选) 开启“涡轮增压”模式 (Megatron-LM)

如果你是初学者，这一步可以先跳过。 这是为了追求极致性能（Scalability）的高级玩家准备的。默认用上面的 FSDP 模式就够了。

  • Task 7: 安装高级并行库 (Megatron-LM)
    • 前置条件：必须先完成上面的 Task 4, 5, 6。
    • 操作：
      1. 安装 Apex 和 TransformerEngine（NVIDIA 的底层加速库，非常难装，很容易报错）。
      2. 下载 Megatron-LM 的特定版本（core_v0.4.0）。
      3. 打补丁：文中提到 veRL 对 Megatron 做了一些修改，你需要把 verl/patches/megatron_v4.patch 这个补丁文件复制过去，然后运行 git apply。这一步是为了修 bug。

总结你的执行路线：

  1. 建 Conda 环境 (Python 3.9)。
  2. Git Clone 源码 并 pip install -e .。
  3. 乖乖按指定版本号安装 PyTorch, vLLM, Ray。
  4. 安装 Flash Attention。
  5. (初学可无视) 如果需要搞超大模型，再去折腾 Megatron-LM 和它的补丁。
