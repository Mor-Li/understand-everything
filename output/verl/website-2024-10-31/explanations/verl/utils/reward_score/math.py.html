verl/utils/reward_score/math.py

这份代码的主要目的是自动批改数学题。

具体来说，它是针对大语言模型（LLM）生成的数学答案（通常是 LaTeX 格式）与标准答案（Ground Truth）进行比对，判断模型回答是否正确。

因为数学公式的写法非常多变（比如 $\frac{1}{2}$ 和 $0.5$ 是一样的，\sqrt3 和 \sqrt{3} 是一样的），所以不能直接简单地对比字符串。这份代码做了大量的“清洗”和“标准化”工作。

我们可以把这个过程想象成一个阅卷老师的“Todo List”，以下是每一步的详细任务拆解：

阅卷流程 Todo List

1. 第一步：从长篇大论中找到“最终答案” (Extraction)

模型在解题时会写很多推导过程（Chain of Thought），但我们只关心最后的结果。 * 任务目标：找到被 \boxed{...} 包裹的内容。在数学竞赛数据集（如 MATH）中，标准格式是把最终答案放在这个框里。 * 对应函数： * last_boxed_only_string(string): 寻找字符串中最后一个 \boxed 出现的位置，并利用括号匹配逻辑（处理嵌套的 {}）把整个框取出来。 * remove_boxed(s): 把取出来的 \boxed{答案} 外面的壳去掉，只留下里面的 答案。

2. 第二步：格式标准化 (Normalization) - 这是最核心的部分

拿到答案后，不能直接比对，因为写法太多样了。需要把模型生成的答案和标准答案都转换成“同一种标准格式”。 * 任务目标：消除格式差异，把所有等价的数学表达统一化。 * 对应函数：strip_string(string) 及其调用的辅助函数。 * 具体子任务清单： * 去噪：去掉换行符 \n，去掉空格，去掉 \$ 符号，去掉百分号 \%。 * 统一命令： * 把 \dfrac 和 \tfrac 全部变成 \frac（分数的不同写法）。 * 去掉 \left 和 \right（LaTeX 中用于自动调整括号大小的命令，对数值无影响）。 * 处理单位和度数：去掉 ^\circ（度数符号），去掉位于右侧的文本单位（remove_right_units）。 * 处理根号：fix_sqrt。 * 例子：把 \sqrt3 变成标准的 \sqrt{3}。 * 处理分数：fix_fracs 和 fix_a_slash_b。 * 例子：把 \frac12 变成 \frac{1}{2}。 * 例子：把 1/2 变成 \frac{1}{2}。 * 例子：把 0.5 强制变成 \frac{1}{2}（代码里硬编码了这一条）。 * 处理小数点： * 例子：把 .5 变成 0.5。

3. 第三步：最终比对 (Comparison)

经过第二步的“强力清洗”，两个答案应该都变成了最纯粹的数学字符串。 * 任务目标：判断清洗后的字符串是否完全一致。 * 对应函数：is_equiv(str1, str2)。 * 它会先对两个字符串都执行 strip_string。 * 然后检查 清洗后的答案 == 清洗后的标准答案。

4. 第四步：打分 (Scoring)

  • 任务目标：输出 0 或 1。
  • 对应函数：compute_score(solution_str, ground_truth)。
    • 这是整个文件的入口。
    • 它按顺序执行：提取 -> 清洗 -> 比对。
    • 如果 is_equiv 返回 True，得 1.0 分。
    • 否则，得 0.0 分。

举个直观的例子

假设题目答案是 $\frac{1}{2}$。

标准答案 (Ground Truth): \frac{1}{2} 模型输出 (Solution): 根据计算，结果是 \boxed{0.5}。

代码执行流程：

  1. 提取：last_boxed_only_string 看到 \boxed{0.5}，提取出 0.5。
  2. 清洗模型答案：strip_string("0.5")。
    • 代码里有一行 if string == "0.5": string = "\\frac{1}{2}"。
    • 结果变为 \frac{1}{2}。
  3. 清洗标准答案：strip_string("\frac{1}{2}")。
    • 去掉空格等，结果还是 \frac{1}{2}。
  4. 比对：\frac{1}{2} == \frac{1}{2}。
  5. 结果：返回 1.0 分。

总结

这个文件的作用就是“数学公式的翻译官和裁判”。它不进行数学运算（比如它不知道 1+1=2），它只是通过极其复杂的字符串替换规则，把各种花里胡哨的数学写法变成统一的格式，然后进行字符串匹配。
