examples/data_preprocess/math.py

这份代码看起来可能有点枯燥，因为它属于数据工程（Data Engineering）脚本。

简单来说，这个脚本的目的是：把原始的数学题库（MATH dataset），“清洗”并“打包”成一种特定的格式，以便后续用来训练 AI 模型（特别是强化学习模型）。

这就好比你要教一个小孩做数学题，你不能直接把乱七八糟的草稿纸扔给他，你需要把题目抄写清楚，告诉他“请把答案写在方框里”，并准备好标准答案以便批改。

为了让你更容易理解，我把这个脚本的工作拆解成一张 Project Todo List（任务清单），我们一步步来看：

📋 任务清单 (Todo List)

  1. 【准备原料】下载原始数学题库
  2. 【制定规则】定义“如何提取标准答案”
  3. 【设计指令】告诉 AI 该怎么做题 (Prompt Engineering)
  4. 【核心加工】把每一道题重新包装成标准格式
  5. 【入库保存】把处理好的数据存成文件

📝 逐步讲解 (Step-by-Step)

1. 【准备原料】下载原始数学题库

代码位置：

data_source = 'lighteval/MATH'
dataset = datasets.load_dataset(data_source, trust_remote_code=True)
train_dataset = dataset['train']
test_dataset = dataset['test']

解读： * 这步就像是去菜市场买菜。脚本从 Hugging Face（一个开源模型和数据社区）下载名为 lighteval/MATH 的数据集。 * 它把数据分成了两堆：一堆用来训练（train），一堆用来测试（test）。

2. 【制定规则】定义“如何提取标准答案”

代码位置：

from verl.utils.reward_score.math import remove_boxed, last_boxed_only_string

def extract_solution(solution_str):
    return remove_boxed(last_boxed_only_string(solution_str))

解读： * 数学题的答案往往很长，包含解题过程。比如：“因为x+1=2，所以x=1，答案是 \boxed{1}”。 * 为了让电脑能自动判卷（计算 Reward/奖励），我们需要把那个最终的数字 1 抠出来。 * 这个函数的作用就是：只保留 \boxed{} 里面的内容作为最终的标准答案（Ground Truth）。

3. 【设计指令】告诉 AI 该怎么做题

代码位置：

instruction_following = "Let's think step by step and output the final answer within \\boxed{}."

解读： * 这叫 Prompt Engineering（提示词工程）。 * 我们在每道题后面加了一句话：“让我们一步步思考，并把最终答案放在 \boxed{} 里。” * 这样做有两个目的： 1. 激发 AI 的思维链（Chain of Thought），让它算得更准。 2. 强制 AI 按格式输出，方便我们在第2步里提取答案来判分。

4. 【核心加工】把每一道题重新包装成标准格式

代码位置： (make_map_fn 和里面的 process_fn) 这是整个脚本最重要的地方。它把原始数据变成了一个复杂的字典（Dictionary）。

它做了这几件事： * 处理问题 (Question): 把原始题目 + 第3步的指令，组合成用户发给 AI 的对话格式 (role: user, content: ...)。 * 处理答案 (Answer): 用第2步的规则，从原始答案里提取出纯净的结果。 * 贴标签: 标记这道题的能力类型是 math，并设置奖励模型（Reward Model）的类型为 rule（规则匹配，即答案对就是对，错就是错）。

转换后的数据长这样（示例）：

{
    "prompt": [{"role": "user", "content": "1+1等于几? Let's think step by step..."}],
    "reward_model": {
        "style": "rule",
        "ground_truth": "2" 
    },
    "ability": "math"
}

5. 【入库保存】把处理好的数据存成文件

代码位置：

train_dataset.to_parquet(os.path.join(local_dir, 'train.parquet'))
# ...
if hdfs_dir is not None:
    copy(src=local_dir, dst=hdfs_dir)

解读： * Parquet 格式： 这是一种压缩率高、读取速度快的文件格式，非常适合存大数据。 * 脚本把处理好的“训练集”和“测试集”保存到本地。 * HDFS： 如果你提供了远程服务器地址（HDFS），它还会把文件自动备份到云端服务器上。

总结

这个脚本其实就是一个流水线工人： 1. 拿来一本数学习题集（原始数据）。 2. 给每道题后面盖个章：“请写出步骤并把答案填在框里”（添加指令）。 3. 把答案页撕下来，只把最终结果抄在评分卡上（提取 Ground Truth）。 4. 把题目、要求、标准答案装进一个标准化的档案袋里（格式化为 JSON/Dict）。 5. 最后把这些档案袋打包封箱（存为 Parquet 文件），准备送去给 AI 上课。
