.github/workflows

这个 .github/workflows 文件夹，就是这个软件项目的 “全自动质检流水线总控室”。

你可以把整个代码库想象成一个 “汽车制造厂”，而这个文件夹里的每一个 .yml 文件，都是一份写给机器人的 “岗位操作手册”。

每当有程序员提交了新代码（相当于送来了一个新零件），GitHub 就会根据这些手册召唤出不同的机器人，对这些零件进行疯狂的测试。

以下是具体的通俗解释：

1. 当前文件夹的主要功能：机器人工头

一句话解释： 这里的代码不产生任何实际的软件功能，它们是用来指挥 GitHub 服务器怎么干活的。

  • 什么时候干活？ (比如：有人提交代码了、每天凌晨、或者手动点击)。
  • 去哪干活？ (比如：申请一台 CPU 电脑，还是申请一台带 8 张显卡的豪车)。
  • 干什么活？ (比如：查错别字、跑数学题、训练一个 AI 模型试试)。

2. 各个直接文件的作用：分工明确的质检员

这里的几十个文件看起来很乱，但其实可以分为 四大类工种：

第一类：门口保安与保洁 (轻量级检查)

这些机器人跑得快、花钱少，主要负责检查“面子工程”和安全性。

  • check-pr-title.yml：门卫大爷。检查你提交代码的标题写得规不规范，不规范不让进。
  • sanity.yml：神智检查员。检查代码有没有最基本的低级错误（比如文件名不对、版权声明没写）。
  • pre-commit.yml / pre-commit-full.yml：代码保洁阿姨。检查代码排版乱不乱，有没有多余的空格，格式是否统一。
  • secrets_scan.yml：安检员。拿着 X 光机扫描代码，看有没有人不小心把密码、私钥这种机密带进去了。
  • type-coverage-check.yml：语法老师。检查 Python 代码有没有乖乖写清楚变量类型（是整数还是字符串）。
  • doc.yml：图书管理员。检查文档能不能正常生成，有没有死链接。
  • scorecard.yml：安全审计官。给整个项目的安全性打分，发小红花（徽章）。

第二类：零件测试员 (单元测试)

这些机器人负责把汽车拆散了，一个零件一个零件地测。

  • cpu_unit_tests.yml：普通零件测试员。在便宜的 CPU 电脑上跑，测那些不需要显卡的小逻辑。
  • gpu_unit_tests.yml：核心零件测试员。在带显卡的电脑上跑，专门测那些必须用 GPU 才能跑的基础代码。

第三类：总成测试员 (组件集成测试)

这些机器人负责测试汽车的大部件（比如发动机、变速箱）能不能正常工作。

  • model.yml：引擎测试员。专门测试各种 AI 模型（Transformer, Llama 等）能不能跑通，特别是多显卡并行的时候会不会炸。
  • vllm.yml / sgl.yml：加速器测试员。专门测试 vLLM 和 SGLang 这两个核心加速引擎是否工作正常。
  • checkpoint_converter.yml：格式转换员。测试能不能把别人的模型格式（HuggingFace）转换成我们自己的格式（Megatron）。

第四类：试车员 (端到端 E2E 测试)

这是最昂贵、最复杂的测试。机器人会把整辆车组装好，去赛道上跑几圈。凡是以 e2e_ 开头的文件都属于这一类。

  • e2e_ppo_trainer...yml / e2e_sft.yml / e2e_spin.yml / e2e_sppo.yml / e2e_dapo.yml：
    • 这些是 “不同赛道的试车员”。
    • 它们分别模拟 SFT（微调）、PPO（强化学习）、SPIN、SPPO 等不同的训练算法流程。
    • 它们会真的去下载数据、下载模型、启动 8 张显卡，从头到尾训练一遍，确保整个流程没问题。
  • e2e_ascend.yml：国产赛道试车员。专门在华为昇腾（Ascend NPU）芯片上跑全流程，确保国产硬件也能用。
  • e2e_eval_aime24.yml：做题家。让模型去考数学题（AIME24），看看代码改动后，模型有没有变笨。

3. 子文件夹的作用

  • 📁 disabled/：仓库/停尸房。
    • 这里面放的是以前用过，但现在暂时不需要、或者坏掉了、或者不想跑的测试流程。放在这里 GitHub 就不会执行它们。

4. 高层认知总结

如果你是老板，你应该这样理解这部分代码：

这是一套价值连城的自动化防御系统。

它的作用是：“拦截烂代码”。

无论是实习生不小心写了个 Bug，还是资深工程师改坏了底层逻辑，甚至是黑客想混入恶意代码，只要经过这几十个机器人的层层扫描（从查错别字到动用 8 张显卡跑训练），任何问题都会在代码合并进主分支之前被揪出来。

它是保证这个 AI 框架稳定、可靠、安全的最后一道防线。
