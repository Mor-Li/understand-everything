examples/data_preprocess/full_hh_rlhf.py

这份代码其实是一个“数据备菜员”。

在训练一个像 ChatGPT 这样的大模型（特别是 RLHF，即“人类反馈强化学习”阶段）时，我们需要把原始食材（原始数据集）切成三种不同的形状，分别喂给三个不同的训练阶段。

这个脚本就是用来做这件事的。它下载一个叫 Dahoas/full-hh-rlhf 的公开数据集，然后把它转换成 SFT、RM 和 RL 三种格式。

我为你列了一个 Task TODO List，带你一步步看懂它是怎么工作的：

📝 任务清单 (Task List)

  1. 准备阶段：下载原始数据集（全是“对话”数据）。
  2. 任务一 (SFT)：制作“照着学”的数据。把所有对话拆开，让模型学会怎么说话。
  3. 任务二 (RM)：制作“打分裁判”的数据。把好回答和坏回答放在一起，让模型学会分辨好坏。
  4. 任务三 (RL)：制作“正式考试”的数据。只保留题目（Prompt），把格式整理好，准备让模型自己生成答案并接受打分。
  5. 收尾：把处理好的数据存成文件（Parquet格式）。

🔍 逐步详细讲解

0. 原始数据是什么？

代码里用的是 Dahoas/full-hh-rlhf。它的每一条数据长这样： * Prompt: 用户问的问题。 * Chosen: 人类认为较好的回答。 * Rejected: 人类认为较差的回答。

1. 任务一：生成 SFT 数据 (generate_sft_dataset)

目标：SFT (Supervised Fine-Tuning) 是为了让模型学会基本的对话能力。

  • 代码逻辑：
    • 它遍历了所有数据。
    • 关键点：它非常“贪心”，把“好回答”和“坏回答”都拿来用了（代码注释写了：Both chosen and rejected is used to train SFT）。
    • 它把数据拆成了两行：
      1. Prompt + Chosen (作为标准答案)
      2. Prompt + Rejected (也作为标准答案)
  • 结果：数据量变为了原来的两倍。虽然混入了坏回答，但这一步通常是为了让模型先学会“把句子写通顺”。
  • 输出格式：两列 -> prompt, response。

2. 任务二：生成 RM 数据 (generate_rm_dataset)

目标：RM (Reward Model) 是奖励模型，它像一个老师，需要学会给作业打分。

  • 代码逻辑：
    • 切分数据：它把原始数据切了一刀。前 75% 用来训练（Train），后 25% 用来测试（Test/Validation）。这是为了防止老师“死记硬背”，要测试它是否真的懂好坏。
    • 保留对比：它没有拆散数据，而是保留了“三元组”结构：Prompt（题目）+ Chosen（好答案）+ Rejected（坏答案）。
    • 这样训练时，模型会学习：“对于这个题目，Chosen 的得分 必须高于 Rejected 的得分”。
  • 输出格式：三列 -> prompt, chosen, rejected。

3. 任务三：生成 RL 数据 (generate_rl_dataset)

目标：RL (Reinforcement Learning) 是最后一步 PPO 训练。模型要根据题目自己写答案，然后拿高分。

  • 代码逻辑：
    • 这里它只关心 Prompt（题目）。因为在 RL 阶段，答案是模型自己生成的，不需要原始数据的答案。
    • 格式大变身：这段代码写得很复杂（make_map_fn），其实是为了把数据包装成 verl 这个训练框架（字节跳动的框架）能读懂的 JSON 格式。
    • 它把数据包装成了类似聊天记录的格式：[{"role": "user", "content": prompt}]。
    • 它把原始答案藏在了 reward_model -> ground_truth 里，仅供参考，不直接参与训练。
  • 输出格式：复杂的嵌套字典结构，包含 prompt, ability, reward_model 等字段。

4. 主程序入口 (if __name__ == "__main__":)

这是脚本的开关。 * 你可以通过命令行参数 --split 来告诉它你想做哪一步菜。 * 比如运行 python full_hh_rlhf.py --split sft，它就只执行任务一。 * 最后它会把处理好的数据保存到 local_dir（本地文件夹），如果配置了 hdfs_dir，还会上传到云端存储。

总结

这个脚本就是把同一块肉（原始数据）： 1. 切碎（SFT）：不管好坏，做成肉末，让模型学会怎么吃。 2. 成对摆放（RM）：好肉坏肉放一起，让模型学会挑食。 3. 精美摆盘（RL）：只给盘子（Prompt），让模型自己产出肉，并符合特定框架的餐仪标准。
