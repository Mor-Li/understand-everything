examples/sglang_multiturn/readme.md

这份文件实际上是一个操作指南（Cookbook/Recipe）。

为了让你更容易理解，我们可以把这个过程想象成“训练一个小学生（AI模型）做数学题”。这个小学生不仅要会心算，还要学会使用计算器（工具），而且是分步骤（多轮）地解决问题。

以下我为你整理的 Todo List，带你一步步拆解这份文档讲了什么：

📋 任务清单：AI 数学解题实验

🟢 Phase 1：搞清楚我们要干什么（核心概念）

任务目标：理解标题 "Multi-Turn Rollout Example (GSM8K)" 是什么意思。

  1. 理解 GSM8K：
    • 这就像是给 AI 准备的一本“小学奥数习题集”。里面全是应用题，比如“小明有3个苹果，小红给了他2个...”。
  2. 理解 Tool-calling（工具调用）：
    • 普通的 AI 只能靠“脑子”想（预测下一个字）。
    • 这里的 AI（Qwen2.5-3B）被赋予了特殊能力：它可以使用工具。比如遇到复杂计算，它可以写一段代码或调用计算器算出结果，而不是瞎猜。
  3. 理解 Multi-Turn Rollout（多轮推演）：
    • 这不是“问一句答一句”的一锤子买卖。
    • 这是一个互动的过程：AI 思考 -> 决定用工具 -> 工具返回结果 -> AI 根据结果继续思考 -> 得出最终答案。这就像你和老师一来一回的对话，或者你一步步打草稿的过程。
  4. 理解 SGLang：
    • 这是底层的“加速引擎”。有了它，AI 做题和互动的速度会更快、效率更高。

🟡 Phase 2：准备食材（数据预处理）

任务目标：执行文档中的 Step 1。

  • 原文指令：python3 gsm8k_multiturn_w_tool.py
  • 通俗解释：
    • 你刚把“习题集”买回来了，但 AI 看不懂 PDF。
    • 这一步是把 GSM8K 习题集下载下来，并整理格式（Preprocess）。
    • 整理成 AI 能够理解的“多轮对话”格式（比如：问题是什么？哪里该停下来用工具？）。
    • 结果会保存在 ~/data/gsm8k/ 目录下。

🟠 Phase 3：开始考试（运行模型）

任务目标：执行文档中的 Step 2。

这里文档给了你两个选择，取决于你家里的电脑（服务器）有多少张显卡（GPU）：

  • 情况 A：如果你是土豪（有 8 张显卡）

    • 动作：运行 run_qwen2.5-3b_gsm8k_multiturn.sh。
    • 解释：火力全开，使用标准配置让 AI 开始做题。

  • 情况 B：如果资源有限（只有 4 张显卡）

    • 动作：运行 run_qwen2.5-3b_gsm8k_multiturn_4xgpu.sh。
    • 解释：这是“低配版”启动脚本，让只有 4 张卡的人也能跑得起来。

这一步发生了什么？ 机器开始运转，AI 模型（Qwen2.5-3B）读取刚才处理好的习题，开始一道道做题。在做题过程中，它会尝试使用工具，SGLang 引擎在后台支撑它快速生成答案。

🔵 Phase 4：理解备注（Notes）

任务目标：了解目前的局限性和未来计划。

  1. 当前状态：
    • 目前的“工具”主要用来验证答案（Answer Evaluation）。意思是 AI 做完题，用工具检查一下对不对。
  2. 未来画饼：
    • 以后会加入更牛的工具，比如 Search（联网搜索） 和 Code Interpreter（代码解释器/写Python代码解题）。

总结

这份文档其实就讲了三件事： 1. 去哪下题库（Step 1）。 2. 怎么让 AI 开始做题（Step 2，分8卡和4卡两种情况）。 3. 这是个什么实验（这是一个让 AI 学会分步骤、用工具解决数学问题的实验）。
