tests/kill_github_tests.sh

这个脚本的核心作用用一句话概括就是： “帮我把 volcengine/verl 这个仓库里，所有正在排队（Queued）的测试任务全部取消掉。”

通常用于测试堆积太多，或者发现代码有错，不想浪费资源跑剩下的测试时使用。

下面我按照“程序执行的任务清单（To-Do List）”的方式，一步步给你拆解它在干什么：

📋 脚本执行任务清单 (Task To-Do List)

1. 第一步：检查“通行证” (Check Input)

代码：

if [ "$#" -ne 1 ]; then
    echo "Usage: $0 YOUR_GITHUB_TOKEN"
    ...
    exit 1
fi
  • 任务说明：程序先检查你有没有给它1个参数。
  • 人话解释：你要操作 GitHub，必须得有权限。这个参数就是你的 GitHub Token（类似密码）。如果你没给 Token，程序就报错并在第一步停止。

2. 第二步：确认“目标地址” (Set Variables)

代码：

OWNER="volcengine"
REPO="verl"
TOKEN=$1
API_URL=".../actions/runs?status=queued"
  • 任务说明：定义我们要操作哪个仓库。
  • 人话解释：
    • 房东 (Owner): volcengine
    • 房子 (Repo): verl
    • 目标: 只要状态是 queued（排队中）的任务。

3. 第三步：检查“工具” (Check Dependencies)

代码：

command -v jq >/dev/null 2>&1 || { echo "jq is required..."; exit 1; }
  • 任务说明：检查电脑里有没有安装 jq 这个工具。
  • 人话解释：GitHub 返回的数据是 JSON 格式（一大坨文本），jq 是专门用来拆解这种格式的“手术刀”。如果没把刀，后面的活儿没法干，程序退出。

4. 第四步：去拿“排队名单” (Fetch Data)

代码：

response=$(curl -s -H "Authorization: token $TOKEN" ... "$API_URL")
  • 任务说明：使用 curl 命令，带着你的 Token，向 GitHub 发起询问。
  • 人话解释：程序对 GitHub 喊话：“喂！把这个仓库里所有正在排队的任务名单给我！” GitHub 会返回一串包含很多信息的文字。

5. 第五步：提取“身份证号” (Extract IDs)

代码：

queued_run_ids=$(echo "$response" | jq -r '.workflow_runs[] | .id')
  • 任务说明：用 jq 工具从那一堆文字中，只把任务的 ID 号抠出来。
  • 人话解释：GitHub 返回的信息里有任务名、时间、作者等等，我们不需要。我们只需要任务 ID（比如 12345, 67890），这是取消任务的唯一凭证。

6. 第六步：如果没有人排队，就下班 (Empty Check)

代码：

if [ -z "$queued_run_ids" ]; then
    echo "No queued workflow runs found."
    exit 0
fi
  • 任务说明：如果提取出来的 ID 列表是空的。
  • 人话解释：如果现在没有任务在排队，那就没事做了，直接结束程序。

7. 第七步：逐个“枪毙” (Loop & Cancel)

代码：

for run_id in $queued_run_ids; do
    echo "Cancelling run $run_id"
    cancel_url=".../runs/$run_id/cancel"
    curl -s -X POST ... "$cancel_url"
done
  • 任务说明：这是一个循环（Loop）。拿着刚才拿到的一串 ID，一个一个处理。
  • 人话解释：
    • 假如 ID 有 101 和 102。
    • 第一轮：拿到 101，拼凑出“取消 101”的链接，发送一个 POST 请求给 GitHub —— “把 101 给我停了！”
    • 第二轮：拿到 102，发送请求 —— “把 102 也给我停了！”
    • 一直重复，直到名单上的 ID 全部处理完。

8. 第八步：汇报工作 (Finish)

代码：

echo "Cancelled all queued workflow runs."
  • 任务说明：打印结束语。
  • 人话解释：告诉你：“老板，所有排队的任务都清理干净了。”

总结

这个脚本就是一个自动化的清理工。

  • 输入：你的 GitHub 密码（Token）。
  • 过程：去 GitHub 查一下 volcengine/verl 谁在排队 -> 记下名字 -> 挨个打电话通知取消。
  • 结果：排队列表清空。
