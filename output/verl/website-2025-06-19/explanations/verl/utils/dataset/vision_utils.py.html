Task 2: 处理图片 (process_image)

目标：看懂代码是如何把不同形式的图片统一化的。

代码片段：

def process_image(image: Union[dict, Image.Image]) -> Image.Image:
    # 1. 如果已经是 PIL 图片对象
    if isinstance(image, Image.Image):
        return image.convert("RGB") # 确保是彩色 RGB 模式，不是黑白或CMYK

    # 2. 如果是字典格式，且包含二进制数据 (bytes)
    if "bytes" in image:
        assert "image" not in image, "不能同时有 bytes 和 image 字段"
        # 把二进制流变成像文件一样可读的对象
        image["image"] = BytesIO(image["bytes"])

    # 3. 调用外部工具真正读取图片
    return fetch_image(image)

人话解释： 这个函数就像一个“图片接收员”。它会对来访的图片说： 1. “你是已经打开的图片对象吗？是的话，转成 RGB 彩色模式，直接通过。” 2. “你是一堆乱码（二进制数据）吗？没关系，我用 BytesIO 把你包装一下，伪装成一个文件。” 3. “最后，我把整理好的东西交给 fetch_image（千问官方工具），让它吐出最终结果。”

Task 3: 制定视频规则 (VIDEO_FORMAT_HELP)

目标：理解视频数据应该长什么样。

代码片段里的那大段字符串 VIDEO_FORMAT_HELP 其实就是一本说明书。

人话解释： 它告诉用户（也就是你），如果你想喂视频给模型，你的数据（JSON/Dict）必须长这样：

  • 格式 A（图片列表法）：视频由一张张图片路径组成。 json { "type": "video", "video": ["frame1.jpg", "frame2.jpg"] }
  • 格式 B（单个视频文件法）：直接给视频路径。 json { "type": "video", "video": "video.mp4" }
  • 进阶玩法（控制采样）：你可以规定每秒截几张图 (fps)，或者最少/最多截多少张。 json { "fps": 2.0, "min_frames": 4, "max_frames": 32 }

Task 4: 处理视频 (process_video)

目标：看懂代码是如何把视频变成模型能懂的张量（Tensor）。

代码片段：

def process_video(
    video: dict,
    nframes: Optional[int] = None,   # 强制指定总帧数
    fps: Optional[float] = None,     # 指定每秒几帧
    ...
) -> torch.Tensor:

    # 1. 检查格式：必须是字典且有 "video" 字段
    if not isinstance(video, dict) or "video" not in video:
        raise NotImplementedError(VIDEO_FORMAT_HELP) # 格式不对就报错，打印上面的说明书

    # 2. 检查冲突：不能既规定“总共截10张”，又规定“每秒截2张”
    assert nframes is None or fps is None, "Can't use both..."

    # 3. 浅拷贝一下，防止修改原始数据
    video = dict(video)

    # 4. 填充采样规则
    # 如果数据里没写怎么截屏，我们就用函数传进来的参数补上去
    contains_sampling_rules = "nframes" in video or "fps" in video
    if not contains_sampling_rules:
        if nframes is not None:
            video["nframes"] = nframes
        elif fps is not None:
            video["fps"] = fps
            # ... 设置最大最小帧数 ...

    # 5. 调用外部工具，把视频变成 Tensor [帧数, 3通道, 高, 宽]
    return fetch_video(video)

人话解释： 这个函数是“视频切片师”。 1. 安检：先看有没有视频文件，没有就报错。 2. 防冲突：你告诉我要切几刀（nframes），或者告诉我要多快切一刀（fps），但不能两个都说，我会晕。 3. 补全指令：如果你给的视频字典里没写怎么切，我就用函数参数里的默认设置来补全（比如设置 fps=2）。 4. 执行：最后交给 fetch_video，它会把视频读取出来，按规则截图，然后变成一堆数字矩阵（Tensor）返回给模型。

Task 5: 总结 (Summary)

一句话总结： 这个文件 (vision_utils.py) 是专门为 Qwen-VL（千问视觉模型） 准备的数据清洗脚本。

它的工作流程： 1. 对于图片：统一转成 RGB 格式或标准对象。 2. 对于视频：检查格式，确定截图规则（是按总张数截，还是按每秒几张截），然后转换成 PyTorch 的张量。

你如果不写代码，只需要知道： 当你看到这个文件报错时，通常是因为你的输入数据格式不对（比如视频字典里缺了 video 键，或者图片 bytes 没传对）。
