verl/utils/reward_score/geo3k.py

这份代码其实就是一个“阅卷老师”的打分逻辑。

它的核心作用是：在强化学习（RL）训练中，当模型生成了一个关于几何题（Geo3k数据集）的回答后，这段代码负责计算模型能得多少分（Reward）。

为了让你好理解，我们可以把这个过程想象成老师给学生的数学卷子打分。我为你列了一个 “阅卷流程 To-Do List”，我们一步步来看：

阅卷流程 To-Do List

  1. 任务一：检查卷面格式（Format Reward）
    • 目标：看学生有没有按规定写解题过程。
    • 规则：必须有思考过程 <think>...</think>，且必须用框框 \boxed{} 把最终答案圈出来。
  2. 任务二：检查答案对错（Accuracy Reward）
    • 目标：看学生圈出来的最终答案对不对。
    • 规则：提取框里的内容，跟标准答案比对。
  3. 任务三：计算总分（Compute Score）
    • 目标：给出一个最终的加权分数。
    • 规则：答案对错占大头（90%），格式规范占小头（10%）。

详细步骤讲解

第一步：检查卷面格式 (format_reward)

代码片段：

def format_reward(predict_str: str) -> float:
    # 定义一个正则表达式规则
    pattern = re.compile(r"<think>.*</think>.*\\boxed\{.*\}.*", re.DOTALL)
    # 检查模型的回答是否完全符合这个规则
    match_result = re.fullmatch(pattern, predict_str)
    # 符合给 1.0 分，不符合给 0.0 分
    return 1.0 if match_result else 0.0

  • 这是啥意思？ 现在的推理模型（比如 DeepSeek-R1 或 OpenAI o1）通常被要求先思考，再回答。 这个函数就是强行规定模型的输出必须长这样： > <think> 我正在思考这道几何题... </think> 最终答案是 \boxed{5}。

  • 为什么这么做？ 如果模型没有写 <think> 标签，或者最后没有用 \boxed{} 包裹答案，这一项就得 0 分。这是一种“格式约束”，强迫模型学会规范答题。

第二步：检查答案对错 (acc_reward)

代码片段：

def acc_reward(predict_str: str, ground_truth: str) -> float:
    # 从模型的回答里，把 \boxed{...} 里面的东西抠出来
    answer = extract_boxed_content(predict_str)
    # 用一个专门的数学判题工具(mathruler)来对比提取出的答案和标准答案(ground_truth)
    return 1.0 if grade_answer(answer, ground_truth) else 0.0
  • 这是啥意思？ 这一步不管你思考过程写得乱不乱，只看结果。 它调用了外部工具 mathruler（数学尺子），这很聪明。因为数学题里 0.5 和 1/2 其实是一样的，普通的字符串对比会判错，但 grade_answer 这种专门的工具能识别出它们是相等的。
    • 做对了：得 1.0 分。
    • 做错了：得 0.0 分。

第三步：计算总分 (compute_score)

代码片段：

def compute_score(predict_str: str, ground_truth: str) -> float:
    # 总分 = 0.9 * 答案分 + 0.1 * 格式分
    return 0.9 * acc_reward(predict_str, ground_truth) + 0.1 * format_reward(predict_str)

  • 这是啥意思？ 这是最后的统分环节。

    • 权重分配：
      • 90% 的分数取决于你题做没做对（acc_reward）。
      • 10% 的分数取决于你格式规不规范（format_reward）。

  • 举个例子：

    • 情况 A（完美）：格式对了，答案也对了。 得分 = $0.9 \times 1 + 0.1 \times 1 = \mathbf{1.0}$ 分。
    • 情况 B（做对但格式乱）：答案是对的，但没写 <think> 标签。 得分 = $0.9 \times 1 + 0.1 \times 0 = \mathbf{0.9}$ 分。
    • 情况 C（格式对但做错）：格式很漂亮，但答案算错了。 得分 = $0.9 \times 0 + 0.1 \times 1 = \mathbf{0.1}$ 分。（给点辛苦分，鼓励模型保持格式）。

总结

这个文件的核心观点是：在训练这个几何解题模型时，我们既看重结果（准确率），也看重过程规范（思维链格式），但结果比形式更重要（9:1开）。
