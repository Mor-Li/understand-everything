verl/utils/reward_score/prime_math/math_normalize.py

这份代码其实就像是一个“数学作业格式整理员”。

在训练 AI 做数学题时，AI 生成的答案格式五花八门（比如有的写 1/2，有的写 0.5，有的写 \frac{1}{2}），但标准答案只有一个。为了能自动判断对错，我们需要把所有千奇百怪的写法，统一转化成一种标准的 LaTeX 格式。

我为你列了一个“整理员的任务清单（Todo List）”，代码就是按照这个顺序一步步执行的：

任务清单：把“脏”答案变“标准”答案

假设输入进来的答案是：\text{ x = .5 cm } （这既有文字，又有变量名，还有单位，格式还不标准）。

第一阶段：预处理（剥壳）

  1. 检查是否为空：如果没答案，直接下班（返回 None）。
  2. 去皮：如果答案被包裹在 \text{...} 里，把外面的壳去掉，只留里面的内容。
    • 例子： \text{ x = .5 cm } $\rightarrow$ x = .5 cm

第二阶段：大扫除（清理杂质）

这一步主要在 _strip_string 函数里进行。

  1. 删掉换行符和多余空格：把 \n 和 \! 这种排版符号删掉。
  2. 统一斜杠：把双斜杠 \\ 变成单斜杠 \。
  3. 统一分数写法：LaTeX 里分数有 tfrac、dfrac，统统改成最普通的 frac。
  4. 删掉装饰性符号：
    • 删掉 \left 和 \right（括号修饰符）。
    • 删掉 ^{\circ}（角度符号，比如 $90^{\circ}$ 变成 90）。
    • 删掉美元符号 \$ 和百分号 \%。
  5. 删掉单位：如果数字后面跟着单位说明（比如 \text{ cm}），直接删掉，只留数值。
    • 例子： x = .5 cm $\rightarrow$ x = .5

第三阶段：格式规范化（整形）

  1. 补全小数点：把 .5 这种写法补全成 0.5。
    • 例子： x = .5 $\rightarrow$ x = 0.5
  2. 去掉变量名：如果答案是“变量 = 数值”的形式（且变量名很短），只保留数值。
    • 例子： x = 0.5 $\rightarrow$ 0.5
  3. 修复根号格式 (_fix_sqrt)：把偷懒的写法 \sqrt3 变成标准的 \sqrt{3}。
  4. 删掉所有空格：把字符串里剩下的空格全部挤掉。

第四阶段：数学等价转换（核心逻辑）

这是最关键的一步，保证不同写法的数学含义一致。

  1. 修复分数括号 (_fix_fracs)：
    • LaTeX 有时允许写 \frac12，要把它变成标准的 \frac{1}{2}。
  2. 强制转换 0.5：
    • 代码里有一个硬性规定：如果结果是 0.5，强制变成 \frac{1}{2}。
    • 例子： 0.5 $\rightarrow$ \frac{1}{2}
  3. 处理斜杠除法 (_fix_a_slash_b)：
    • 把 a/b 这种计算机写法，变成 LaTeX 的 \frac{a}{b} 写法。
    • 例子： 1/2 $\rightarrow$ \frac{1}{2}

总结

输入： 各种乱七八糟的写法，例如： * x = 0.5 * 1/2 * \text{ .5} * \frac12

经过这个文件的处理后，输出全部统一为： * \frac{1}{2}

目的： 这样一来，只要拿处理后的字符串和标准答案进行“字符串是否相等”的对比，就能知道 AI 算没算对了。这个文件就是数学评测中的“标准化过滤器”。
