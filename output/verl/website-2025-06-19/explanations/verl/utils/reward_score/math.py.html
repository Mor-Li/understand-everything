verl/utils/reward_score/math.py

这份代码的核心功能非常简单：它是一个数学题的“自动阅卷老师”。

在训练或测试 AI 做数学题时，模型会输出一大段推导过程，我们需要判断它最后算对没有。这份代码就是用来提取模型答案并与标准答案进行比对的。

为了让你更容易理解，我把它拆解成一个 “阅卷流水线” (Todo List)，每一步对应代码中的一个功能模块：

阅卷流水线 Task List

Task 1: 寻找答案在哪里 (Extraction)

  • 目标：模型可能输出几百个字的推理过程，我们只需要最后的那个数字或表达式。
  • 代码对应：last_boxed_only_string(string)
  • 动作：
    1. 在文字里从后往前找 \boxed 或 \fbox 这样的标记（这是 LaTeX 数学公式中用来给答案画框的标记）。
    2. 找到最后一个被框住的内容。
    3. 举例：如果模型输出 “因为 1+1=2，所以答案是 \boxed{2}”，这一步就把 \boxed{2} 抓出来。

Task 2: 拆开包装 (Unwrapping)

  • 目标：把刚才找到的 \boxed{2} 变成纯粹的 2。
  • 代码对应：remove_boxed(s)
  • 动作：
    1. 去掉外面的 \boxed{ 和 }。
    2. 只留下里面的核心内容。

Task 3: 格式标准化 (Normalization) —— 这是最复杂的一步

  • 目标：数学写法太多样了，比如 $\frac{1}{2}$ 和 $0.5$ 是一样的，x+y 和 x + y (有空格) 是一样的。为了让计算机能比对，必须把它们变成统一的格式。
  • 代码对应：strip_string(string) 及其调用的各种 fix_... 函数。
  • 具体步骤 (Sub-tasks)：
    • 清理杂质：去掉换行符、空格、\left、\right、$符号、百分号等 (strip_string 内部逻辑)。
    • 统一单位：去掉右边的单位描述，比如把 "5 kg" 变成 "5" (remove_right_units)。
    • 统一分数：把 0.5 强行变成 \frac{1}{2}；把 1/2 变成 \frac{1}{2}；把简写的 \frac12 变成标准的 \frac{1}{2} (fix_fracs, fix_a_slash_b)。
    • 统一根号：把 \sqrt3 变成标准的 \sqrt{3} (fix_sqrt)。

Task 4: 最终比对 (Comparison)

  • 目标：判断“处理后的模型答案”和“处理后的标准答案”是否一致。
  • 代码对应：is_equiv(str1, str2)
  • 动作：
    1. 分别对“模型答案”和“标准答案”执行上面的 Task 3 (标准化)。
    2. 比较两个字符串是否完全相等。
    3. 如果相等，返回 True，否则 False。

Task 5: 打分 (Scoring)

  • 目标：输出最终分数。
  • 代码对应：compute_score(solution_str, ground_truth)
  • 动作：
    1. 这是整个文件的主入口。
    2. 它依次调用 Task 1 -> Task 2 -> Task 4。
    3. 如果比对成功，返回 1.0 分；如果失败或出错，返回 0.0 分。

总结

你不需要逐行读懂那些复杂的字符串替换逻辑（比如正则替换），你只需要知道：

这个文件的作用就是把 AI 写的五花八门的数学答案，清洗成最标准的 LaTeX 格式，然后跟标准答案对比，看它算没算对。
