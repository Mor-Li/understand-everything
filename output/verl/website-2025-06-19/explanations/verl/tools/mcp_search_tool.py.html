讲解： 这里是“翻译官”干苦力的地方。因为返回的数据可能不是很标准的 JSON 格式，所以作者用了一种比较“暴力”的方法——正则表达式 (Regex) 来硬抓取信息。

  1. 过滤：它遍历输入的内容，只处理文本类型 (type == "text")。
  2. 修正：把单引号 ' 替换成双引号 "，试图让文本看起来更像标准的 JSON 格式。
  3. 硬抓取 (关键点)：
    • re.search(r'query"...)：它在文本里找 query: "..." 这种模式，强行把搜索关键词抠出来。
    • re.findall(r'"title"...)：它数一下文本里出现了多少次 "title":，以此来判断搜到了多少条结果。
    • re.search(r'"results"...)：它把 results: [...] 中括号里的所有具体内容抠出来。

比喻： 就像收到一封排版很乱的信，你拿着荧光笔，把“标题”、“关键词”和“正文”强行圈出来，不管信的语法对不对，只要看到关键词就圈。
