recipe/r1/tasks/math.py

这份代码其实就是一个“自动阅卷老师”。它的作用是判断 AI 做出的数学题答案（model_output）和标准答案（ground_truth）是否一致。

因为数学题的答案写法很多（比如 1/2 和 0.5，或者 LaTeX 格式的 \frac{1}{2}），不能简单地对比字符串是否相等，所以它用了一个专门的工具来处理。

为了让你彻底搞懂，我把你“理解这份代码”的过程拆解成了一个 5步走的 To-Do List：

✅ Task 1：搞清楚“谁来阅卷？” (依赖库)

代码位置： 开头的 try...except ImportError 部分。

  • 你的任务：理解这段代码需要外援。
  • 讲解：
    • Python 自带的功能不够强大，无法识别复杂的数学公式。
    • 所以代码尝试引入一个叫 math_verify 的第三方库。你可以把它想象成“专门批改数学卷子的专家”。
    • 如果你的电脑里没安装这个库，它会报错并提示你去安装 (pip install math-verify)。

✅ Task 2：设定“阅卷规则” (配置解析器)

代码位置： verify_func = math_metric(...)

  • 你的任务：理解阅卷老师是怎么从一大段文字里找到答案的。
  • 讲解：
    • AI 回答问题时可能会废话很多（比如：“经过计算，我认为答案是...”）。
    • 这几行代码是在配置“抓取答案”的规则：
      • pred_extraction_target: 告诉程序，AI 的答案可能是普通数学表达式 (Expr)，也可能是 LaTeX 格式 (Latex)，都要试着提取出来。
      • gold_extraction_target: 告诉程序，标准答案主要看作 LaTeX 格式。

✅ Task 3：处理“标准答案” (格式化)

代码位置： ground_truth_boxed = "\\boxed{" + ground_truth + "}"

  • 你的任务：理解为什么要给答案加个框。
  • 讲解：
    • 在很多数学竞赛数据集（如 MATH 数据集）中，最终答案通常要求用 LaTeX 的 \boxed{} 包裹起来，比如 \boxed{42}。
    • 这个阅卷工具 (math_verify) 比较认死理，它希望标准答案是有框的。
    • 所以这行代码强行给传入的标准答案穿上一件“马甲”（加上 \boxed{}），方便后面做对比。

✅ Task 4：开始“批改”并防手抖 (执行与容错)

代码位置： with contextlib.suppress(Exception): ... verify_func(...)

  • 你的任务：理解实际打分的过程以及如果出错怎么办。
  • 讲解：
    • verify_func([ground_truth_boxed], [model_output])：这就是真正的阅卷时刻。它对比处理后的标准答案和 AI 的输出。
    • contextlib.suppress(Exception)：这是一个保护机制。万一阅卷过程中程序崩溃了（比如公式格式太烂解析不了），不要让整个程序报错停止，而是“假装无事发生”，跳过错误。
    • 如果不出错，ret_score 就会被赋值为分数（通常对是 1.0，错是 0.0）。

✅ Task 5：给出“最终成绩” (返回值)

代码位置： return ret_score

  • 你的任务：理解函数最后吐出了什么。
  • 讲解：
    • 函数一开始把分数初始化为 0.0（假设你没及格）。
    • 如果 Task 4 阅卷成功且答案正确，分数变高。
    • 最后把这个分数（或者代表对错的布尔值）返回给调用者。

📝 总结 (一句话看懂)

这个脚本定义了一个叫 compute_score 的函数，它引入了一个专业的数学公式验证工具，把标准答案包装成特定格式后，与AI的输出进行智能比对，最后返回能不能得分。
