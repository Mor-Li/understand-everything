recipe/retool

这是一个专门为 Qwen（通义千问）系列模型 开设的 “工具使用特训班”。

在这个文件夹里，我们不教模型写诗或聊天，而是专门教它们如何使用工具（Retool），并且是在多轮对话的场景下（比如：“帮我查下天气” -> “北京今天晴” -> “那适合穿什么？”）。

以下是通俗易懂的解读：

1. 📁 当前文件夹 (recipe/retool) 的核心功能

把这里想象成一个 “职业技术学校的教务处”。 * 教学目标：让 AI 模型学会看说明书、调用 API、使用外部工具。 * 教学对象：Qwen 系列模型（从 4B 到 32B 不等）。 * 教学特色：长文本处理。因为工具的说明书通常很长，这里用到了特殊的“序列并行（Sequence Parallelism）”技术，让模型能一口气读完很长的内容而不“脑容量爆炸”（显存溢出）。

2. 📄 各个直接文件的作用

这里的文件主要分为两类：备菜工 和 烹饪指南。

  • retool_multi_turn_sft_preprocess.py (备菜工)

    • 作用：数据预处理。
    • 比喻：就像厨师做饭前要洗菜、切菜。这个脚本负责从网上下载原始的对话数据，把它清洗干净，整理成模型爱吃的格式（Parquet），并划分好哪些是平时练习题（训练集），哪些是期末考试题（测试集）。

  • run_qwen*.sh 系列 (不同难度的烹饪指南)

    • 这些都是启动训练的脚本，区别在于教的学生（模型大小）和使用的黑科技级别不同：
    • run_qwen2.5_32b_sp8.sh：
      • 对象：32B 的大模型（大块头学生）。
      • 特点：因为学生块头大，书又厚（长文本），所以开启了 SP8（把一句话切成 8 段给 8 张显卡处理），防止显卡撑爆。
    • run_qwen2.5_7b_sp4.sh：
      • 对象：7B 的中等模型。
      • 特点：开启了 SP4（把一句话切成 4 段），难度适中。
    • run_qwen3_4b_sp4.sh：
      • 对象：Qwen3-4B 的小巧模型。
      • 特点：同样使用 SP4 技术，训练速度最快。

  • run_sft.sh (通用入门指南)

    • 作用：一个更通用的启动脚本（看起来是针对 Qwen3-8B 的）。
    • 比喻：这是一个“懒人包”。它里面包含了下载数据和开始训练的全套流程，适合想快速跑通流程的人。

3. 📁 子文件夹的作用

(注：在你提供的结构中，recipe/retool 下面并没有列出子文件夹，只有文件。如果它是作为一个大项目的一部分，通常子文件夹会存放具体的代码逻辑，而这里主要是存放“怎么跑代码”的配置脚本。)

4. 🧠 高层认知：一句话理解这部分代码

这个文件夹就是一套流水线方案：

它先用 Python 脚本把“工具使用对话数据”整理好，然后提供了一堆 Shell 脚本，指挥8张显卡配合，利用序列并行技术（SP），分别把不同大小的 Qwen 模型 训练成能熟练使用工具的“AI 助手”。
