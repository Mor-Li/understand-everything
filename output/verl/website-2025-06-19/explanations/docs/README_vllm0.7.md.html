docs/README_vllm0.7.md

这份文档其实是一份技术操作指南，主要面向的是使用 verl（一个强化学习训练框架）的开发者，教他们如何将底层的推理引擎 vLLM 升级并配置到 0.7.x 版本。

简单来说，就是：“如果你想让 verl 跑得更快、更顺畅，并且想用 vLLM 0.7 版本，请按以下步骤操作。”

我为你整理了一个 Task Todo List，带你一步步拆解这份文档的核心观点：

✅ Task 1: 灵魂拷问（版本确认）

文档观点：虽然这篇文档讲的是 0.7 版本，但 0.8.3 版本现在已经稳定了。 * 你需要做的事： * 先停下来想一想：你必须用 0.7 吗？ * 如果不是非要用 0.7，文档建议你直接去读 docs/README_vllm0.8.md（去用更新更稳的 0.8 版本）。 * 如果你确定要用 0.7，请继续往下看 Task 2。

✅ Task 2: 基础环境搭建（安装）

文档观点：要让 verl 和 vLLM 0.7 配合工作，需要特定的安装顺序和版本。 * 你需要做的事： 1. 创建环境：新建一个 Python 3.10 的 conda 环境。 2. 安装 verl：下载源码并安装。 3. 安装 vLLM：强烈推荐直接安装 vllm==0.7.3（因为它是 0.7 系列里比较省心的）。 4. 安装 Flash-Attn：安装这个加速库。

✅ Task 3: “填坑”（仅针对旧版本 0.7.0 - 0.7.2）

文档观点：vLLM 的早期 0.7.x 版本（0.7.0, 0.7.1, 0.7.2）有 Bug 或不兼容的地方，官方还没修，你得自己动手改代码。 * 你需要做的事： * 如果你装的是 Task 2 推荐的 0.7.3：直接跳过这一步，不用看。 * 如果你不幸装了旧版：你需要找到安装目录下的 3 个 Python 文件，手动修改代码（文档里列出了具体要删掉哪行断言、改哪行变量、删哪行清空缓存的代码）。

✅ Task 4: 开启“加速模式”（CUDA Graph）

文档观点：装好后，默认配置没发挥全力。开启 CUDA Graph 功能可以大幅提升推理速度（从 115秒 -> 62秒），但也有一点副作用。 * 你需要做的事： * 在你的运行脚本里，添加两行配置： * enforce_eager=False (允许使用 CUDA Graph) * free_cache_engine=False * 注意风险：文档警告说，如果你的采样参数 n > 1（一次生成多条回答），开启这个功能可能会导致生成时间不稳定。

✅ Task 5: 开启“极速/稳定模式”（vLLM V1 Engine）

文档观点：vLLM 有一个新的实验性引擎叫 "V1 Engine"，它比上面的方法更稳、更快（提速 1.5倍），但安装很麻烦。 * 你需要做的事： * 如果你对性能有极致追求，或者 Task 4 的方案不稳定： 1. 卸载刚才装的 vLLM。 2. 从 GitHub 下载 vLLM 源码。 3. 切换到特定的 commit 版本 (2275784)。 4. 手动修改一行代码（关于 data_parallel_size 的）。 5. 开启 VLLM_USE_PRECOMPILED=1 重新编译安装。 6. 运行时设置环境变量 export VLLM_USE_V1=1。

总结

这篇文档其实就讲了三件事： 1. 怎么装（Task 1 & 2）。 2. 旧版怎么修 Bug（Task 3）。 3. 怎么配置能跑得更快（Task 4 & 5）。
