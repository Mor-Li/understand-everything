docs/preparation/prepare_data.rst

这份文档其实就在讲一件事：“如何把乱七八糟的数据，整理成训练代码能读懂的格式”。

不用被代码吓到，我把它拆解成一个 Task To-Do List（任务清单），带你一步步把这事儿做完。

核心目标

我们要写一个 Python 脚本，把原始数据（比如 HuggingFace 上的 GSM8K 数学题）转换成一个标准的 .parquet 文件。

Task List: 数据准备五步走

✅ Task 1: 准备好“原材料” (Load Data)

你需要先从 HuggingFace 或者本地加载你的原始数据集。 * 文档里的做法：使用 datasets.load_dataset 加载数据。 * 你的任务：确定你要训练什么数据（比如 GSM8K），并把它们加载进代码里，分成 train（训练集）和 test（测试集）。

✅ Task 2: 定义“标准格式” (The 5 Fields)

这是文档最核心的部分。训练系统（Verl）比较死板，它要求每条数据必须包含 5个特定的字段。不管你原本的数据长啥样，你都得把它们“整容”成这 5 个字段：

  1. data_source (字符串):
    • 含义：给数据贴个标签，告诉系统这数据叫啥。
    • 例子："openai/gsm8k"。
  2. prompt (列表/List):
    • 含义：这是喂给 AI 的输入。注意：它必须是 HuggingFace 的 Chat 格式（对话格式）。
    • 例子：[{"role": "user", "content": "1+1等于几？"}]。
  3. ability (字符串):
    • 含义：任务类型，用于分类。
    • 例子："math" (数学), "coding" (代码)。
  4. reward_model (字典/Dict):
    • 含义：这是给“判卷老师”（Reward Model）看的标准答案。
    • 关键点：里面必须有一个 ground_truth 字段，存着正确答案。
    • 例子：{"style": "rule", "ground_truth": "2"}。
  5. extra_info (字典/Dict):
    • 含义：存一些杂七杂八的信息，比如数据的 ID、是训练集还是测试集。目前暂时不太用，但得有。

✅ Task 3: 编写“转换逻辑” (Implement make_map_fn)

既然知道了标准格式，你需要写一个函数，把原始数据转换过去。文档里把这个函数叫做 make_map_fn。

  • 你的任务：
    • 写一个函数，输入是一条原始数据（比如包含 question 和 answer）。
    • 处理 Prompt：把 question 拿出来，加上提示词（比如“请一步步思考”），包装成 Task 2 里的 prompt 格式。
    • 处理答案 (extract_solution)：这是最麻烦的一步。原始数据的答案可能是一大段话，你需要写个正则（Regex）或者逻辑，把最终的那个数字或结果提取出来，塞给 ground_truth。
    • 组装：把上面处理好的东西，塞进一个字典返回。

✅ Task 4: 批量转换 (Map & Save)

逻辑写好了，现在要应用到所有数据上。 * 文档里的做法：调用 dataset.map(function=make_map_fn)。这就像工厂流水线，把每一条数据都过一遍你的转换函数。 * 保存：最后调用 .to_parquet() 把处理好的数据存成文件（train.parquet 和 test.parquet）。

✅ Task 5: 放到指定位置 (Copy to HDFS/Local)

  • 训练代码通常会去读某个特定文件夹。脚本最后一步是把生成好的 .parquet 文件复制到那个文件夹（比如 HDFS 或者本地目录）。

总结一下你需要写什么代码

如果你要跑一个新的数据集，你需要修改文档代码中的这两个地方：

  1. extract_solution(solution_str):
    • 问自己：我的原始答案里，怎么把“正确答案”抠出来？（比如 GSM8K 是用 #### 符号标记答案的，你就得写代码去截取 #### 后面的数字）。
  2. make_map_fn(split):
    • 问自己：我的原始数据里，哪一列是问题？哪一列是答案？怎么把它们填进那 5个标准字段 里？

举个例子（人话版）

假设你有一条原始数据： {"问题": "小明有1个苹果，又买了1个，现在有几个？", "答案": "很简单，1+1=2。#### 2"}

经过你的脚本处理后，它必须变成这样：

{
  "data_source": "my_math_data",
  "prompt": [
    {
      "role": "user",
      "content": "小明有1个苹果，又买了1个，现在有几个？ Let's think step by step..."
    }
  ],
  "ability": "math",
  "reward_model": {
    "style": "rule",
    "ground_truth": "2"  // 注意：这里是你用 extract_solution 从原始答案里抠出来的
  },
  "extra_info": {
    "index": 0,
    "split": "train"
  }
}

懂了吗？这篇文档就是在教你如何写代码完成这个格式转换的过程。
