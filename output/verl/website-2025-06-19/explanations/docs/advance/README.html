docs/advance

这里是 docs/advance（高级进阶文档）目录的通俗解读。

1. 🏎️ 这个文件夹是干嘛的？

如果说基础文档是教你怎么“开车”，那么 docs/advance 就是“赛车改装车间”的工程师手册。

这里不讲怎么简单地跑通一个任务，而是讲当你的需求超出标准配置时该怎么办。比如：模型太大显存不够怎么办？想跑一个新的冷门模型怎么办？想修改底层的算法逻辑怎么办？想用更硬核的分布式架构怎么办？

简单来说，这里存放的是为了解决极端性能问题、定制化需求和大规模训练难题而准备的“黑科技”说明书。

2. 📄 各个文件都在讲什么？（直接文件解读）

这里的文件主要分为三类：防灾与维护、性能魔改、深度定制。

💾 防灾与维护类

  • checkpoint.rst（存档与拼图指南）

    • 作用：教你如何保存训练进度（防止断电白跑），以及最重要的是，如何把训练时被切碎分散在几十张显卡里的模型文件，“拼”回成一个完整的、HuggingFace 能识别的文件。
    • 比喻：就像玩游戏时的“存档点”，以及把打碎的瓷瓶重新粘好的“修复胶水”。

  • placement.rst（调度指挥中心）

    • 作用：介绍系统底层（基于 Ray）是如何分配工人的。比如谁负责写文章（Actor），谁负责打分（Critic），它们怎么分组，怎么领任务。
    • 比喻：这是工厂的HR和工头手册，告诉你怎么把成百上千个 GPU 工人编成小组，高效干活。

🚀 性能魔改类（省钱与加速）

  • ppo_lora.rst（省钱装修攻略）

    • 作用：教你如何用有限的显卡资源（LoRA技术）去训练超大的模型（如 70B 参数）。
    • 比喻：“轻装修”指南。不动承重墙（全量参数），只贴壁纸（LoRA），既省钱（省显存）效果又好。

  • rope.rst（长文本补丁）

    • 作用：针对某些出厂没写明支持长文本的模型（如 Qwen），教你如何通过修改配置，强行开启“长文本模式”。
    • 比喻：给近视眼的模型强行配一副“远视眼镜”，让它能看清更长的文章。

🛠️ 深度定制类（造轮子）

  • dpo_extension.rst（新算法设计图）

    • 作用：如果你不满足于现有的算法，想自己写一套新的强化学习流程（比如 Online DPO），这篇文档教你如何利用框架的 API 来实现。
    • 比喻：“新菜谱研发指南”。教你如何指挥厨房里的切菜工、炒菜工配合，做出一道菜单上没有的新菜。

  • fsdp_extension.rst（FSDP 搬运工培训）

    • 作用：当你引入一个新模型，且使用 FSDP 分布式训练时，教你如何写代码让推理引擎（vLLM）能聪明地加载训练好的参数，不至于撑爆内存。
    • 比喻：教新来的搬运工（vLLM）怎么从仓库（FSDP）里“化整为零”地搬运货物，而不是一次性把门堵死。

  • megatron_extension.rst（重型机械操作手册）

    • 作用：教你如何把业界最硬核、最复杂的训练后端 Megatron-LM 接入到这个框架里来。
    • 比喻：“核动力引擎安装指南”。如果你嫌原本的引擎不够劲，想换个工业级的大家伙，就看这个。

4. 🧠 高层认知：怎么理解这部分代码？

要把 docs/advance 看作是一个“可以按需查阅的工具箱”：

  1. 你不需要从头读到尾：只有当你遇到了具体瓶颈（比如显存炸了、模型不支持、要改算法）时，才需要来查对应的文档。
  2. 核心逻辑是“解耦”与“桥接”：
    • 大部分文档都在解决一个问题：训练端（Actor）和推理端（Rollout/vLLM）是两套不同的系统，甚至是分布在不同机器上的碎片。
    • 这里的很多代码（Extension 类文件）就是在做“翻译官”和“搬运工”，确保数据和权重能在这些复杂的分布式组件之间顺畅流动。

一句话总结：这是给高级玩家准备的，教你如何打破框架的默认限制，榨干硬件性能，或者接入你自己魔改的新模型。
