docs/perf

这里是 docs/perf 目录的通俗解读。

如果把训练大模型比作“赛车比赛”，那么这个文件夹就是你的“王牌技师团队”和“车辆改装指南”。它的核心目的是：帮你省钱（选对显卡） 和 帮你省时间（跑得更快）。

1. 📁 这个文件夹主要负责什么？

核心功能：性能优化与硬件指南。

它不讲怎么写代码逻辑，只讲怎么压榨显卡性能。它回答了三个最昂贵的问题： 1. “我需要买几张卡？”（硬件门槛） 2. “为什么跑得这么慢？”（性能诊断） 3. “怎么调节参数才能跑得飞快？”（性能调优）

2. 📄 各个文件的具体作用（通俗版）

这里只有四个文件，每一个都是一本“武功秘籍”：

1. device_tuning.rst —— “装机配置单” (硬件篇)

  • 作用：告诉你跑不同大小的模型（7B, 70B等），到底需要什么样的显卡组合。
  • 比喻：这就是一份“电脑城装机推荐表”。
    • 想玩轻量级游戏（7B模型）？它告诉你“两张 H800 够了”。
    • 想玩 3A 大作（70B模型）？它警告你“必须上 8 张 H100，否则别想跑”。
    • 它分了“最低配置（能动就行）”和“推荐配置（跑得爽）”两档。

2. perf_tuning.rst —— “极速改装手册” (软件篇)

  • 作用：教你通过调整软件参数（Batch Size, 显存利用率等），把显卡的潜力发挥到极致。
  • 比喻：这是“赛车ECU调校指南”。
    • 硬件已经定好了，这篇文档教你如何调整“喷油量”（Batch Size）和“进气量”（vLLM显存），让你的车在不爆缸（不爆显存）的前提下，速度拉到最快。
    • 核心口诀是：去填充、开动态批次、把显存塞满。

3. nsight_profiling.md —— “全身体检仪” (诊断篇)

  • 作用：教你用 NVIDIA Nsight Systems 工具来监控训练过程，找出哪里卡顿了。
  • 比喻：这是“X光机使用说明书”。
    • 当你觉得训练速度慢得不正常，又找不到原因时，按照这个文档做一次“CT扫描”。
    • 它能生成一张图表，告诉你每一毫秒显卡在干嘛，是“在干活”还是“在偷懒等待”。

4. dpsk.md —— “打怪兽专享攻略” (特例篇)

  • 作用：专门针对 DeepSeek-V3 (671B) 这种超级巨无霸模型的训练指南。
  • 比喻：这是“哥斯拉饲养指南”。
    • 普通模型是养猫养狗，DeepSeek 671B 是养哥斯拉。普通的笼子（服务器）根本装不下。
    • 这篇文档告诉你，要搞定这只怪兽，你需要 512 张显卡组成的超级牢笼，以及特殊的喂养技巧（Megatron 分布式切分）。

4. 🧠 给你一个高层的认知

看到 docs/perf，你就把它想象成一个“赛车维修站（Pit Stop）”：

  • 进站前，先看 device_tuning 选对车（硬件）。
  • 上赛道前，照着 perf_tuning 把引擎参数调到最猛（调优）。
  • 跑得慢了，用 nsight_profiling 查查是不是排气管堵了（诊断）。
  • 如果你要开的是“航天飞机”（DeepSeek 671B），请单独阅读 dpsk 手册。

一句话总结：这里不教你怎么开车（写模型代码），只教你怎么把车改得最快、最稳。
