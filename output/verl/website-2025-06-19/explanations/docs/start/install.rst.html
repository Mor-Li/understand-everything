docs/start/install.rst

这份文档主要讲的是如何安装和配置 verl（一个用于大模型强化学习训练的框架）。因为涉及到深度学习、大规模并行训练和推理，所以它的依赖项比较复杂。

为了让你看懂，我把文档的核心观点拆解成一个“任务清单 (To-Do List)”，并按逻辑顺序一步步给你讲。

核心概念（先看这个，否则后面不知道在选什么）

verl 运行需要两个核心引擎配合： 1. 训练引擎 (Training Backend)：负责更新模型的参数。 * 选项 A (FSDP)：推荐用于研究、原型开发（比较简单）。 * 选项 B (Megatron-LM)：推荐用于追求极致扩展性的大规模训练（比较复杂）。 2. 推理引擎 (Rollout/Inference Backend)：负责让模型生成数据（玩游戏/对话）。 * 选项 A (vLLM)：稳定，兼容性好（推荐 0.6.3 或 0.8.2 版本）。 * 选项 B (SGLang)：速度更快，吞吐量更高（正在快速发展中）。

你的 To-Do List (安装步骤)

你可以根据你的情况选择 方案一（推荐，简单） 或 方案二（困难，折腾）。

✅ 步骤 0：硬件检查 (Requirements)

  • [ ] 确认 Python 版本 >= 3.9
  • [ ] 确认 CUDA（显卡驱动相关）版本 >= 12.1

🚀 方案一：使用 Docker 安装（强烈推荐）

这是最省事的办法，环境都是配置好的。

Task 1: 选择并拉取 Docker 镜像 根据你的需求选择一个镜像（Image）： - [ ] 如果你要跑 DeepSeek-V3 或需要稳定版： 使用镜像：whatcanyousee/verl:ngc-cu124-vllm0.8.5-sglang0.4.6.post5-mcore0.12.1-te2.3-deepseekv3 - [ ] 如果你要用 FSDP 跑最新版： 使用镜像：hiyouga/verl:ngc-th2.6.0-cu126-vllm0.8.4-flashinfer0.2.2-cxx11abi0 - [ ] 如果你要用 SGLang + FSDP： 使用镜像：ocss884/verl-sglang:ngc-th2.6.0-cu126-sglang0.4.6.post5

Task 2: 启动容器 - [ ] 运行文档中提供的 docker create 和 docker start 命令进入环境。

Task 3: 在容器内安装 verl - [ ] 克隆代码仓库：git clone ... - [ ] 安装依赖（二选一）： - 想用 vLLM 推理：pip3 install -e .[vllm] - 想用 SGLang 推理：pip3 install -e .[sglang]

🛠️ 方案二：手动环境安装（仅当无法使用 Docker 时）

这部分很麻烦，容易出错，主要是在处理依赖冲突。

Task 1: 安装底层依赖 (Pre-requisites) - [ ] 安装 CUDA Toolkit：必须 >= 12.4（文档给了 wget 和 dpkg 命令）。 - [ ] 安装 cuDNN：必须 >= 9.8.0（文档给了安装命令）。 - [ ] 安装 NVIDIA Apex：用于加速训练，安装时间很长，注意设置 MAX_JOB 避免内存爆炸。

Task 2: 创建 Python 环境 - [ ] 使用 Conda 创建新环境：conda create -n verl python==3.10

Task 3: 运行安装脚本 文档警告：推理框架（如 vLLM）容易覆盖掉 PyTorch 版本，所以顺序很重要。 - [ ] 运行官方提供的脚本： - 如果用 Megatron：bash scripts/install_vllm_sglang_mcore.sh - 如果只用 FSDP：USE_MEGATRON=0 bash scripts/install_vllm_sglang_mcore.sh

Task 4: 安装 verl 本体 - [ ] git clone 代码并执行 pip install --no-deps -e .

Task 5: 检查版本 (Post-installation) - [ ] 检查 torch, vLLM, SGLang 等包是否被意外覆盖成了错误版本。

🖥️ 特殊情况：AMD 显卡用户

如果你用的是 AMD 显卡（如 MI300）： - [ ] 不要用上面的方法。 - [ ] 必须构建专门的 ROCm Docker 镜像。 - [ ] 参考文档最后的 docker/Dockerfile.rocm 部分进行构建和启动。

总结

简单来说，文档就是在告诉你：别折腾手动安装了，直接用 Docker 吧。 选好你要用的推理引擎（vLLM 还是 SGLang），拉取对应的镜像，进去运行几行命令就搞定了。
