verl/utils/dataset/README.md

这份文档其实是在定义“如何把数据喂给 AI 进行强化学习（RLHF）训练”的标准。

因为它写得很技术化，我把它转换成一个“数据准备任务清单（Todo List）”。想象你现在是这个项目的数据工程师，你需要按照以下步骤准备数据，才能让系统跑起来。

以下是根据文档内容拆解的 5 个步骤：

Task 1：确定文件存储格式

文档原文： "We combine all the data sources into a single parquet files." * 你的任务： 不要用 txt 或 csv，要把所有数据存成 Parquet 格式。 * 白话解释： Parquet 是一种比 Excel 更高效、更适合大数据的表格文件格式。不管数据从哪来，最后都要汇总成这一个文件。

Task 2：把“提问”包装成“聊天记录”

文档原文： "organize the prompt into the chat format so that multi-turn chats can be easily incorporated." * 你的任务： 在构造数据时，不要只给一个干巴巴的问题字符串。要把它包装成一个列表（List），里面包含角色（User）和内容（Content）。 * 看例子： json "prompt": [ { "role": "user", "content": "Natalia sold clips..." } ] * 为什么要这么做？ 这样如果以后有“多轮对话”（你一句我一句），系统也能直接支持，不用改代码。

Task 3：在提问中“埋”入格式指令

文档原文： "add instruction following texts to guide the model output the answers in a particular format so that we can extract the answers." * 你的任务： 在你的问题后面，必须加上一句话，强行规定 AI 回答的格式。 * 看例子： 注意 prompt 里的这句话： > "Let's think step by step and output the final answer after '####'" > (让我们一步步思考，并在 "####" 之后输出最终答案) * 为什么要这么做？ 机器是很笨的。如果不规定它在 #### 后面写数字，程序就不知道去哪里抓取答案来判断对错。

Task 4：准备好“阅卷标准”（标准答案）

文档原文： "reward_model": { "style": "rule", "ground_truth": ["72"] } * 你的任务： 你得告诉系统，这道题的正确答案是什么，以及用什么规则去判分。 * 看例子： * style: "rule" -> 表示用规则硬性匹配（比如必须数字对）。 * ground_truth: ["72"] -> 标准答案是 72。 * 逻辑流： AI 输出了答案 -> 程序去 #### 后面抓取数字 -> 和 ground_truth 里的 "72" 对比 -> 如果一样，就给 AI 奖励（Reward）。

Task 5：打上元数据标签

文档原文： "data_source": "openai/gsm8k", "ability": "math" * 你的任务： 给这条数据打上来源和类型的标签。 * 白话解释： * data_source: 这题是从哪抄来的？（比如 OpenAI 的 gsm8k 数据集）。 * ability: 这题考的是什么能力？（比如 math 数学）。 * 这主要是为了方便以后管理和筛选数据。

总结：

这个文档就是在告诉你，每一行数据（Json 对象）必须长成这个样子：

  1. 来源 (source): 哪里来的？
  2. 能力 (ability): 考什么的？
  3. 题目 (prompt): 必须是聊天格式 + 包含“请在####后写答案”的指令。
  4. 判分 (reward_model): 标准答案是多少？

弄懂了这个结构，你就看懂了这个 dataset 的说明文档。
