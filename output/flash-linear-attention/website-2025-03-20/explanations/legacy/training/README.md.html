legacy/training/README.md

这份文档其实是一个名为 Flame 的训练框架的使用说明书。简单来说，它是用来训练一种特殊的“线性注意力机制（Linear Attention）”大模型的工具。

虽然代码看起来很复杂，但它的核心逻辑就是：配环境 -> 搞数据 -> 跑训练。

为了让你看得更清楚，我把它拆解成一个 任务清单 (To-Do List)，你只需要按顺序理解这几步即可：

⚠️ 任务 0：重要前置提醒 (必读)

状态： 警告 * 核心观点：这个代码库（Legacy）已经是旧版本了，官方已经不再维护。 * 行动建议：如果你是新来的，官方建议你去新的仓库 fla-org/flame（基于 torchtitan 构建），不要死磕这一版代码。但如果你必须用这版，请继续往下看。

✅ 任务 1：环境搭建 (Setup)

目标： 把跑代码需要的软件装好。 1. 下载代码：把 fla 这个核心库下载下来。 2. 安装依赖：安装 accelerate（用于多显卡并行训练的工具）。 3. 避坑指南：文档特意强调，安装 tokenizers 库时，版本必须大于 0.20.4，否则处理长文本时内存会泄漏（爆内存）。

✅ 任务 2：数据准备 (Preprocessing)

目标： 下载文本数据，并把它转换成模型能读懂的格式（Tokenization）。 1. 使用脚本：作者提供了一个 preprocess.py 脚本。 2. 操作举例： * 如果你用 fineweb-edu 数据集，运行提供的命令，它会自动下载并处理 10B (100亿) token 的数据。 * 如果你用 SlimPajama 数据集，建议先用 git lfs 下载原文件，再运行处理脚本。 3. 结果：处理好的数据会被存在 data/ 目录下，供训练使用。

✅ 任务 3：开始训练 (Training)

这里分两种情况，看你的需求是“从零开始”还是“接着别人的练”。

🔹 情况 A：从零开始训练 (Training from scratch)

目标： 像训练初生婴儿一样，训练一个全新的模型（比如 3.4亿参数的 GLA 模型）。 1. 运行命令：使用 bash train.sh。 2. 关键参数解释（不用全背，看这几个就行）： * config: 模型的图纸（json文件）。 * lr: 学习率（学得太快容易走火入魔，太慢学不会）。 * batch: 一次喂给模型多少数据。 * context: 模型一次能看多长的文章（比如 2048 个字）。 * steps: 总共训练多少步。 3. 算账：文档教你怎么算“全局 Batch Size”（总吞吐量）。公式是：单卡Batch * 显卡数 * 机器数 * 累积步数。修改参数时要注意这个总数别太离谱。 4. 断点续训：如果训练中途断电了，加上 checkpoint=路径 参数，可以接着上次的地方继续练。

🔹 情况 B：继续预训练/微调 (Continual Pretraining)

目标： 把一个已经很厉害的模型（比如 Mistral-7B），改造成线性注意力模型（GLA）并继续训练。 1. 模型转换：先运行 convert_from_llama.py，把原本的 Mistral 模型权重，“搬运”到新的 GLA 架构里。 2. 开始微调：拿着转换好的模型（checkpoint），运行 train.sh 继续训练。 * 提示：这种大模型（7B）通常需要多台机器（Multi-node）一起跑才快，单机跑不动。

✅ 任务 4：监控训练过程

目标： 看着模型变聪明。 * 工具：支持 wandb。这是一个可视化工具，能在网页上看到训练曲线（Loss下降了没有，学习率怎么变的），就像看股票K线图一样。

总结 (Summary)

这篇文章就是告诉你： 1. 别用这个旧版了（除非必须）。 2. 装环境（注意 tokenizer 版本）。 3. 下数据（用脚本处理）。 4. 跑脚本（train.sh 是核心，改改参数就能跑）。
