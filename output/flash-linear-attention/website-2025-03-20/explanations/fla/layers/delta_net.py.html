fla/layers/delta_net.py

这份代码实现了一个名为 DeltaNet 的神经网络层。

简单来说，它是 Transformer 中“自注意力机制（Self-Attention）”的一个替代品。它的目标是：拥有 Transformer 的性能，但计算速度像 RNN 一样快（特别是推理时），并且更省显存。

为了让你读懂它，我把这份代码的执行流程拆解成了一个 “任务清单 (Todo List)”。我们可以把这个层看作是一个“信息加工厂”，数据进来后，需要经过以下 7 个步骤的处理。

📋 DeltaNet 任务清单 (Todo List)

  1. 【准备原材料】特征投影 (Projections)：把输入变成 Q, K, V。
  2. 【局部打磨】短卷积 (Short Convolution)：先看看邻居，提取局部特征。
  3. 【预处理】激活与归一化 (Activation & Norm)：把数据调整到合适的分布。
  4. 【控制阀门】计算 Beta ($\beta$)：决定要往记忆里写入多少新信息。
  5. 【核心工艺】Delta Rule 计算 (The Delta Rule)：更新记忆状态，计算输出。
  6. 【质量控制】门控与归一化 (Gating & Norm)：过滤杂质，稳定输出。
  7. 【打包出厂】输出投影 (Output Projection)：变回原来的形状。

逐步讲解 (Step-by-Step)

1. 【准备原材料】特征投影 (Projections)

  • 代码位置：__init__ 中的 self.q_proj, self.k_proj, self.v_proj。
  • 在做什么： 就像标准的 Transformer 一样，我们把输入的向量 hidden_states 分别通过三个全连接层，变成了三个新的向量：
    • Q (Query)：查询向量。
    • K (Key)：键向量。
    • V (Value)：值向量（包含实际内容）。
    • 注：这里还支持 expand_k/v，意味着 K 和 V 的维度可以比输入更大或更小。

2. 【局部打磨】短卷积 (Short Convolution)

  • 代码位置：forward 函数中的 if self.use_short_conv: 代码块。
  • 在做什么： 这是线性 Attention 模型的一个关键技巧。
    • 问题：普通的线性 Attention 往往忽略了词与词之间紧挨着的“局部关系”（比如“好”后面大概率接“的”）。
    • 解决：在进行复杂的计算前，先用一个很小的卷积核（kernel_size=4）在 Q, K, V 上滑一遍。这相当于让每个词先和它左右的邻居“交流”一下。
    • 代码体现：self.q_conv1d, self.k_conv1d, self.v_conv1d。

3. 【预处理】激活与归一化 (Activation & Norm)

  • 代码位置：forward 函数中 if self.qk_activation ... 和 if self.qk_norm ...。
  • 在做什么： 为了让数学公式稳定运行，需要对 Q 和 K 做非线性变换。
    • 通常使用 SiLU 或 ReLU 激活函数。
    • 代码中还涉及了 rearrange，把数据形状调整为适合多头计算的格式 (batch, seq_len, num_heads, head_dim)。

4. 【控制阀门】计算 Beta ($\beta$)

  • 代码位置：forward 函数中 if self.use_beta:。
  • 在做什么： 这是 DeltaNet 的核心特色之一。
    • 概念：你可以把 $\beta$ 想象成一个“学习率”或者“更新强度”。
    • 它是由输入数据通过 self.b_proj 计算出来的。
    • 如果 $\beta$ 很大，说明当前的输入很重要，我们要大幅更新记忆；如果 $\beta$ 很小，说明当前输入是噪音，忽略它，保持原有的记忆。

5. 【核心工艺】Delta Rule 计算 (The Delta Rule)

  • 代码位置：forward 函数中调用 chunk_delta_rule 或 fused_recurrent_delta_rule 的地方。
  • 在做什么： 这是整个文件最难懂、也是最重要的地方。它不再使用 Transformer 的 $QK^T$ 矩阵乘法（那是 $O(N^2)$ 的复杂度），而是用一种递归（Recurrent）的方式。
    • 原理：它维护一个记忆状态矩阵 $S$。
      • 传统 RNN：$S_t = S_{t-1} + K^T V$ （简单的累加）。
      • Delta Rule：$S_t = S_{t-1} + \beta (V - K S_{t-1})$。
    • 通俗解释：
      1. 先用当前的 Key ($K$) 去查询旧的记忆 ($S_{t-1}$)，看看我们预测出的 Value 是什么。
      2. 计算误差 (Delta)：实际的 $V$ 减去 预测的 $V$。
      3. 根据 $\beta$ 的大小，把这个误差更新回记忆 $S$ 中。
    • 两种模式：
      • chunk：训练时用。把序列切成小块并行计算，速度快。
      • fused_recurrent：推理（生成文本）时用。像 RNN 一样一个词一个词处理，显存占用极低。

6. 【质量控制】门控与归一化 (Gating & Norm)

  • 代码位置：forward 最后的 if self.use_gate: 和 self.o_norm。
  • 在做什么：
    • Gating (门控)：计算出一个 Gate 向量 g，通过 o * g 来过滤输出。这能让模型训练更稳定。
    • Norm：通常使用 RMSNorm，确保输出数值的尺度是正常的，防止梯度爆炸。

7. 【打包出厂】输出投影 (Output Projection)

  • 代码位置：forward 最后一行 return self.o_proj(o), ...。
  • 在做什么： 把经过各种复杂计算的输出向量，通过一个全连接层 o_proj，映射回模型原本的 hidden_size。这样这个层就可以无缝衔接到下一个层去。

总结：这段代码到底牛在哪里？

如果你看懂了上面的流程，就会发现 DeltaNet 的本质是：

  1. 它是一个 RNN（因为它有状态 $S$，且是随时间更新的）。
  2. 它引入了 Delta 规则（利用“预测误差”来更新记忆，比简单的累加更聪明）。
  3. 它引入了 Short Conv（不仅看历史，也看局部邻居）。
  4. 它在代码实现上做了高度优化（chunk_delta_rule），使得它训练时能像 Transformer 一样并行，推理时能像 RNN 一样快。
